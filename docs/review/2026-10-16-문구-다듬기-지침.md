- 날짜: 2026-10-16
- 요청: 「문구들중에 뭐 "처치하면 보물상자" 이런걸 "처치하면 보물상자를 획득합니다." 이런식으로 전부 다 찾아내서 바꿔」 + 「이런 비슷 류의 개선작업도 전부 다 찾아내」

## 1. 번역 구조 (코드로 확인한 사실)

### 1-1. 찾는 순서 (`Assets/Scripts/Loc.cs` 19~31행)

```
Loc.T(ko) = KeyBindings.Apply(Translate(ko))
Translate: Entries.TryGetValue(ko) 없음 → ko 그대로
           현재 언어 0(한국어) → tr[0] 이 비어 있지 않으면 tr[0], 비었으면 ko(키)
           그 밖(en=1 · ja=2 · zh=3) → tr[i] 가 null 이 아니면 그대로 ("" 도 그대로 — 일부러 비운 단위) · null 이면 ko
```

- 따라서 **한국어 표시는 키를 건드리지 않고 ko 칸(0번)만 채우면 바뀐다.** 이미 그렇게 쓴 예: `LocTable.cs:168` `{ "사망하셨습니다...", E("쓰러졌다...", ...) }`, `LocTable.cs:172` `{ "[P] 상점    [ESC] 메뉴", E("[ESC] 메뉴 · 설정", ...) }`.
- 번역 뒤 `KeyBindings.Apply` 가 `{INTERACT}` `{ULT}` `{ATTACK}` `{RELOAD}` `{MOVE}` `{UPGRADE}` `{REROLL}` `{RELIC}` `{SKILL1~3}` 을 지금 키 이름으로 바꾼다. 네 언어 모두 이 표시를 **글자 하나 틀리지 않게** 유지해야 한다.
- 씬에 적힌 글자(버튼 · 제목)는 `GameSettings.cs:322~` `SceneLocalizer.RefreshAll()` 이 **`Loc.Has(t.text)` 가 참인 것만** `Loc.T` 로 바꾼다. 씬 글자를 고치려면 씬을 열지 말고 그 글자를 키로 둔 채 ko 칸을 채운다(위 「사망하셨습니다...」 방식). 지금 씬에 남은 한국어 TMP 는 `Assets/Prefabs/Scenes/GameScene.unity:2252` 「계속하기」 하나뿐이고 표에 있다.
- 코드가 만드는 글칸(`MenuExtras.cs:556 UIKit.Text(parent, ko, ...)`)도 `Loc.T(ko)` 로 번역하고 언어가 바뀌면 다시 그린다 → 같은 규칙.

### 1-3. 한국어 칸을 채우는 방법 (파일마다 다름)

- `LocTable.cs`: `L("en","ja","zh")` → `E("새 한국어", "en", "ja", "zh")`. 키(왼쪽 `"..."`)는 그대로.
- `Result/Relics/SoulBrand/Weight/KeyGuide/Codex/Content/Notice/Leaderboard/Ux/Juice`: 두 번째 인자(ko)만 고친다. 키가 `result.xxx` 같은 식별자인 것도, 한국어 문장 자체인 것도 있다 — **첫 번째 인자는 건드리지 않는다.**
- `Skills/Heroes/Transcend` 는 `A(ko,en,ja,zh)` 4개 인자라 ko 칸이 없다. 한국어를 고쳐야 하면 그 파일 맨 위 `A` 옆에 **5개 인자 도우미 하나를 더한다**(예: `void K(string key, string ko, string en, string ja, string zh) { if (!Entries.ContainsKey(key)) Entries[key] = E(ko, en, ja, zh); }`) 그리고 그 줄만 `K("원래 키", "새 한국어", ...)` 로 바꾼다. 다른 파일은 건드리지 않는다.
- 새 키를 **추가하지 않는다.** 코드 속 `Loc.T("…")` 의 글자와 키가 한 글자라도 다르면 번역이 끊긴다(`LocTable.Transcend.cs:122` 주석 「키는 CodexUI 의 문장과 글자까지 같아야 함」).

### 3-4. 같은 화면에서 문체 섞임

## 5. en · ja · zh 규칙

### 5-1. 공통
- 한국어를 고친 뒤 **같은 줄의 세 언어도 같은 뜻 · 같은 문장 수 · 같은 자리표시자 · 같은 `\n`** 으로 맞춘다. 한국어만 문장이 되고 영어가 명사형으로 남으면 안 된다.
- 한국어가 라벨이면 다른 언어도 라벨, 문장이면 문장.
- 한국어가 바뀌지 않은 줄도 **문장부호 규칙**(아래)은 맞춘다.

### 5-2. 영어
- 설명 · 툴팁: 완결 문장 + 마침표. 2인칭 「you」 또는 명령형(「Defeat them all for a treasure chest.」) — 지금 다수.
- 이름 · 버튼 · 탭 · 설정 이름: Title Case. 접속사 · 관사 · 2~3자 전치사(of · to · in · for · and · or)는 소문자(「Reset to Default」 「Gate of Hell」).
- 수치 라벨: sentence case, 마침표 없음.
- 큰 알림 첫 줄: 느낌표 유지 「The curse awakens!」
- 숫자: 「1.5×」 「5s」 「2 tiles」 「3,000」 「0.6–1.5%」 「+15%」. 「x」 → 「×」.
- 따옴표: 곧은 `"` (`\"` 로 이미 다수). `LocTable.cs:917 · 1812` 의 「“ ”」 두 곳은 그대로 두어도 되지만 새로 쓸 때는 `"`.
- 고유 용어 대문자(3-8).

### 5-3. 일본어
- 설명 · 툴팁 · 안내: **です・ます体** + 「。」. 도감 적 설명(`LocTable.cs:640~663` 「突っ込んでくる。」 등 普通体)은 「突っ込んできます。」 로.
- 이름 · 버튼 · 라벨: 体言止め, 「。」 없음.
- 큰 알림 첫 줄 · 서사 · 보스 대사: 지금 문체 그대로(「倒した！」 「……」).
- 가운뎃점은 **「・」**(전각, 공백 없음). 「 · 」 44건 → 「・」. 괄호는 전각 「（ ）」, 느낌표 · 물음표 전각 「！ ？」, 콜론 전각 「：」. 숫자 · % · 단위는 반각 「35%」 「2秒」.
- 「体力」(HP 아님) · 「英雄」 · 「章」 · 「必殺技」 · 「リッチ王」 · 「イージー/ノーマル/ハード」 · 「エンドレス」 · 「魂のかけら」 · 「魂のツリー」.
- 줄임표 「……」.

### 5-4. 중국어(간체)
- 설명 · 툴팁: 완결 문장 + 「。」(句号). 쉼표 「，」, 느낌표 「！」, 물음표 「？」, 콜론 「：」, 괄호 「（ ）」. 숫자 · % 반각.
- 이름 · 버튼 · 라벨: 「。」 없음.
- 가운뎃점은 **「 · 」**(반각 가운뎃점 + 양쪽 공백, 327건 다수). 「・」 8건 → 「 · 」. 나열 「、」 52건은 문장 속 나열이라 허용.
- 「生命」(HP · 体力 아님) · 「英雄」 · 「第N章」 · 「首领」(보스) · 「中头目」(중간 보스) · 「精英」(엘리트) · 「必杀技」 · 「无尽模式」 · 「灵魂碎片」 · 「灵魂树」.
- 이름 인용 「」 (지금 다수) · 사람 말 “ ”.

## 7. 바꾸면 안 되는 것 · 검사

### 7-1. 금지
- **키 문자열**(`{ "…"` 의 왼쪽, `A/C("…", ` 의 첫 인자, `Loc.T("…")` 안의 글자). 한 글자라도 바꾸면 번역이 끊기거나(C/A 는 조용히 새 키가 되어 옛 키가 죽음) `LocTable.cs` 안에서는 중복으로 **게임이 켜지지 않는다**.
- 자리표시자 `{0}` `{1}` `{INTERACT}` `{ULT}` `{ATTACK}` `{RELOAD}` `{MOVE}` `{UPGRADE}` `{REROLL}` `{RELIC}` `{SKILL1}~{SKILL3}` — 개수 · 이름 · 중괄호 그대로. 서식 `<color=#F5D478>` `</color>` `<size>` `\n` 그대로. 조각 끝의 공백(「보유 포인트: 」 「상점  」) 그대로.
- 일부러 비운 `""` 번역(영어 단위) — 채우지 않는다.
- 고유명사: Soul Saver · Gun Saver · Unity · Steam/스팀 · Noto · 영웅 · 보스 · 스킬 · 유물 · 각인 이름(뜻을 바꾸지 않음. 네 언어 이름이 이미 쓰이는 곳—도감 · 업적—과 맞아야 함).
- `docs/patch-notes/**` · `Assets/Resources/PatchNotes*.txt` · 스팀 공지 · `README` · 코드 주석.
- `L` → `E` 로 바꿀 때 **en · ja · zh 인자 순서**를 그대로 옮긴다(E 는 ko 가 맨 앞).
- 코드(.cs 로직 · 글칸 크기 · 씬 · 프리팹)는 이 작업에서 고치지 않는다. 필요하면 H 에게 메모.
