# 범위표시 영웅별 개편 기획 (2026-10-22)

사용자 요청
- 「필살기 범위 표시」 = **범위표시**. 영웅끼리 너무 비슷함 → 영웅마다 상징이 보이게 (예: 검사는 원 주변을 검이 돎)
- 유령: 스킬 사용 중인지, 끝났는지(나온 건지) 모르겠음 → 확실하게
- 지도 제작자: 범위표시가 그냥 선 → 바꿈
- 조건 (지난 지시): 범위표시는 **무조건 맨 위**에 그림 · 판정 크기는 그대로 · 도트(캐릭터와 같은 칸 크기 1/7 유닛)

## 1. 공통 구조

### 1-1. 영웅별 고리 문양 (PixelRingArt)
- `PixelRingArt.Get(radius, charge, plain, style)` — style = 영웅(CharacterId) 또는 기본(적 · 공용). 캐시 키에 style 추가
- 바깥 테 · 차오름 · 외곽 · 안쪽 디더 는 공통, **룬 점 · 네 방향 마름모 자리를 영웅 문양**으로:

| 영웅 | 테 문양 (그림에 구움) |
|---|---|
| 기본(적 · 공용) | 지금 그대로 (룬 점 · 마름모) |
| 거너 | 조준경: 네 방향 긴 십자 눈금 + 테 사이 탄환 점(2칸 세로) |
| 검사 | 테 사이 짧은 칼날 빗금(사선 3칸) · 네 방향 칼끝 삼각 |
| 도적 | 바깥 테에 가시(바깥으로 2칸 톱니 16개) · 단검 점 |
| 궁수 | 테 사이 깃 모양 갈매기(∧) 표시 · 네 방향 화살촉 |
| 연금술사 | 테 사이 거품 동그라미(3칸 고리) · 마름모 대신 작은 플라스크 점 |
| 지도 제작자 | 나침반: 북쪽 긴 바늘 · 동서남 짧은 바늘 · 테 사이 점선 위도선 |
| 시계공 | 문자판: 12 시 눈금(3·6·9·12 는 길게) |
| 우체부 | 우표 톱니(바깥 테 가장자리 톱니 구멍) · 소인 점선 |
| 유령 | 일렁이는 혼불 꼬리(바깥으로 1~3칸 흐늘거리는 털, 높이 고르지 않게) |

- 어떤 고리가 어느 영웅 것인지: PixelStrokeMin 의 Hero 목록 이름이면 `CharacterKit.Instance.Id` (영웅 판이 아니면 기본). 적 · 상점 · 줍기 고리는 기본/단정한 테 그대로

### 1-2. 움직이는 상징 장식 (새 HeroAimDecor)
- 범위표시 고리 · 선 위에 **영웅 무기 · 상징 스프라이트(Resources/Weapons, FX)** 를 띄워 움직임 — 그림 문양만으로는 정지 화면이라 차이가 약함
- PixelStrokeMin 이 영웅 고리 · 선을 그릴 때 HeroAimDecor 에 (모양, 중심, 반지름 / 시작 · 끝, 색, 차오름) 을 넘김 → 장식은 같은 맨 위 층 · Overlay 큐 · 카메라 앞
- 장식 스프라이트는 점 필터 · 도트 크기 유지 (무기 그림 PPU 그대로, 크기 배율은 정수 배 우선)
- 선이 꺼지면(조준 끝) 장식도 즉시 숨김 · 오브젝트 파괴 시 같이 파괴 (끊김 상태 남지 않게)

| 영웅 | 우클릭 · 현재 표시 | 움직이는 장식 |
|---|---|---|
| 거너 | 일제 사격: 표적 마크만 (범위 원 없음) | 사거리 8 고리(거너 문양)를 새로 그림 + 고리 위를 탄피 4개가 돎. 표적 지정 수 = 고리 바깥 탄환 점 채움 |
| 검사 | 회전 베기 모으기 · 내 둘레 원 | **검 6자루가 고리 위를 돎**, 모을수록 빨라지고 다 차면 칼끝이 바깥을 향해 번쩍 |
| 도적 | 출혈 돌진 · 직선 + 끝 원 | 직선 위를 **표창이 시작 → 끝으로 흘러감**(3개, 회전) · 끝 고리 가운데 표창이 돎 |
| 궁수 | 화살비 · 마우스 원 | **고리 안으로 화살이 위에서 떨어져 꽂힘**(3~5개 차례로) · 가운데 조준점 |
| 연금술사 | 대폭발 모으기 · 마우스 원(커짐) | **고리 안에서 거품이 보글보글 올라옴** + 플라스크 3개가 고리 위를 흔들리며 돎 |
| 지도 제작자 | 지도 접기 · 직선 3개 | 아래 2 참고 (양피지 지도) |
| 시계공 | 되감기 · 경로 + 과거 자리 원 | 과거 자리 고리 = 문자판, **가운데 시곗바늘 2개가 거꾸로 돎** · 경로 위를 톱니 2개가 굴러감(과거 쪽으로) |
| 우체부 | 속달 · 내 둘레 큰 원(15) | **편지 6장이 고리 위를 날아다님**(살짝 위아래 흔들림) |
| 유령 | 빙의 조준 · 표적 원 + 폭발 범위 원 | 표적 고리 둘레에 **혼불 3개가 돎** + 표적 머리 위 해골 표식(fx_markskull) |

### 1-3. 원이 아닌 영웅 선
- 도적 직선 · 시계공 경로 · 지도 제작자 선: 선은 그대로(도트 획 · 맨 위), 장식만 위에 얹음

## 2. 지도 제작자 — 양피지 지도
- 지금: 접힘선 1 + 양옆 가장자리 선 2 (직선 3개)
- 바꿈: **접힐 영역(직사각형, 판정과 같은 크기 len × 2·half)을 양피지 지도 그림으로 깔고**
  - 양피지 타일(코드로 만든 도트 16×16: 바탕 · 얼룩 · 격자 · 테두리), SpriteRenderer Tiled, 영역 회전 = 접힘선 방향
  - 테두리: 바깥 가장자리 2줄은 지금 선 그대로(도트 획) → 지도 테두리 역할
  - 접힘선: 점선(PixelLine.Dash) 잉크 선으로 바꿈 + 접힘선 가운데 나침반 문양 고리(작은 반지름 0.9)
  - 양쪽 반에서 접힘선 쪽을 가리키는 **화살표(▶◀) 3쌍이 접힘선으로 흘러들어감** → 「이쪽이 접혀 들어온다」
  - 다 차면 양피지 테두리 금빛 깜빡임 (지금 금빛 깜빡과 같음)
- 판정 · 길이 · 폭 계산은 그대로 (FoldGeometry 결과를 그림에 그대로 씀)

## 3. 유령 — 빙의 중 / 끝 확실하게
원인 (조사)
1. 빙의 중 몸 흐림(0.12)이 PlayerController.LateUpdate 가 매 프레임 덮어써 **한 번도 안 보였음** → `player.bodyAlpha` 로
2. 빙의 중 무적 때문에 피격 무적과 똑같이 깜빡임 → 빙의 중에는 깜빡임 대신 흐린 몸
3. 빙의 중 UI · 남은 시간 없음, `UltEngaged` 에 빙의 빠짐
4. 쓰러짐으로 끝나면 possessUntil 이 남아 최대 1.5초 우클릭 막힘

바꿈
- **빙의 중 (확실히 「들어가 있음」)**
  - 내 몸: 투명도 0.25 + 푸른 빛(Chill) · 깜빡임 없음 (bodyAlpha · 빙의 중엔 무적 깜빡임 끔)
  - 숙주(적): 유령 문양 고리(반지름 = 몸 크기 + 0.6) 가 붙어 따라다님 · **바깥 테가 남은 빙의 시간만큼 줄어듦**(차오름 표시 거꾸로 = 남은 시간 타이머)
  - 숙주 머리 위 해골 표식 + 혼불 3개가 숙주 둘레를 돎
  - 내 몸과 숙주 사이 영혼 사슬 점선(맨 위, 흐르는 점선)
- **끝 (확실히 「나왔음」)**
  - 숙주 고리가 터지듯 커지며 사라짐(0.25초) · 내 몸 투명도 1 로 돌아오며 흰 번쩍(0.15초) · 짧은 「빠져나옴」 소리(기존 whoosh 높은 음)
  - 머리 위 글자 「빙의 해제」 0.8초 (4개 언어)
- **이어진 빙의(사령술 극의)**: 다음 숙주로 고리 · 사슬이 옮겨감 (끝 번쩍은 마지막에만)
- 쓰러짐 · 일찍 끝남: finally 에서 possessUntil = 0 · bodyAlpha 복원 · 장식 정리 (남는 상태 없게)
- `UltEngaged` 에 possessing 포함

## 4. 맨 위 · 판정 · 안전
- 모든 장식 · 고리 · 양피지: 가장 위 정렬 층 · Overlay 큐 · 카메라 앞 (지난 수정과 같은 방식)
- 판정 · 반지름 · 길이 계산은 손대지 않음 — 그림은 판정 값을 읽어 그리기만
- 장식은 선/고리가 꺼지면 같은 프레임에 숨김, 부모(선 오브젝트) 파괴 시 함께 파괴, Instantiate 로 자기 복제 없음 (new GameObject + AddComponent)
- 일시정지(timeScale 0) 중에도 표시는 멈춰 보임 (unscaled 시간 쓰지 않음)
- 성능: 장식 스프라이트 수 영웅당 최대 ~12, 범위표시는 한 번에 하나라 부담 없음 · 양피지 타일은 한 번 만들어 재사용

## 5. 하지 않는 것
- 적 예고 · 줍기 범위 등 영웅 것이 아닌 고리는 이번에 손대지 않음 (기본 문양 그대로)
- 진화 무기 덧붙는 궁극기(UltAimRing/Line 공유)는 해당 영웅 문양을 그대로 따름
