# 체력바 타격감 — 플레이어 · 보스 · 적 공통 (기획서)

- 날짜: 2026-10-16
- 요청: 「내 캐릭터의 체력바도 그런식으로 줄어들게 해. 큰 데미지(누적 포함)일수록 체력바가 흔들리는 효과 등 강조효과를 넣고, 데미지 누적기준 시간을 좀 늘리자」 + 「보스의 체력바랑 적들 체력바도 똑같이해」
- 「그런식으로」 = 참고 영상(젬소켓 타격감 체력바): 앞 막대는 맞는 순간 실제 체력까지 바로 줄고, 잃은 양은 뒤에 주황 조각으로 잠깐 남았다가 따라 내려옴. 깎인 양 숫자는 큰 타격일수록 크게. 번쩍임 · 흔들림은 큰 한 방에만 아껴 씀.
- 「데미지 누적 기준 시간」 = **피해 숫자 합산 창**(짧은 사이 들어온 피해를 숫자 하나로 합치는 시간). 사용자 확인 완료.
- 이 문서는 기획만. 코드는 고치지 않았다. 구현자가 그대로 따라 할 수 있게 파일 · 클래스 · 메서드 · 상수까지 적는다.

### 1-2. 플레이어 피해 처리 경로 (`PlayerController.cs`)

- 입구 `TryHit(float amount, from)` 1285행: 무적(`IsInvincible`, `hurtInvincibleTime` 0.6초) → 영혼 트리 보호막 `special.ConsumeBarrier()`(0.3초 무적) → 초월 「영혼 보호막」 `TranscendRules.WardBlocks()`(0.5초) → 도적 회피 `special.KitDodge()` → 피격 소리 → `taken = amount × GameMode.DamageMul × Chapters.HurtMul × (1 − def ≤ 0.7)` × `CharacterKit.TakenMul` → `special.AdjustTaken` → `SignatureSkills.Taken` → 보스전 한 방 상한 `PlayerMaxHealth × BossHitShare(0.4)` → `taken ≤ 0` 이면 끝.
- 최후의 보루 `LastStand.Ready` 면 체력 1 남기고 → 불사의 맹세 `special.TryUndying()` 이면 `PlayerHealth = UndyingReviveHealth`, 3초 무적, `DamageFlash.Show(1)` 후 **return (피해 숫자 · 흔들림 없음)**.
- 그 뒤 `RunStats.Hurt` → `PlayerHealth -= taken` → `HurtCount++` → `ShowHurt(taken)` → `special.OnPlayerHurt()` → `SignatureSkills.Hurt` → `LastStand.Check` → 0 이하면 `DeathSequence()`.
- `ShowHurt(taken)` 1267행: `DamageFlash.Show(0.45 + taken / max × 2.5)`(화면 가장자리 붉은 비네트) · `SharedFx.Shake(0.2 + min(0.3, taken/60), 0.15)`(카메라) · 받은 피해 숫자 `SharedFx.FloatText(pos, "-N", 빨강(1, 0.3, 0.28), size 5, throttle 0)`.
- 회복: `PlayerHealth = Mathf.Min(max, hp + x)` 를 **여러 파일이 직접 대입**한다(`regenPerSecond` 309행 · `HealOnKill` 1147행 · `HPpack` · `Shop.Potions` · `LevelShop` · `ChestRewards` · `MapProps` 고기 · `SignatureSkills` 심장 · `CharacterKit`/시계장이 되감기 · `SpecialAbilities.Evolution` 등). 체력 감소도 `TryHit` 밖에서 일어나는 곳이 있다: `CharacterKit.Rules.cs` 82행(최대 체력 8% 자가 소모) · 시계장이 되감기(과거 체력으로 되돌림 — 올라갈 수도 내려갈 수도).
- 최대 체력 변화: `PlayerMaxHealth` 를 카드 · 성장 · 물약이 직접 바꿈(`SpecialAbilities.Evolution.cs` 641행 `PlayerHealth += add` 등).
- 부활: 불사의 맹세(위) · 최후의 보루(체력 1 로 버팀, `LastStand.Check` 가 2초 무적). 씬 시작: `PlayerController.Start` 243행 `PlayerHealth = PlayerMaxHealth`, 이어하기 `RunSave` 373행이 체력 복원(HUD 첫 프레임 전).
- 사망: `DeathSequence` — `Time.timeScale` 0.25 → 0.05 로 1.1초 느려짐 (HUD 애니메이션은 실제 시간으로 돌아야 함).

## 2. 설계

### 2-0. 한눈에

```
피해 발생 (TryHit / bosss.TakeDamage / EnermyController.TakeDamage)
   │ amount, maxHp
   ▼
HealthBarFeel.OnDamaged(amount, maxHp, Time.time)   ← 공용 (새 파일, MonoBehaviour 아님)
   │ 누적 창(마지막 피해 후 Window 안이면 합산) → 누적 / maxHp → 등급 0~3
   │ 조각(ghostHp) 은 맞기 직전 체력에 머무름 · 홀드 시각 갱신 · 등급별 흔들림 · 번쩍임 예약 (상한 · 빈도 제한)
   ▼ 등급 반환
피해 숫자 (DamagePopup.Show / 새 ShowHurt) : 같은 Window 로 합산 · 등급별 크기 · 색
체력바 (PlayerHP / bossbar / EnemyHealthBar) : 매 프레임 Feel.Tick(hp, maxHp, unscaledDt, out Frame) → 앞 막대 · 조각 · 흔들림 오프셋 · 번쩍임 알파 그리기
```

### 2-1. 공용 로직 — `Assets/Scripts/HealthBarFeel.cs` (새 파일)

```csharp
// 체력바 타격감 공용: 두 겹 막대(잃은 양 조각) · 피해 누적 등급 · 흔들림 · 번쩍임 시간표
// 플레이어 HUD(PlayerHP) · 보스 HUD(bossbar) · 적 머리 위(EnemyHealthBar) 가 하나씩 들고 씀. MonoBehaviour 아님 · Tick 에 할당 없음
public sealed class HealthBarFeel
{
    public enum Kind { Player, Boss, Enemy }
    public enum Tier { Small = 0, Medium = 1, Big = 2, Deadly = 3 }

    // ---- 누적 창 (피해 숫자 합산과 같은 값 · DamagePopup 이 이 상수를 읽음)
    public const float WindowPlayer = 1.0f;   // 새로 (지금 없음 · FloatText 는 합산 없음) · 맞은 뒤 무적(0.6 + 재정비 최대 0.3 = 0.9초)보다 길게
    public const float WindowBoss   = 0.6f;   // DamagePopup.BossMerge 0.35 → 0.6
    public const float WindowEnemy  = 0.4f;   // DamagePopup.Merge     0.15 → 0.4
    public const float WindowMax    = 1.5f;   // 첫 피해부터 이 시간이 지나면 창을 새로 시작 (도트 · 접촉 피해가 영원히 쌓여 치명이 되지 않게)

    // ---- 등급 문턱 (누적 피해 / 최대 체력) : [Medium, Big, Deadly]
    static readonly float[] TierPlayer = { 0.05f, 0.15f, 0.30f };   // 기본 체력 100: 5 · 15 · 30 (보스 접촉 25 = Big · 보스 상한 40 = Deadly)
    static readonly float[] TierBoss   = { 0.02f, 0.06f, 0.12f };   // 보스는 체력이 커서 낮게 (필살기 · 진화 폭발이 Big~Deadly)
    static readonly float[] TierEnemy  = { 0.15f, 0.35f, 0.60f };   // 잡몹은 한 방이 크므로 높게 · 쓰러지는 피해는 등급 매기지 않음 (바가 꺼짐)

    // ---- 조각
    public const float GhostHold = 0.30f;         // 마지막 피해 후 머무는 시간 (Deadly 는 0.45)
    public const float GhostHoldDeadly = 0.45f;
    public const float GhostFallRate = 8f;        // 1초에 남은 간격의 8배 속도 (지수 감쇠 · 큰 조각은 빨리, 끝은 부드럽게)
    public const float GhostFallMin = 1.5f;       // 최소 속도: 최대 체력의 150%/초 (아무리 작아도 0.2초 안에 붙음)

    // ---- 흔들림 (등급별 · Small/Medium 0) : 진폭은 「막대 높이 대비 비율」 → 그리는 쪽이 자기 단위로 환산 (HUD 는 px, 적 바는 월드)
    static readonly float[] ShakeAmp  = { 0f, 0f, 0.25f, 0.5f };    // Big: 막대 높이 25% (HUD 20px 바 → 5px · 적 0.26 → 0.065) · Deadly 50%
    static readonly float[] ShakeTime = { 0f, 0f, 0.18f, 0.30f };
    public const float ShakeHz = 34f;             // 감쇠 사인 (sin(2π·Hz·t) · 두 축 위상 다르게) — Random 안 씀 (할당 · 지터 없음)
    public const int EnemyShakeMax = 4;           // 잡몹 바가 한 화면에서 동시에 흔들리는 상한 (보스 · 플레이어는 제한 없음)

    // ---- 번쩍임 (등급별 · 막대 채움을 흰색으로 섞는 세기) · 빈도 제한
    static readonly float[] FlashAmp  = { 0f, 0.35f, 0.7f, 1f };    // Medium 살짝, Big 또렷, Deadly 완전 흰색 + 배경까지
    public const float FlashTime = 0.09f;         // 흰색 → 원래 색으로 돌아오는 시간
    public const float FlashGap  = 0.34f;         // 한 막대 1초 3회 이하

    public readonly Kind kind;
    public HealthBarFeel(Kind kind) { this.kind = kind; }

    // 상태 (전부 값 타입)
    float ghostHp = -1f;          // 조각 윗끝 (체력 단위로 저장 — 최대 체력이 바뀌어도 비율 재계산이 맞음)
    float holdUntil;              // 이 시각까지 조각이 머무름 (Time.unscaledTime)
    float accum, accumFirst, accumLast;   // 누적 피해 · 창 시작 · 마지막 피해 (Time.time)
    float shakeAmp, shakeT, shakeLen;     // 지금 흔들림 (막대 높이 비율 · 경과 · 길이)
    float flashAmp, flashT, nextFlashAt;  // 지금 번쩍임
    bool shaking;                 // 상한 집계용
    static int enemyShaking;      // 지금 흔들리는 잡몹 바 수

    public bool Active => ghostHp > 0f && (holdUntil > 0f || shakeT < shakeLen || flashT < FlashTime);   // 그리는 쪽이 「변화 없음 → 갱신 생략」 판단에 씀

    public float Window => kind == Kind.Player ? WindowPlayer : kind == Kind.Boss ? WindowBoss : WindowEnemy;
    float[] Thresholds => kind == Kind.Player ? TierPlayer : kind == Kind.Boss ? TierBoss : TierEnemy;

    // 씬 시작 · 풀에서 다시 꺼냄 · 부활 · 이어하기: 조각을 지금 체력에 붙임 · 효과 모두 끔
    public void Reset(float hp)
    {
        ghostHp = Mathf.Max(0f, hp);
        holdUntil = 0f; accum = 0f; accumFirst = accumLast = -99f;
        if (shaking && kind == Kind.Enemy) enemyShaking--;
        shaking = false; shakeT = shakeLen = 0f; flashT = FlashTime; flashAmp = 0f;
    }
    public void Cancel() => Reset(ghostHp);     // 오브젝트가 꺼질 때 (OnDisable) 상한 집계에서 빠지게

    // 피해 한 번. hpBefore: 깎기 전 체력 · visible: 화면에 보이는가 (false 면 조각만 두고 흔들림 · 번쩍임은 예약 안 함)
    // 반환: 이번 누적의 등급 (피해 숫자 크기 · 비네트 세기에 쓰라고)
    public Tier OnDamaged(float amount, float hpBefore, float maxHp, bool visible = true)
    {
        float now = Time.time;
        if (now - accumLast > Window || now - accumFirst > WindowMax) { accum = 0f; accumFirst = now; }
        accum += amount; accumLast = now;
        float[] th = Thresholds;
        float r = maxHp > 0f ? accum / maxHp : 1f;
        Tier tier = r >= th[2] ? Tier.Deadly : r >= th[1] ? Tier.Big : r >= th[0] ? Tier.Medium : Tier.Small;

        // 조각: 맞기 직전 체력 자리에 (떨어지던 중이면 그 자리에서 다시 멈춤) · 다시 기다림
        ghostHp = Mathf.Max(ghostHp < 0f ? hpBefore : ghostHp, hpBefore);
        holdUntil = Time.unscaledTime + (tier == Tier.Deadly ? GhostHoldDeadly : GhostHold);

        if (!visible || hpBefore - amount <= 0f) return tier;      // 안 보이거나 이 피해로 쓰러짐(바가 꺼짐): 연출 생략

        int t = (int)tier;
        if (ShakeAmp[t] > 0f && GameSettings.ScreenShake)
        {
            if (kind != Kind.Enemy || shaking || enemyShaking < EnemyShakeMax)
            {
                if (!shaking && kind == Kind.Enemy) enemyShaking++;
                shaking = true;
                shakeAmp = Mathf.Max(shakeAmp * (1f - shakeT / Mathf.Max(0.01f, shakeLen)), ShakeAmp[t]);  // 더 센 것만 덮어씀
                shakeT = 0f; shakeLen = ShakeTime[t];
            }
        }
        if (FlashAmp[t] > 0f && GameSettings.Flashes && Time.unscaledTime >= nextFlashAt)
        {
            nextFlashAt = Time.unscaledTime + FlashGap;
            flashAmp = FlashAmp[t]; flashT = 0f;
        }
        return tier;
    }

    public struct Frame
    {
        public float front;      // 앞 막대 비율 0~1
        public float ghost;      // 조각 윗끝 비율 (front 와 같으면 조각 숨김)
        public bool ghostShown;
        public float shakeX, shakeY;   // 막대 높이 대비 비율 (그리는 쪽이 × 높이)
        public float flash;      // 0~1 채움 색에 섞을 흰색
    }

    // 매 프레임. 실제 시간(unscaledDt)으로 — 사망 슬로모션 · 멈춤 중에도 자연스럽게 (DamageFlash 와 같은 원칙)
    public void Tick(float hp, float maxHp, float unscaledDt, out Frame f)
    {
        hp = Mathf.Max(0f, hp);
        if (ghostHp < 0f) ghostHp = hp;                       // 첫 프레임 동기화
        if (ghostHp > maxHp) ghostHp = maxHp;                 // 최대 체력이 줄었을 때
        if (hp >= ghostHp) { ghostHp = hp; holdUntil = 0f; }  // 회복 · 부활 · 최대 체력 증가: 조각 없이 즉시 (회복 조각은 두지 않음 — 2-2 참고)
        else if (Time.unscaledTime >= holdUntil)
        {
            float gap = ghostHp - hp;
            ghostHp = Mathf.MoveTowards(ghostHp, hp, Mathf.Max(gap * GhostFallRate, maxHp * GhostFallMin) * unscaledDt);
            if (ghostHp <= hp + 0.001f) { ghostHp = hp; holdUntil = 0f; }
        }
        f.front = maxHp > 0f ? Mathf.Clamp01(hp / maxHp) : 0f;
        f.ghost = maxHp > 0f ? Mathf.Clamp01(ghostHp / maxHp) : 0f;
        f.ghostShown = f.ghost > f.front + 0.002f;

        f.shakeX = f.shakeY = 0f;
        if (shakeT < shakeLen)
        {
            shakeT += unscaledDt;
            float k = 1f - Mathf.Clamp01(shakeT / shakeLen);
            float w = shakeT * ShakeHz * 6.2832f;
            f.shakeX = Mathf.Sin(w) * shakeAmp * k;
            f.shakeY = Mathf.Sin(w * 0.77f + 1.3f) * shakeAmp * k * 0.6f;
            if (shakeT >= shakeLen && shaking) { shaking = false; if (kind == Kind.Enemy) enemyShaking--; }
        }
        f.flash = 0f;
        if (flashT < FlashTime) { flashT += unscaledDt; f.flash = flashAmp * (1f - Mathf.Clamp01(flashT / FlashTime)); }
    }

    // 조각 색 (색약 모드면 흰빛 — 주황이 빨강 · 초록 막대와 섞여 안 보이지 않게)
    public static Color GhostColor(float flash) => GameSettings.ColorBlind
        ? new Color(0.96f, 0.96f, 0.9f, 0.95f)
        : Color.Lerp(new Color(1f, 0.62f, 0.22f, 0.95f), new Color(1f, 0.92f, 0.8f, 1f), flash);

    // 등급 → 피해 숫자 크기 배율 (DamagePopup 이 씀)
    public static readonly float[] PopupScale = { 1f, 1.2f, 1.55f, 2f };
}
```

규칙 정리 (위 코드가 곧 규칙):

- **두 겹 막대**: 앞 막대는 늘 실제 체력. 조각(ghost)은 체력 단위로 저장해 **맞기 직전 체력**에 서고, 마지막 피해 후 `GhostHold 0.3초`(치명 0.45초) 머문 뒤 **지수 감쇠**(남은 간격 × 8/초, 최소 최대체력 150%/초)로 따라 내려온다 → 큰 조각은 처음에 빠르게, 끝은 부드럽게, 작은 조각도 0.2초 안에 닫힘.
- **연속 피해**: 매 피해마다 조각은 `max(지금 조각, 맞기 직전 체력)` 에 머물고 홀드가 다시 시작된다(떨어지던 중이면 그 자리에서 멈춰 다시 기다림). 즉 연타 동안 조각은 「연타가 시작된 체력」을 계속 보여주고, 연타가 끝난 0.3초 뒤 한 번에 내려온다 — 누적량이 눈에 보이는 핵심.
- **회복**: 앞 막대가 올라가 조각에 닿거나 넘으면 조각은 즉시 앞 막대에 붙는다. 회복 조각(초록 조각이 먼저 올라가는 식)은 **두지 않는다** — 이 게임 회복은 초당 재생 · 처치 회복 · 시계장이 되감기처럼 잦고 잔잔해 조각이 계속 깜빡이게 되고, 참고 영상도 없다. 회복 숫자는 기존 그대로(`FloatText "+N"` 등).
- **최대 체력 변화**: 조각이 체력 단위라 비율이 저절로 맞고, 최대가 줄면 조각을 최대로 잘라낸다. **부활**(불사의 맹세 · 최후의 보루): 체력이 올라가는 길이라 즉시 동기화. **씬 시작 · 이어하기 · 풀 재사용**: `Reset(hp)`.
- **누적 창**: 마지막 피해 후 `Window` 안이면 합산, 첫 피해로부터 `WindowMax 1.5초` 지나면 새 창. 등급은 **누적 / 최대 체력**. 피해 숫자도 같은 `Window` 상수를 써서 「숫자에 보이는 수」 = 「등급을 매긴 수」.
- **Small 은 거의 아무것도 안 함**: 조각 + 평소 크기 숫자만. Medium: 막대에 살짝 흰 기운(0.35). Big: 흔들림(막대 높이 25% · 0.18초) + 흰 번쩍임 0.7. Deadly: 흔들림 50% · 0.3초 + 완전 흰 번쩍임 + 배경까지 + 조각 더 오래 + 숫자 2배.
- **접근성**: 흔들림은 `GameSettings.ScreenShake`, 막대 번쩍임은 `GameSettings.Flashes` 를 따른다(둘 다 끄면 조각 · 숫자 크기 · 비네트(원래 Flashes 따름)만 남음). **번쩍임 빈도** 막대당 `FlashGap 0.34초` → 1초 3회 이하. 화면 비네트는 기존 `DamageFlash`(Max 합성 · 2.2/초 감쇠)라 플레이어 무적 0.6초와 합쳐 1초 2회 미만.
- **잡몹 상한**: 동시에 흔들리는 적 바 ≤ `EnemyShakeMax 4`. 화면 밖(`SpriteRenderer.isVisible == false`) · 쓰러지는 피해 · 바가 꺼진 상태는 흔들림 · 번쩍임 예약 자체를 안 함(조각 위치만 기록).
- **성능**: 클래스 하나를 바마다 1회 할당, `Tick` 은 `out struct` 로 반환 · 문자열 · 배열 · 코루틴 없음 · `Random` 없음. 그리는 쪽은 `front/ghost/shake/flash` 가 지난 프레임과 같으면 갱신 생략(아래).

**`EnemyHealthBar`**

```csharp
SpriteRenderer ghostRenderer; Transform ghost;      // 처음 피해 때 만들고(보이는 적만) 조각이 없을 땐 꺼 둠

public HealthBarFeel.Tier OnDamaged(float amount, float before)
    => feel.OnDamaged(amount, before, enemy.setEnemyHP, fillRenderer.enabled && fillRenderer.isVisible);
public void ResetFeel(float hp) { feel.Reset(hp); shownRatio = -1f; }
void OnDisable() => feel.Cancel();

void Build() { ... rest = transform.localPosition; fillRenderer.sortingOrder = 2; }   // Back 0 · Ghost 1 · Fill 2

void LateUpdate()
{
    if (enemy == null) return;
    float hp = enemy.EnemyHealth, max = enemy.setEnemyHP;
    float ratio = max > 0 ? Mathf.Clamp01(hp / max) : 0f;
    if (ratio == shownRatio && !feel.Active) return;        // 변화 없고 효과도 없으면 지금처럼 생략 (수백 마리 대부분이 여기서 끝)
    feel.Tick(hp, max, Time.unscaledDeltaTime, out HealthBarFeel.Frame f);

    bool alive = ratio > 0f;
    if (ratio != shownRatio)
    {
        shownRatio = ratio;
        backRenderer.enabled = fillRenderer.enabled = alive;
        if (alive) { fill.localScale = new Vector3(Width * ratio, Height, 1f); fillColor = /* 기존 색 계산 */; }
    }
    if (!alive) { if (ghostRenderer != null) ghostRenderer.enabled = false; return; }

    if (f.ghost != shownGhost)
    {
        shownGhost = f.ghost;
        if (f.ghostShown && ghostRenderer == null) { ghostRenderer = MakePart("Ghost", HealthBarFeel.GhostColor(0f), 1, -Width / 2f, Width, Height); ghost = ghostRenderer.transform; }
        if (ghostRenderer != null) { ghostRenderer.enabled = f.ghostShown; if (f.ghostShown) ghost.localScale = new Vector3(Width * f.ghost, Height, 1f); }
    }
    transform.localPosition = rest + new Vector3(f.shakeX * transform.localScale.x, f.shakeY * transform.localScale.y, 0f) * Height;      // Big 0.065 · Deadly 0.13 (월드 단위 · 머리 위에서 살짝)
    fillRenderer.color = f.flash > 0f ? Color.Lerp(fillColor, Color.white, f.flash) : fillColor;
    if (ghostRenderer != null && ghostRenderer.enabled) ghostRenderer.color = HealthBarFeel.GhostColor(f.flash);
}
```
- `Ghost` 스프라이트는 **처음 조각이 필요할 때만** 만들고(안 보이는 적은 `visible:false` 라도 조각은 기록되지만 렌더러는 `LateUpdate` 때 만들어짐 — 화면 밖 적은 `isVisible` 이 false 여도 LateUpdate 는 돈다. 그래서 `ghostShown && !fillRenderer.isVisible` 이면 렌더러 생성을 미룬다: `if (f.ghostShown && ghostRenderer == null && fillRenderer.isVisible)`), 같은 1×1 스프라이트 · 같은 머티리얼이라 `Back/Fill` 과 함께 배칭됨.
- 잡몹은 한 방이 체력 대부분이라 `TierEnemy {0.15, 0.35, 0.60}` 로 높게 두고, **쓰러지는 피해는 등급 효과 없음**(바가 꺼지며 사망 연출 `Juice.EnemyDied` 가 있음). 실제로 흔들리는 건 「엘리트 · 중간 보스 · 체력 큰 적이 안 죽고 60% 이상 깎였을 때」 정도 → 화면이 시끄럽지 않음. 그래도 광역기 한 번에 수십 마리가 동시에 Big 이 될 수 있어 `EnemyShakeMax 4`.
- `transform.localPosition` 은 부모(적) 스케일만큼 커지므로 흔들림 오프셋에 바 자신의 보정 스케일(`Attach` 의 1/lossyScale)을 곱한다 (중간 보스 ×1.8 이어도 같은 월드 폭).

### 2-5. 피해 숫자 — `DamagePopup.cs` (누적 창 · 등급 크기 · 플레이어 받은 피해도 여기로)

- 상수: `Merge 0.15f` → **삭제, `HealthBarFeel.WindowEnemy`(0.4) 사용** · `BossMerge 0.35f` → **`HealthBarFeel.WindowBoss`(0.6)**. 합칠 때 `t = 0` 으로 수명이 다시 시작하는 지금 방식 유지(창이 길어진 만큼 숫자가 오래 남음 — 의도된 효과).
- 시그니처 `Show(Transform target, float damage, SpriteRenderer body, bool fromBoss = false, HealthBarFeel.Tier tier = HealthBarFeel.Tier.Small)`. `Add(damage, tier)` 에서 `size = Mathf.Max(size, 기존 size × HealthBarFeel.PopupScale[(int)tier])` (등급은 올라만 감 — `tierMax` 필드에 보관) · 합칠 때 튀는 `popAmp` 를 `0.08f` → `0.08f + 0.06f × (int)tier`(Deadly 0.26) · Deadly 는 색을 더 진한 금빛 `(1, 0.7, 0.2)` 로. 보스 치명타 상한 `2.8` 유지(`Mathf.Min`).
- **플레이어 받은 피해** 새 메서드
```csharp
// 플레이어가 받은 피해: 짧은 사이 피해를 한 숫자로 합침 (WindowPlayer) · 빨강 · "-N" · 등급별 크기

```
  `Show` 와 같은 풀 · `byTarget` 을 쓰되 `hurt = true` 플래그: 창 `HealthBarFeel.WindowPlayer`, 글자 `"-" + CeilToInt(amount)`, 색 `(1, 0.3, 0.28)` → Deadly `(1, 0.15, 0.15)`, 크기 `1.3 × PopupScale[tier]`(지금 FloatText size 5 ×1.6 = 8 과 비슷한 체감이 되도록 기본 글꼴 11 기준 1.3 배), 위치 머리 위 `+1.6`(FloatText 의 +3.2 보다 낮게 — 체력바 조각과 눈이 같이 가게), 수명 `Life` 1.0초, 떠오르기 `Rise`, 정렬 50(기존 FloatText 와 같음 · 적 숫자 40/45 위), `GameSettings.DamageNumbers == 2` 면 안 띄움, `== 1` 이면 글꼴 15. 치명타 분기 없음.

- `Add` 의 색 계산이 `Hostile.Player.damage` 를 읽는 부분은 `hurt` 일 때 건너뜀.

### 2-6. 성능 · 안전 요약

- 할당: `HealthBarFeel` 바마다 1회 · `Frame` 은 `out struct` · 문자열은 숫자 바뀔 때만(기존 유지) · 플레이어 피해 숫자는 풀로 전환(개선).
- 매 프레임 비용: 적 바 `LateUpdate` 는 `ratio == shownRatio && !feel.Active` 로 지금처럼 즉시 return. `feel.Active` 는 필드 비교 몇 개.
- `isVisible` 은 Unity 가 컬링 때 갱신하는 bool 이라 공짜. 화면 밖에선 조각 위치만 기록하고 렌더러도 안 만듦.
- 정적 `enemyShaking` 은 `Reset/Cancel/Tick` 세 곳에서만 증감 · `OnDisable → Cancel` 로 꺼진 적이 집계에 남지 않음. 씬 전환 때 `HealthBarFeel.ResetStatics()`(`enemyShaking = 0`) 를 `bossbar.Start` 또는 `PlayerHP.Start` 에서 한 번 호출.
- 시간: 창 판정은 `Time.time`(기존 DamagePopup 과 같음 · 멈춤 중엔 합산 창도 멈춤) · 애니메이션은 `Time.unscaledDeltaTime`(사망 슬로모션 · 멈춤에도 흐름 · `DamageFlash` 와 같은 원칙).
- 에디터 전용 코드 없음. 새 스프라이트는 전부 코드(복제 · 1×1 픽셀)라 에셋 추가 없음. 씬 수정 없음(`HPghost` · `BossGhost` 는 런타임 복제).
- 체험판(Demo)도 같은 코드라 자동 반영 · 빌드 때 `-Demo` 업로드.
