- 대상 파일: `Assets/Scripts/HealthBarFeel.cs`(공용) · `PlayerHP.cs`(플레이어 HUD) · `bossbar.cs`(보스 HUD) · `EnemyHealthBar.cs`(적 머리 위) · 참고 `DamagePopup.cs`(피해 숫자 합산 — 바꾸지 않음)

- 이 문서는 기획만. 코드는 고치지 않았다. 구현자가 그대로 따라 할 수 있게 파일 · 메서드 · 상수 · 공식까지 적는다.
- **패치노트에는 체력바 내용을 넣지 않는다** (사용자 규칙).

### 절대 규칙 (이번 렉의 원인 · 재발 금지)

1. 스크립트가 붙은 오브젝트를 `Instantiate` 로 복제하지 않는다. 필요한 컴포넌트(`Image` · `SpriteRenderer`)만 새로 만든다 — `HealthBarFeel.MakeGhost` · `EnemyHealthBar.MakePart` 방식 유지. 이 기획은 **새 오브젝트를 하나도 추가하지 않는다**(이미 있는 조각 Image/SpriteRenderer 를 흰색으로 쓰고, 강조 연출은 이미 있는 배경 · 루트 트랜스폼의 색 · 위치 · 스케일만 쓴다).
2. 매 프레임 할당 금지 · 새 재질/스프라이트 금지. 상태는 전부 값 타입, `Tick` 은 `out struct`.
3. 적 수백 마리에서 **맞지 않은 적은 비용 0** — `ratio == shownRatio && !feel.Active` 조기 반환 유지.
4. 정적 이벤트 구독은 짝 맞추기 — `PlayerController.Damaged` 는 `OnEnable/OnDisable` 짝(현재 그대로), 새 정적 이벤트 없음.
5. 설정 존중 — 흔들림 · 두께 펀치는 `GameSettings.ScreenShake`, 번쩍임 · 점화 · 테두리 강조는 `GameSettings.Flashes`, 색은 `GameSettings.ColorBlind`. 흰 게이지 자체(정보)는 설정과 무관하게 항상.

## 1. 진단 — 왜 지금은 「의미 없는 수준」인가

### 1-1. 실제 화면 크기 (씬 · 카메라에서 측정)

캔버스 기준 해상도 1920×1080 (Expand) → **1 캔버스 단위 = 1px @1080p**.

| 바 | 실제 구조 · 크기 | 비고 |
|---|---|---|
| 플레이어 | `HPbackground` 456×44 (좌상단 앵커 · (136, −72) · 피벗 (0, 0.5) · 프레임 스프라이트 `ui_bar_frame` = 검보라 바탕 + 금색 테두리 · 틴트 흰색) > `HPgauge` 432×20 at (12, 0) · 빨강 `(0.86, 0.17, 0.24)` · 스프라이트 `ui_bar_fill`(세로 흰→회색 그라데이션) · `HPText` | **`PlayerHP` 는 `HPgauge` 자신에 붙어 있다** (씬: HPgauge 필드 = 자기 오브젝트) |
| 보스 | `BossBarBackground` 620×44 (상단 중앙 · (20, −112) · 피벗 (0.5, 1) · 같은 프레임 스프라이트) > `BossBar` 596×20 at (12, 0) · `(0.72, 0.1, 0.2)` | 코드 주석의 `MaxBarX 1333 · BarY 119` 는 인스펙터 기본값. `Start` 가 씬 크기로 덮어써 **실제 596 × 20** |

### 1-2. 시간 — 조각이 실제로 보이는 시간 (지금 1.2.0 수치: 머무름 0.3초 · 지수 감쇠 간격×8/초 · 최소 최대체력 150%/초)

| 대상 · 피해 | 등급 | 머무름 | 내려오는 시간 | 조각 노출 합계 | 움직임이 보이는 프레임(60fps) |
|---|---|---|---|---|---|
| 플레이어 100 중 5 (접촉) | Small | 0.30 | 5 / 150 = **0.033초** | 0.33초 | **2프레임** |
| 플레이어 25 (보스 접촉) | Big | 0.30 | 0.036 + 18.75/150 = 0.16초 | 0.46초 | 10프레임 |
| 플레이어 40 (보스 상한) | Deadly | 0.45 | 0.095 + 0.125 = 0.22초 | 0.67초 | 13프레임 |
| 보스 3000 중 30 (평타 1%) | Small | 0.30 | 30 / 4500 = **0.007초** | 0.31초 | **1프레임** |
| 보스 300 (10%) | Big | 0.30 | 0.067초 | 0.37초 | 4프레임 |
| 적 50 중 20 (40%) | Big | 0.30 | 0.22초 | 0.52초 | 13프레임 |

- 지수 감쇠는 **큰 조각일수록 처음에 빨리 사라진다**(간격 × 8/초). 「큰 피해를 오래 보여 준다」는 목적과 정반대. 작은 조각은 최소 속도 150%/초에 걸려 1~2 프레임에 닫힌다 → 눈에 안 보인다.
- 머무름 0.3초는 맞은 순간의 흔들림 · 피격 소리와 겹치는 시간이라 「머물렀다」고 인식되기 전에 끝난다. 연속 피해 때 「머무름 다시 시작」 규칙은 있었지만 0.3초라 연타 사이(플레이어 무적 0.6초)를 잇지 못해 **접촉 피해는 한 덩어리로 보인 적이 없다**.

### 1-3. 색 — 주황 조각이 안 보이는 이유

- 조각 `(1, 0.62, 0.22)` vs 적 바 중간 색 `HalfColor (0.98, 0.72, 0.22)` → **거의 같은 색**. 적 체력이 50% 근처면 조각과 채움이 구분되지 않는다. 빨강 `LowColor` · 초록 `FullColor` 옆에서도 「같은 바의 다른 칸」처럼 읽히지 「잃은 양」으로 읽히지 않는다.
- 플레이어 빨강 `(0.86, 0.17, 0.24)` 옆의 주황은 같은 난색이라 경계가 약하다. 흥행 게임이 지연 구간에 **흰색 · 회색 · 노랑처럼 채움과 다른 계열의 밝은 단색**을 쓰는 이유.

### 1-4. 흔들림 · 번쩍임 · 배경 — 수치와 구조 결함

### 1-5. 결론 한 줄

「주황 조각 · 0.3초 · 지수 감쇠 · 작은 흔들림 · 5프레임 번쩍임」 은 각각이 지각 문턱 아래에 있고, 플레이어 바는 흔들림이 어긋남으로 나오며, 보스 바는 계수 오류로 흔들림이 없다. 고칠 것은 **색(흰색) · 시간(머무름 ≥ 0.65초 · 내려옴 ≥ 0.35초 · 연타 연장) · 움직임의 대상(바 전체) · 크기(지각 문턱 위)** 네 가지다.

## 2. 참고 — 흥행 액션 게임의 「지연 게이지」 문법

(수치는 공개된 값이 아니라 플레이 체감 기준의 근사치)

| 게임 | 지연 구간 | 머무름 | 내려옴 | 연타 때 | 추가 강조 |
|---|---|---|---|---|---|
| 격투 게임 (스트리트 파이터 · 철권 · 길티기어) | **흰색 / 밝은 회색** 바가 채움 뒤에 남음 | 콤보가 끝난 뒤 약 0.5~1초 | 일정 속도로 흘러내림 (바 전체 약 1.5~2초) | **콤보 중엔 그대로 멈춰 콤보 총량을 한 덩어리로 보여 줌** — 이 요청의 「연장」 그 자체 | 큰 한 방에 바 번쩍임 · 화면 흔들림 |
| 다크 소울 · 엘든 링 | 노랑 ~ 주황 구간 | 약 1초 | 일정 속도 | 연타 중 유지 | 없음 (단순함이 무게감) |
| 데드 셀 | 주황 ~ 밝은 구간 | 약 0.4~0.6초 | 빠르게 미끄러짐 | 유지 · 연장 | 피격 때 바 흔들림 · 번쩍임, 큰 피해 숫자 |
| 하데스 | 밝은 잔상이 짧게 남고 따라붙음 | 짧음 | 빠름 | 유지 | 피격 때 바와 숫자가 번쩍임 |
| 뱀서류 (Vampire Survivors 등) | 없음 — 즉시 감소, 적 바 없음 | – | – | – | 거의 없음 |

공통 문법 다섯 가지 — 이 기획이 그대로 따르는 것:

1. **채움은 즉시** 줄고, 잃은 구간만 뒤에 남는다 (채움이 느리게 줄면 체력 판단이 늦어진다).
2. 잃은 구간은 **채움과 다른 계열의 밝은 단색**(흰 · 회색 · 노랑). 「잃었다」가 한 가지 색으로 읽힌다.
3. **머무름은 0.5초 이상**, 연타 중엔 **고정**. 연타가 끝난 뒤에야 내려온다 → 연타 총량이 한 덩어리로 보인다.
4. 내려올 땐 **눈이 따라갈 수 있는 속도**(0.3~1초) · 부드러운 시작과 끝. 한 프레임에 사라지는 구간은 정보가 없다.
5. 작은 피해는 게이지만, **큰 피해에만 번쩍임 · 흔들림**을 아껴 쓴다. 그래야 큰 피해가 「큰」 것으로 느껴진다.

이 게임에 맞게 바꿀 점 하나: 뱀서류는 **접촉 피해 · 도트가 끝없이 들어온다**(플레이어 무적 0.6초마다, 보스는 평타 10회/초). 격투 게임의 「콤보가 끝날 때까지 유지」를 그대로 두면 군중 속에선 흰 게이지가 영원히 안 내려온다 → **사슬 상한(ChainCap)** 을 두어 「최근 몇 초 동안 잃은 양」 단위로 끊어 보여 준다.

## 3. 설계

### 3-1. 용어 · 상태 기계

- **채움(front)**: 실제 체력. 늘 즉시.
- **흰 게이지(ghost)**: 잃은 구간의 윗끝(체력 단위 `ghostHp` 로 저장 — 최대 체력이 바뀌어도 비율이 맞음). 채움 바로 뒤에 그려져 「채움 오른쪽 끝 ~ 흰 게이지 끝」만 보인다.
- **사슬(chain)**: 흰 게이지가 열린 뒤 닫힐 때까지의 피해 묶음. 첫 피해 시각이 `chainStart`.
- **자기 시계 `clock`**: `Tick(dt)` 마다 `clock += dt`. 머무름 · 사슬 · 내려옴 · 효과 타이머는 모두 이 시계로. 호출자는 `dt = HealthBarFeel.Dt` 를 넘긴다 (3-7 일시정지 참고).

```
        피해(OnDamaged)                 clock ≥ holdUntil                 u ≥ 1 (또는 회복으로 hp ≥ ghost)
 닫힘 ───────────────▶ 머무름(Hold) ───────────────────▶ 내려옴(Drain) ────────────────────────▶ 닫힘
  ▲                     ▲   │ 피해: holdUntil 다시 (상한 안)  │ 피해(상한 안): 그 자리에서 멈춤 → 머무름으로
  └─────────────────────┘   └───────────────────────────────┘ 피해(상한 뒤): 연장 없이 계속 내려옴
```

### 3-2. 타이밍 수치표

| 상수 | 플레이어 | 보스 | 적 | 근거 |
|---|---|---|---|---|
| `Hold[Small, Medium, Big, Deadly]` | 0.65 / 0.75 / 0.90 / 1.10 | 0.45 / 0.50 / 0.60 / 0.80 | 0.40 / 0.45 / 0.50 / 0.65 | 플레이어 Small 0.65 > 피격 무적 0.6 → 접촉 피해가 한 사슬로 이어짐. 등급이 높을수록 오래 보여 줌 |
| `ChainCap` (첫 피해부터) | 3.0 | 1.5 | 1.2 | 보스 다단 패턴(1~2초)이 한 덩어리 · 군중 속에선 3초 단위로 끊어 보여 줌. 보스는 연사 DPS 를 1.5초 덩어리로 |
| `FullBarTime` (바 전체 길이를 내려오는 데 걸리는 시간) | 1.6 | 1.2 | 1.0 | 격투 게임 체감(1.5~2초) · 보스 · 적은 사건이 잦아 조금 빠르게 |
| `DrainMin` | 0.35 | 0.30 | 0.25 | 아무리 작은 구간도 21 / 18 / 15 프레임은 움직인다 |
| `DrainMax` | 0.80 | 0.70 | 0.50 | 절반 넘게 잃어도 0.8초 안에 닫힘 (다음 사건을 가리지 않게) |
| `DtMax` | 0.1 | 0.1 | 0.1 | 프레임 끊김 뒤 한 번에 건너뛰지 않게 `dt` 상한 |

내려오는 시간 `D = clamp(FullBarTime × (ghostHp − hp) / maxHp, DrainMin, DrainMax)` — **내려오기 시작하는 순간 한 번 계산**(중간에 바뀌지 않음).

예시 (플레이어 최대 100):

| 피해 | 등급 | 머무름 | D | 흰 구간 노출 합계 | 지금(1.2.0) |
|---|---|---|---|---|---|
| 5 | Small | 0.65 | 0.35 | **1.00초** | 0.33 (움직임 2프레임) |
| 10 | Medium | 0.75 | 0.35 | 1.10 | 0.37 |
| 25 | Big | 0.90 | 0.40 | 1.30 | 0.46 |
| 40 | Deadly | 1.10 | 0.64 | 1.74 | 0.67 |
| 보스 3000 중 30 (1%) | Small | 0.45 | 0.30 | 0.75 | 0.31 (1프레임) |
| 보스 300 (10%) | Big | 0.60 | 0.30 | 0.90 | 0.37 |
| 적 50 중 7 (14%) | Small | 0.40 | 0.25 | 0.65 | 0.39 |
| 적 20 (40%) | Big | 0.50 | 0.40 | 0.90 | 0.52 |

피해 숫자 수명과도 맞는다: 플레이어 받은 피해 숫자 `HurtLife 1.0초` ≈ 흰 구간 최소 1.0초, 보스 숫자 1.15초, 적 숫자 0.75초. 숫자가 떠 있는 동안 흰 구간이 같이 보인다.

### 3-3. 내려오는 곡선 — 공식 · 시간표

```
u = (clock − drainStart) / D            // 0 → 1
s = u × u × (3 − 2u)                    // smoothstep · s(0)=0, s(1)=1, 기울기 0 → 최대 1.5 (u=0.5) → 0
ghostHp = lerp(drainFrom, hp, s)        // hp 는 매 프레임 실제 체력 (내려오는 중 회복되면 목표가 올라가 조금 일찍 닿음)
u ≥ 1 → ghostHp = hp, 닫힘
```

왜 smoothstep 인가: 머무름이 끝나고 **천천히 떨어지기 시작**해 「이제 내려간다」가 읽히고, 가운데는 눈이 따라갈 수 있는 속도로 미끄러지고, 끝에서 **부드럽게 채움에 붙는다**(지금의 지수 감쇠는 첫 프레임이 가장 빨라 큰 조각이 「툭」 사라진다). 격투 게임의 등속보다 시작 · 끝이 부드러워 작은 바(20px)에서도 덜컹거리지 않는다.

플레이어 25 피해 (흰 100 → 75, D = 0.40초, 1 체력 = 4.32px):

| 경과 | u | s | ghostHp | 속도 |
|---|---|---|---|---|
| 0.00 | 0 | 0 | 100.0 | 0 |
| 0.05 | 0.125 | 0.043 | 98.9 | 느리게 시작 |
| 0.10 | 0.25 | 0.156 | 96.1 | |
| 0.15 | 0.375 | 0.316 | 92.1 | |
| 0.20 | 0.5 | 0.5 | 87.5 | **최대 94 체력/초 = 405px/초 = 6.8px/프레임** |
| 0.25 | 0.625 | 0.684 | 82.9 | |
| 0.30 | 0.75 | 0.844 | 78.9 | |
| 0.35 | 0.875 | 0.957 | 76.1 | 부드럽게 붙음 |
| 0.40 | 1 | 1 | 75.0 | 닫힘 |

### 3-4. 연속 피해(사슬) 규칙 — 「시간 연장」

피해 한 번(`OnDamaged`)마다:

1. **흰 게이지 위치**: 닫혀 있었으면 `ghostHp = hpBefore`, `chainStart = clock`. 열려 있었으면 `ghostHp = max(ghostHp, hpBefore)` — 머무는 중이면 그대로, **내려오던 중이면 그 자리에서 멈춘다**(위로 되돌아가지 않음 · 격투 게임과 같음). 결과적으로 흰 구간은 「사슬이 시작된 체력 ~ 지금 체력」 또는 「멈춘 자리 ~ 지금 체력」으로 **더 긴 구간을 한 덩어리로** 보여 준다.
2. **머무름 연장 = 최소 보장 리셋**: `holdUntil = max(holdUntil, min(clock + Hold[등급], chainStart + ChainCap))`, 상태 → 머무름.
   - 「리셋」(마지막 피해 뒤 Hold 만큼)이지 「가산」(피해 횟수 × Hold)이 아니다. 가산은 보스 평타 10회/초에서 금방 상한에 붙어 리셋과 같아지고, 상한이 없으면 무한히 자란다. 리셋은 「마지막 피해 뒤 n초」 로 예측 가능하고 격투 게임의 규칙과 같다.
   - 등급이 올라가면(누적 창 `Window` 안에서 Medium → Big → Deadly) 그 등급의 더 긴 Hold 로 다시 시작한다.
3. **상한**: `clock ≥ chainStart + ChainCap` 이면 연장하지 않는다. 머무는 중이었다면 상한 시각에 내려오기 시작하고, **내려오는 중 들어온 피해는 멈추지 못한다**(흰 게이지는 실제 체력(움직이는 목표)까지 계속 내려와 닫힘). 닫힌 뒤 다음 피해가 **새 사슬**을 연다. → 군중 속에서는 「3초 동안 잃은 양」 덩어리가 3.0초 머물고 ≤0.8초에 내려오는 리듬이 생긴다.
4. 흰 게이지 **점화**(3-5) · 등급 효과 예약은 사슬과 무관하게 피해마다.

타임라인 예시 (플레이어 최대 100 · 시각 = clock):

**A. 보스 접촉 25 한 번 (Big)**
```
0.00  채움 100→75 즉시 · 흰 게이지 100 (순백 점화) · 채움 번쩍 0.7 · 프레임 붉은 틴트 0.35 · 바 전체 흔들림 9px 0.28초 · 두께 +12% · 「-25」 1.55배
0.30  점화 끝(쉼 흰색) · 흔들림 끝 — 흰 구간 100~75 가 또렷이 머무름
0.90  머무름 끝 → 내려오기 (D 0.40)
1.10  흰 87.5
1.30  흰 75 = 채움 → 닫힘
```

**B. 다단 히트 3연타 (10 · 10 · 10, 0 / 0.65 / 1.30초)**
```
0.00  hit1 100→90 · 사슬 시작 · 흰 100 · 누적 10 = Medium → holdUntil 0.75
0.65  hit2  90→80 · 누적 20(창 1.0 안) = Big → holdUntil = max(0.75, min(0.65+0.90, 3.0)) = 1.55 · 흰 100 그대로 · 재점화 · 번쩍 0.7 · 흔들림 9px
1.30  hit3  80→70 · 누적 30 = Deadly → holdUntil = min(1.30+1.10, 3.0) = 2.40 · 프레임 붉은 틴트 0.65 · 흔들림 16px · 두께 +20% · 「-30」 2배
2.40  내려오기 (구간 30% → D 0.48)
2.88  닫힘 — 흰 100→70 한 덩어리(30)가 2.9초 동안 보임
```

**C. 군중 접촉 (5 씩 0.6초마다)**
```
0.0  100→95 사슬 시작 · hold 0.65
0.6   95→90 hold 1.25        1.2  →85 hold 1.85        1.8  →80 hold 2.45
2.4   →75 hold min(3.05, 상한 3.0) = 3.0
3.0   →70 상한 지남 → 연장 없음 · 같은 프레임 Tick 이 내려오기 시작 (100→70 = 30% → D 0.48)
3.48  닫힘 (흰 = 70)
3.6   70→65 새 사슬 (흰 70) …  → 「3초 동안 30 잃음」 덩어리가 리듬으로 보임
```

**D. 보스 연사 (1% 씩 10회/초)**
```
0.0~1.5  피해마다 hold 다시(0.45) → 상한 1.5 까지 흰 게이지가 사슬 시작 위치에 고정 · 덩어리가 15% 까지 자람
1.5      내려오기 (D = clamp(1.2×0.15, 0.30) = 0.30) · 이 사이 피해는 연장 없음
1.8      닫힘 → 다음 피해가 새 사슬 … 주기 1.8초의 「DPS 덩어리」
```

### 3-5. 「확 눈에 띄게」 — 피격 순간 연출

모든 연출은 **등급(Tier)** 으로 세기를 정한다 (등급 · 문턱은 그대로: 플레이어 5 / 15 / 30%, 보스 2 / 6 / 12%, 적 15 / 35 / 60%).

| 효과 | Small | Medium | Big | Deadly | 모양 · 시간 | 설정 |
|---|---|---|---|---|---|---|
| ① 흰 게이지 **점화** | ○ | ○ | ○ | ○ | 색 `lerp(쉼, 순백, k)`, `k = (1 − t/0.30)²` (ease-out). 재점화는 직전 점화 후 ≥ 0.12초 (≤ 8회/초) | `Flashes` 꺼지면 쉼 흰색 고정 |
| ② 채움 **번쩍임** (흰색 섞기) | 0.25 | 0.45 | 0.70 | 1.00 | `flash(t) = amp × (t < 0.035 ? 1 : 1 − (t − 0.035) / 0.125)` · 총 0.16초 (정점 2프레임 + 7~8프레임 감소). **채움 색에는 `flash × 0.7`** (흰 게이지와 경계 유지) — Deadly 는 정점 2프레임만 1.0 (바 전체가 하얗게 「퍽」). 막대당 간격 ≥ 0.34초(≤ 3회/초) · 간격 안에 더 센 등급이 오면 새 정점 없이 세기만 올림 | `Flashes` |
| ③ **테두리 · 배경 강조** | – | – | 0.35 | 0.65 | ②와 같은 모양. HUD(플레이어 · 보스) 프레임은 흰 틴트라 더 밝힐 수 없음 → **붉은 틴트** `lerp((1,1,1), (1, 0.72, 0.72), amp × 모양)` (금색 테두리가 붉게 물듦 · 피격 비네트와 같은 계열). 적 `Back`(어두운 테두리) 은 **흰색으로** `lerp(back, (1, 0.96, 0.92), amp × 모양)` → 0.5 / 0.85 | `Flashes` |
| ④ **흔들림** (바 전체) | – | – | 높이 45% · 0.28초 | 높이 80% · 0.42초 | `k = (1 − t/len)²`, `x = sin(2π·20·t) × amp × k`, `y = sin(2π·20·t × 0.77 + 1.3) × amp × k × 0.6`. **20Hz** (60fps 에서 3프레임/주기 → 사인파가 보임 · 0.28초 = 5.6주기). 더 센 것만 덮어씀(지금 규칙) | `ScreenShake` |
| ⑤ **두께 펀치** (세로 스케일) | – | – | +12% | +20% | `scaleY = base × (1 + amp × (1 − t/0.16)²)` · 0.16초. 가로는 안 건드림 (피벗이 왼쪽 끝 · 위쪽이라 가로로 키우면 밀림) | `ScreenShake` |
| ⑥ 피해 숫자 크기 | 1 | 1.2 | 1.55 | 2 | 그대로 (`PopupScale`) | `DamageNumbers` |

픽셀로 환산:

| 바 | 흔들림 Big / Deadly | 두께 펀치 Big / Deadly | 움직이는 대상 |
|---|---|---|---|
| 플레이어 (높이 20) | **9 / 16px** | 20 → 22.4 / 24px (프레임 44 → 49 / 53) | **`HPbackground`** (= `transform.parent`) — 프레임 · 흰 게이지 · 채움 · 글자가 한 몸으로 (1-4 a 수정) |
| 보스 (높이 20) | 9 / 16px (`× BarY × 0.25` → `× BarY`) | 20 → 22.4 / 24px · 아래 줄은 base 0.8 에 곱함 | `BossBarBackground`(`Row.root`) — 지금처럼 · 피벗 (0.5, 1) 이라 펀치는 아래로 자람 |
| 적 (높이 0.32) | 0.144 / 0.256 월드 = 5.2 / 9.2px (줌 15) | 0.32 → 0.358 / 0.384 | 바 루트 (`EnemyHealthBar.transform`) — 지금처럼 · 보정 스케일 1/lossyScale 에 곱함 |

- 적 바의 ③④⑤ 는 **「큰 피해 묶음」** 으로 한 번에 예약 · 상한 `EnemyShakeMax 4` 에 함께 걸린다 (광역기로 100마리가 동시에 Big 이어도 흰 게이지 · 번쩍임 ②만 100개, 테두리 · 흔들림 · 펀치는 4개).
- Small 도 ②(0.25) 가 있다 — 플레이어 빨강 `(0.86, 0.17, 0.24)` → `(0.88, 0.32, 0.37)` 로 0.16초 살짝 밝아짐. 작은 피해도 「맞았다」가 바에서 읽히게. 적 몸의 흰 번쩍임(`EnermyController.HitEffect` 0.05초 · 0.25초 간격)과는 리듬이 달라 겹쳐도 문제 없음.
- 플레이어 **쓰러지는 피해**는 등급을 Deadly 로 올려 ②③④⑤ 를 모두 보여 준다 (지금은 `hpBefore − amount ≤ 0` 이면 연출 생략 — 적 · 보스는 바가 꺼지므로 그대로 생략). 흰 게이지는 Deadly 머무름 1.1초 뒤 0.8초 이내에 0 으로 내려온다 → 사망 슬로모션(1.1초, 실제 시간) 동안 「생명이 빠져나가는」 그림.

### 3-7. 예외 처리

| 상황 | 처리 |
|---|---|
| **회복** (재생 · 처치 회복 · 고기 · 물약 · 심장) | 채움이 흰 게이지에 닿거나 넘으면 **즉시 닫힘**(흰 게이지 = 체력, 사슬 종료). 닿지 않으면 흰 구간이 아래에서 줄어드는 것으로 보임(자연스러움). 회복 전용 게이지(초록 잔상)는 **두지 않음** — 이 게임의 회복은 초당 재생처럼 잦고 잔잔해 계속 깜빡이게 됨 |
| 최대 체력 증가 (카드 · 성장) | `ghostHp` 가 체력 단위라 비율이 저절로 맞음. 채움이 올라가는 길이면 닫힘 |
| 최대 체력 감소 | `ghostHp = min(ghostHp, maxHp)` (지금 규칙) |
| 부활 (불사의 맹세 · 최후의 보루) | 체력이 올라가므로 즉시 닫힘 · 연출 없음 (지금과 같음) |
| `TryHit` 밖의 체력 감소 (시계장이 되감기 · 자가 소모 8%) | `PlayerHP.Update` 폴링 → `OnDamaged(visible:false)` → 흰 게이지 · 사슬만, 번쩍임 · 흔들림 없음 (지금 규칙) |
| 이어하기 (`RunSave.Restore`) · 씬 시작 | `Reset(hp)`: 흰 게이지 = 체력 · 사슬 · 효과 타이머 모두 끔 (지금 `ResetFeel`) |

**`HealthBarFeel.cs`** — 상수 · 상태 · `OnDamaged` · `Tick` · `Frame` 교체. 등급 · 창 · `MakeGhost` · `PopupScale` · 흔들림 상한 집계는 그대로.

```csharp
// ---- 흰 게이지 (예전 GhostHold · GhostHoldDeadly · GhostFallRate · GhostFallMin 삭제)
static readonly float[] HoldPlayer = { 0.65f, 0.75f, 0.90f, 1.10f };
static readonly float[] HoldBoss   = { 0.45f, 0.50f, 0.60f, 0.80f };
static readonly float[] HoldEnemy  = { 0.40f, 0.45f, 0.50f, 0.65f };
static readonly float[] ChainCap   = { 3.0f, 1.5f, 1.2f };        // [Player, Boss, Enemy]
static readonly float[] FullBar    = { 1.6f, 1.2f, 1.0f };
static readonly float[] DrainMin   = { 0.35f, 0.30f, 0.25f };
static readonly float[] DrainMax   = { 0.80f, 0.70f, 0.50f };
public const float DtMax = 0.1f;
// ---- 강조
static readonly float[] FlashAmp  = { 0.25f, 0.45f, 0.70f, 1f };   public const float FlashTime = 0.16f, FlashPeak = 0.035f, FlashGap = 0.34f, FillFlashMul = 0.7f, FillFlashMulCB = 0.5f;
static readonly float[] BackFlash = { 0f, 0f, 0.35f, 0.65f };
public const float IgniteTime = 0.30f, IgniteGap = 0.12f;
static readonly float[] ShakeAmp  = { 0f, 0f, 0.45f, 0.80f };      static readonly float[] ShakeTime = { 0f, 0f, 0.28f, 0.42f };   public const float ShakeHz = 20f;
static readonly float[] PunchAmp  = { 0f, 0f, 0.12f, 0.20f };      public const float PunchTime = 0.16f;
public const int EnemyShakeMax = 4;     // 적 「큰 피해 묶음」(테두리 · 흔들림 · 펀치) 동시 상한

float[] Hold => kind == Kind.Player ? HoldPlayer : kind == Kind.Boss ? HoldBoss : HoldEnemy;      // 아래에서 Hold[(int)tier]
public static float Dt => PlayerController.IsPaused ? 0f : Mathf.Min(Time.unscaledDeltaTime, DtMax);
public static Color GhostColor(float ignite) => Color.Lerp(new Color(0.90f, 0.91f, 0.93f, 0.94f), Color.white, ignite);   // 색약 분기 없음 (흰색으로 통일)

enum Phase { Closed, Hold, Drain }
float clock; Phase phase; float ghostHp = -1f, holdUntil, chainStart, drainFrom, drainStart, drainDur;
float igniteT = IgniteTime, punchAmp, punchT = PunchTime, backAmp, backT = FlashTime;    // + 기존 accum/shake/flash 상태 · backT: 테두리 강조는 자기 타이머 (번쩍임 0.34초 간격 제한과 무관 — Big 이상만이라 드묾)

public bool Active => ghostHp > 0f && (phase != Phase.Closed || shakeT < shakeLen || flashT < FlashTime || backT < FlashTime || igniteT < IgniteTime || punchT < PunchTime);

public Tier OnDamaged(float amount, float hpBefore, float maxHp, bool visible = true)
{
    Tier tier = …기존 창 · 등급 계산…;
    bool lethal = hpBefore - amount <= 0f;
    if (kind == Kind.Player && lethal) tier = Tier.Deadly;                 // 쓰러지는 피해는 가장 센 연출

    // 흰 게이지 · 사슬
    if (phase == Phase.Closed || ghostHp < 0f) { ghostHp = hpBefore; chainStart = clock; }
    else ghostHp = Mathf.Max(ghostHp, hpBefore);                           // 내려오던 중이면 그 자리에서 멈춤
    float cap = chainStart + ChainCap[(int)kind];
    if (clock < cap) { holdUntil = Mathf.Max(holdUntil, Mathf.Min(clock + Hold[(int)tier], cap)); phase = Phase.Hold; }
    // 상한 뒤: 연장 없음 (내려오던 중이면 계속 내려와 닫힘 → 다음 피해가 새 사슬)

    if (!visible || (lethal && kind != Kind.Player)) return tier;         // 안 보이거나 바가 꺼질 피해: 연출 생략
    if (GameSettings.Flashes && igniteT >= IgniteGap) igniteT = 0f;        // 점화 (모든 등급)
    int t = (int)tier;
    if (GameSettings.Flashes && FlashAmp[t] > 0f)                           // 채움 번쩍임 (간격 안이면 세기만 올림)
    {
        if (Time.unscaledTime >= nextFlashAt) { nextFlashAt = Time.unscaledTime + FlashGap; flashAmp = FlashAmp[t]; flashT = 0f; }
        else flashAmp = Mathf.Max(flashAmp, FlashAmp[t]);
    }
    bool big = t >= (int)Tier.Big;
    if (big && (kind != Kind.Enemy || shaking || enemyShaking < EnemyShakeMax))   // 큰 피해 묶음 (적은 4개 상한)
    {
        if (!shaking && kind == Kind.Enemy) enemyShaking++;
        shaking = true;                                                     // 집계용 (흔들림 설정과 무관하게 묶음 단위)
        if (GameSettings.Flashes) { backAmp = BackFlash[t]; backT = 0f; }
        if (GameSettings.ScreenShake)
        {
            …기존 「더 센 것만 덮어씀」 규칙으로 shakeAmp · shakeLen…;
            punchAmp = Mathf.Max(punchAmp * (1f - Mathf.Clamp01(punchT / PunchTime)), PunchAmp[t]); punchT = 0f;
        }
    }
    return tier;
}

public struct Frame
{
    public float front, ghost; public bool ghostShown;
    public float shakeX, shakeY;    // 막대 높이 대비 비율 (그리는 쪽이 × 높이)
    public float flash;             // 채움에 섞을 흰색 0~1 (이미 ×0.7 · 색약 ×0.5 적용됨 · Deadly 정점은 1.0)
    public float backFlash;         // 프레임 · 테두리 강조 0~1
    public float punch;             // 세로 스케일 증가분 (0 = 평소)
    public float ignite;            // 흰 게이지 밝기 0~1 → GhostColor(ignite)
}

public void Tick(float hp, float maxHp, float dt, out Frame f)
{
    hp = Mathf.Max(0f, hp); clock += dt;
    if (ghostHp < 0f) { ghostHp = hp; phase = Phase.Closed; }
    if (maxHp > 0f && ghostHp > maxHp) ghostHp = maxHp;
    if (hp >= ghostHp) { ghostHp = hp; phase = Phase.Closed; }             // 회복 · 부활 · 최대 체력 증가: 즉시 닫힘
    else if (phase == Phase.Closed) ghostHp = hp;                           // 안전장치 (OnDamaged 없이 내려간 체력)
    else if (phase == Phase.Hold && clock >= holdUntil)
    {
        phase = Phase.Drain; drainFrom = ghostHp; drainStart = clock;
        int k = (int)kind; drainDur = Mathf.Clamp(FullBar[k] * (ghostHp - hp) / Mathf.Max(1f, maxHp), DrainMin[k], DrainMax[k]);
    }
    if (phase == Phase.Drain)
    {
        float u = (clock - drainStart) / drainDur;
        if (u >= 1f) { ghostHp = hp; phase = Phase.Closed; }
        else { float s = u * u * (3f - 2f * u); ghostHp = Mathf.Lerp(drainFrom, hp, s); }
    }
    f.front = maxHp > 0f ? Mathf.Clamp01(hp / maxHp) : 0f;
    f.ghost = maxHp > 0f ? Mathf.Clamp01(ghostHp / maxHp) : 0f;
    f.ghostShown = f.ghost > f.front + 0.002f;

    // 점화
    f.ignite = 0f;
    if (igniteT < IgniteTime) { igniteT += dt; float r = 1f - Mathf.Clamp01(igniteT / IgniteTime); f.ignite = r * r; }
    // 채움 번쩍임 (정점 2프레임 + 선형 감소) · 프레임 · 테두리 강조는 같은 모양, 자기 타이머(backT)
    f.flash = f.backFlash = 0f;
    if (flashT < FlashTime)
    {
        flashT += dt;
        float shape = Shape(flashT);
        float mul = GameSettings.ColorBlind ? FillFlashMulCB : FillFlashMul;
        f.flash = flashAmp >= 1f && flashT < FlashPeak ? 1f : flashAmp * shape * mul;
    }
    if (backT < FlashTime) { backT += dt; f.backFlash = backAmp * Shape(backT); }
    // static float Shape(float t) => t < FlashPeak ? 1f : 1f - Mathf.Clamp01((t - FlashPeak) / (FlashTime - FlashPeak));
    // 흔들림 (20Hz 감쇠 사인 · (1−t/len)²)
    f.shakeX = f.shakeY = 0f;
    if (shakeT < shakeLen)
    {
        shakeT += dt; float k = 1f - Mathf.Clamp01(shakeT / shakeLen); k *= k; float w = shakeT * ShakeHz * 6.2832f;
        f.shakeX = Mathf.Sin(w) * shakeAmp * k; f.shakeY = Mathf.Sin(w * 0.77f + 1.3f) * shakeAmp * k * 0.6f;
    }
    // 두께 펀치
    f.punch = 0f;
    if (punchT < PunchTime) { punchT += dt; float r = 1f - Mathf.Clamp01(punchT / PunchTime); f.punch = punchAmp * r * r; }
    // 「큰 피해 묶음」 집계 해제: 흔들림 · 펀치 · 테두리가 모두 끝났을 때
    if (shaking && shakeT >= shakeLen && punchT >= PunchTime && backT >= FlashTime) { shaking = false; if (kind == Kind.Enemy && enemyShaking > 0) enemyShaking--; }
}

public void Reset(float hp)   // 씬 시작 · 풀 · 부활 · 이어하기
{
    ghostHp = Mathf.Max(0f, hp); phase = Phase.Closed; holdUntil = chainStart = 0f; accum = 0f; accumFirst = accumLast = -99f;
    if (shaking && kind == Kind.Enemy && enemyShaking > 0) enemyShaking--;
    shaking = false; shakeT = shakeLen = 0f; flashT = backT = FlashTime; flashAmp = backAmp = 0f; igniteT = IgniteTime; punchT = PunchTime; punchAmp = 0f;
}
```

### 3-11. 검증 체크리스트 (구현 뒤 · 캡처 · 배치 테스트 없이 눈으로)

1. 1장 보스 접촉 25: 채움이 즉시 75 로, **흰 구간 100~75 가 0.9초 또렷이 머문 뒤 0.4초에 걸쳐 부드럽게 줄어듦**. 바 **전체**(프레임 · 글자 포함)가 9px 흔들리고 프레임 테두리가 붉게, 두께가 잠깐 두꺼워짐.
2. 접촉 피해 5 × 연속: 흰 구간이 **내려오지 않고 자라다** 3초에 한 번 내려옴. 「-N」 숫자는 1초 창으로 합쳐짐.
3. 보스 다단 히트: 흰 구간이 한 덩어리로 유지되다 마지막 타 1.1초 뒤 내려옴.
4. 보스 바: 평타 연사 중 흰 덩어리가 1.5초 자라고 0.3초에 미끄러져 닫히는 리듬. Big 이상에서 **눈에 보이는 9~16px 흔들림**(지금은 1~2px).
5. 적 바: 바 높이 11.5px · 흰 구간이 초록 · 주황 · 빨강 어느 채움 옆에서도 보임 · Big 에서 테두리가 하얗게 · 동시 흔들림 4개 이하.
6. ESC 로 멈춤: 흰 구간 · 번쩍임이 **그대로 얼어 있고** 풀면 이어짐. 사망 슬로모션: 흰 구간이 실제 시간으로 0 까지 내려옴.
7. 회복(고기 · 물약 · 재생): 채움이 흰 구간에 닿으면 즉시 사라짐 · 깜빡임 없음. 최대 체력 카드: 비율 틀어짐 없음. 불사의 맹세 · 최후의 보루: 튀지 않음.
8. 설정: 「화면 흔들림」 끄면 흔들림 · 펀치 0, 「번쩍임 효과」 끄면 번쩍임 · 점화 · 테두리 0 — **흰 구간과 시간은 그대로**. 색각 모드: 흰 구간 그대로 · 채움 번쩍임 약함.
9. 킹 슬라임 분열 · 무한 모드 보스 2마리: 줄마다 흰 구간 · 흔들림 따로, 줄이 바뀌어도 조각이 남지 않음.
10. 성능: 프로파일러 GC 0B · 적 300마리 중 맞지 않은 적의 `LateUpdate` 가 첫 줄에서 반환 · 하이어라키에 새 오브젝트가 늘지 않음(HPghost 1개 고정).
