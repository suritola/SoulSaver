# Soul Saver 1.0.5 패치노트 — 게임패드 지원

첫 구매자 점검(`docs/review/2026-10-14-첫구매자-점검.md`)에서 남겨 두었던 「게임패드를 지원하지 않음 — 스팀 덱으로는 메뉴조차 못 움직인다」 항목입니다. 새 패키지 없이 옛 Input Manager 로 만들었습니다.

## 🎮 버튼 배치 (엑스박스 기준)

| 버튼 | 전투 | 메뉴 · 창 |
|---|---|---|
| 왼쪽 스틱 | 이동 (살짝 기울이면 천천히) | 가상 커서 |
| 십자키 | 이동 | 그 방향의 가장 가까운 버튼으로 커서 · 카드 창은 ← → 로 카드 고르기 |
| 오른쪽 스틱 | 조준 (0.3 넘게 기울이면 그 방향, 0.5 넘으면 자동 평타) · 놓으면 마지막 방향 | 스크롤 · 영혼 트리 화면 이동 |
| RT | 공격 (누르고 있기) | 영혼 트리 확대 |
| LT | 필살기 (누르고 있다가 떼기) | 영혼 트리 축소 |
| A | 상호작용 · 확정 · 대사 넘기기 | 클릭 (고른 카드를 한 번 더 = 확정) |
| B | — | 뒤로 (ESC 와 같음) |
| X | 재장전 | 레벨업 창 다시 뽑기 |
| Y | 무기 교체 | |
| RB · LB · L3 | 스킬 1 · 2 · 3 | |
| R3 | 튜토리얼 「이 단계 건너뛰기」 | |
| View | 영혼 트리 열기 · 닫기 | |
| Menu | 일시정지 | ESC 와 같음 |

- 스틱 없이 RT · LT 만 누르고 있으면 0.4초 뒤부터 11칸 안의 가장 가까운 적을 보조 조준
- 마지막으로 쓴 장치(패드 / 키보드 · 마우스)에 따라 안내 글자가 [RT] · [A] · 「왼쪽 스틱」으로 바뀌고, 패드 동안은 게임 커서 모양의 가상 커서 · 조준점을 그림
- 메뉴 · 창은 EventSystem 입력을 바꿔 끼워 버튼 · 호버 · 툴팁 · 슬라이더 끌기 · 스크롤이 마우스와 똑같이 동작
- ESC 를 쓰던 10곳(일시정지 · 설정 · 확인 창 · 영혼 트리 · 이야기 · 캐릭터 · 일일 도전 · 스킨 상점 · 패치노트 · 튜토리얼)이 패드 Menu · B 를 받음
- 설정 → 조작 탭에 게임패드 배치표
- `ProjectSettings/InputManager.asset` 에 패드 축 8개 (왼쪽 · 오른쪽 스틱, 십자키, 트리거)
- 자동 테스트 · 트레일러 입력과 겹치지 않음, 패드를 쓰지 않으면 키보드 · 마우스 동작은 그대로
- 새 문구 4개 언어

## 알려진 점

- 버튼 · 축 번호는 윈도우 XInput 배열 기준 — 다른 드라이버에서 십자키 위 · 아래가 거꾸로면 알려 주세요
- 몇몇 안내(HUD 「무기 [Q]」 제목, 상점 가판대 키 그림 등)는 장치를 바꿔도 다음에 다시 그릴 때 바뀜
