## 4장 잡몹 스킬 예고 (AbyssWarn · EnemySkill)
- 넷 다 같은 직선 띠 · 원판이라 단조롭고 겹치면 어지럽던 것 → 스킬마다 다른 모양 · 색
  - 사슬 던지기: 쇳빛 점선 테두리(판정 폭 1.5) + 뻗어 나가는 사슬 + 끝 갈고리
  - 공허의 시선: 보라 부채꼴 (메시 · fx_ind_cone), 시작 변 흰 선 · 채움이 훑는 방향으로
  - 영혼 베기: 안쪽 원(차오르는 원판) + 바깥 고리(점선 → 차례가 오면 실선 · 진하게)를 처음부터 함께
  - 심연 균열: 청록 지그재그 금이 갈라져 나감 + 판정 폭(2)의 옅은 띠 (예전 띠 1.4 는 판정보다 좁았음)
- 룬 마법진 · 좁혀 드는 고리 없음, 시전한 적이 죽으면 바로 거둠
- 4장 잡몹 스킬 동시 시전 3마리까지 (중간 보스 제외 · 넘으면 0.3~0.8초 미룸)
