## 영혼 제단 · 유산 (`SoulLegacy`, 새 파일)
- 메인 메뉴 「영혼 제단」: 조건을 이루면 깨어나는 특수 능력 8종 · 깨어난 것 중 셋까지 지님 (`legacy.eq` 비트) · 포인트로 사지 않음 · 새 조작 키 없음 (모두 저절로 발동)

| 유산 | 효과 | 조건 |
|---|---|---|
| 피의 맹세 | 처치 시 3% 확률로 최대 체력 2% 회복 | 적 20,000 처치 (누적) |
| 불굴 | 판마다 한 번 쓰러질 피해를 체력 30%로 버팀 · 2초 무적 | 어려움 클리어 |
| 왕 사냥꾼 | 보스에게 주는 피해 +15% | 영웅 5명으로 이야기 클리어 |
| 왕의 전리품 | 보스 처치 시 레벨업 카드 2장 (대기 카드만 · 경험치 요구량 그대로) | 무한 모드 클리어 |
| 숨 고르기 | 레벨업마다 최대 체력 3% 회복 | 쉬움 클리어 |
| 선구자 | 판 시작 레벨업 카드 +1 (이야기) | 숙련 최대 영웅 1명 |
| 역류의 잔향 | 체력 30% 이하일 때 받는 피해 -25% | 역류 클리어 |
| 연전의 기억 | 보스 처치 시 최대 체력 20% 회복 | 보스 러시 클리어 |

- 효과 자리: `PlayerController.TryHit`(피해 감소 · 불굴) · `bosss.TakeDamage`(왕 사냥꾼) · `bosss.Die`(보스 처치) · `LevelShop` 레벨업 · `EnermyController.Killed` · `StageManager` 판 시작 카드
- 꺼지는 판: 체험판 · 페스티벌 · 튜토리얼 · 자동 봇 · 배치 (밸런스 측정은 유산 없이)

## 영웅 각성 (`HeroAwaken`, 새 파일)
- 영웅 상세 「각성 n/5」 버튼: 그 영웅으로 조건을 이루면 단계마다 따로 열리고 늘 켜짐

| 단계 | 효과 | 조건 (그 영웅으로) |
|---|---|---|
| 1 | 판 시작 레벨업 카드 +1 (이야기 · 숙련과 합산) | 이야기 클리어 |
| 2 | 필살기를 쓰면 최대 체력 8% 회복 | 이야기 보스 네 종 처치 |
| 3 | 판 시작 때 필살기 게이지 절반 | 필살기 300번 |
| 4 | 체력 40% 이하일 때 받는 피해 -20% | 무한 모드 15분 |
| 5 | 판 시작부터 1차 무기 진화 (역류 제외 · 이어하기는 기록 재생) | 숙련 최대 |

- 효과는 지금 영웅(`CharacterData.Selected`)으로 그때그때 읽어 영혼 릴레이 교대도 그대로

## 보스 러시 (`Modes/BossRush.cs`, 새 모드)
- 도전 모드 창 4번째 카드 (창 1320 → 1440 · 카드 410 → 340) · 보통 클리어로 해금 · 메인 메뉴에서 고른 영웅으로
- 킹 슬라임 → 리치 왕 → 지옥의 군주(체력 ×0.5) → 거울의 군주 → 개발자 · 앞 보스 처치 연출 · 진화 창이 끝나고 12초 뒤 다음
- 보스마다 무한 모드처럼 무기 진화 · 전리품 + 체력 30% 회복 · 잡몹 · 레벨 10 시작은 무한 그대로
- 기록 = 모두 쓰러뜨린 시간 · 순위표 `BOSSRUSH_BEST`(오름차순, 순위 창 5번째 탭) · 첫 클리어 5,000P · 그 뒤 1,000P · 이어하기 없음
- `EndlessMode`: 보스 러시 판은 자기 보스 일정 · 15:00 · 중간 보스 · 엄마 예고를 끔, 무한 기록 · 이정표 · 해제 조건(무한 10분 · 보스 5)에 섞지 않음 (`ModeKind.BossRush` → `ModeRun.Special`)
