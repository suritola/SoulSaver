# Soul Saver 1.0.9 패치노트 — 3장부터 보스 강화 · 또렷한 적 탄 · 눈에 띄는 안내

## 👑 보스 난이도

「3장부터 보스가 약하다」는 의견을 반영해, 3장부터 보스가 확실히 세집니다.

- **3장 지옥의 군주**: 체력 4760 → **6843**, 공격 피해 **×1.3**, 스킬을 더 자주 씀
- **4장 거울의 군주**: 체력 5040 → **6930**, 공격 피해 **×1.45**, 스킬을 훨씬 더 자주 씀
  - 거울의 군주의 공격 한 대 상한: 최대 체력의 15% → **20%**
- 1 · 2장 보스와 잡몹은 그대로입니다

## 🔥 결계

- **지옥의 군주 「연옥 낙화」가 더 어려워졌습니다**
  - 운석 비: 10개 → **17개**, 그중 일부는 내 주변을 노림
  - 거대 운석: 범위가 넓어지고, 둘레 여섯 곳을 함께 막으며, 피한 자리에 **한 번 더** 떨어짐
  - 운석 행진이 더 빠르고 넓어짐
  - 결계 내내 **내 발밑에 작은 불씨 운석**이 떨어짐 — 가만히 서 있을 수 없습니다
  - 모든 운석은 그대로 예고가 먼저 보여 움직이면 피할 수 있습니다
- **리치 왕 「망자의 묘역」은 살짝 쉬워졌습니다**
  - 영혼 고리 간격 1.5초 → 1.75초, 뼈 가시 간격 0.55초 → 0.68초 · 예고 0.75초 → 0.85초

## 👁 적 투사체가 또렷하게

- 흐릿한 빛 덩어리였던 적 탄이 **검은 테두리 + 진한 색 + 하얀 심**의 구슬로 바뀌었습니다
- 뒤에 어두운 그림자가 깔려 밝은 초원 · 어두운 묘역 · 붉은 지옥 어디서든 잘 보입니다
- 탄이 두근거리고 꼬리도 더 진해졌습니다 (결계의 산성 덩어리도 같은 모양)

## 💡 안내가 눈에 잘 띄게

- **카드 다시 뽑기**: 작은 글씨 대신 테두리 있는 배지, 키와 남은 횟수는 노란색으로
- **시너지**: 초록 배지에 「시너지! 카드 이름」
- **추천**: 더 큰 밝은 금빛 배지에 진한 글씨
- 카드 확정 안내와 「도움말」 팝업도 더 크고 굵게, 진한 바탕과 테두리로
