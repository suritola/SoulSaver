# v2.0.5 (2026-11-20)

## 저장 복구 (`SteamManager.RestoreFromAchievements`)
- 저장이 날아간 유저를 위해, 켤 때 한 번 스팀 기록을 읽어 진행을 되살림 (`restore.steamAch` 로 저장마다 한 번 · 올리기만 함)
  - 난이도 해금 · 보통 · 어려움 클리어 업적 → 해당 난이도 클리어 표시, 무한까지 열림 (`GameMode.RestoreCleared`)
  - 사막 비밀 영웅 업적 → 그 영웅 해금 (`CharacterData.UnlockSecret`)
  - 스팀 통계 `SAVE_POINTS` · `SAVE_HEROES` → 포인트(큰 쪽) · 해금 영웅 비트 (`CharacterData.RestoreBackup`)
  - 되살린 것이 있으면 알림 한 줄 (`restore.steamAch`, 4개 언어)
- `SyncSaveStats`: 장면마다 포인트 · 해금 영웅을 스팀 통계에 맞춤 (바뀌었을 때만 · 복구가 끝난 저장에서만 — 빈 저장이 서버 값을 0 으로 덮지 않게)
- 체험판 · 페스티벌 · 자동 봇 · 배치 · 테스트 해금 빌드에서는 돌지 않음

## 저장 백업 (`Prefs`)
- `save.json.keep`: 해금 · 클리어 수가 지금까지 가장 많은 마지막 저장. 진행이 줄어든 저장으로는 덮지 않음
  - 켤 때 본 저장보다 `.keep` 의 해금 · 클리어가 많으면 `.keep` 으로 되살리고 메인 메뉴에 알림
  - (`.bak` 은 매 저장마다 바로 전 내용이라, 저장이 날아간 뒤 두 번만 저장해도 빈 내용으로 덮였음)
- 본 파일이 없을 때도 `.bak` 으로 되살림 (예전엔 본 파일이 깨졌을 때만)
- 되살린 일을 `save.events` 에 남기고 판 기록 · 텔레메트리 끝 칸 `save_events` 로 보냄 (원인 · 빈도 확인용)

## Steamworks 설정 (빌드 밖)
- 자동 클라우드 경로가 스팀 예시 값(`gameinstall/SavesDir/*.sav`)이었고 개발자 전용이라, 출시 이후 저장이 한 번도 클라우드에 올라가지 않았음
  → `WinAppDataLocal / Soul Saver / save.json*` 로 고치고 일반 유저에게 공개 (2026-11-20 게시)
