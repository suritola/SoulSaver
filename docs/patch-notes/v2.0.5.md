# v2.0.5 (2026-11-20)

## 저장 복구 (`SteamManager.RestoreFromAchievements`)
- 저장이 날아간 유저를 위해, 켤 때 한 번 스팀 업적을 읽어 진행을 되살림 (`restore.steamAch` 로 한 번만)
  - 난이도 해금 · 보통 · 어려움 클리어 업적 → 해당 난이도 클리어 표시, 무한까지 열림 (`GameMode.RestoreCleared`)
  - 사막 비밀 영웅 업적 → 그 영웅 해금 (`CharacterData.UnlockSecret`)
  - 되살린 것이 있으면 알림 한 줄 (`restore.steamAch`, 4개 언어)
  - 포인트 · 일반 영웅 해금은 업적에 없어 되살리지 못함
- 체험판 · 자동 봇 · 배치 · 테스트 해금 빌드에서는 돌지 않음
