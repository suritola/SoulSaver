# v2.0.7 (2026-11-26) — 버그 전면 수정 · 그래픽 다듬기 · 밸런스

2.0.0 이후 바뀐 코드(약 1만 1천 줄)를 세 갈래(게임플레이 · 저장/UI/스팀 · 스킨 그래픽)로 감사해 확인된 것만 고침. 밸런스는 플레이 데이터(`tools/telemetry`, 정식판 54판 · 2.0.x 17판) 기준.

## 버그 수정 — 게임플레이
- `Modes/BossRush.cs`: 보스가 Die 없이 사라지면 `BossCount` 가 안 올라 `Clear()` 가 영영 안 불리던 것 — `tracked[next-1] == null && LiveCount == 0 && BossCount < next` 이면 쓰러진 것으로 셈
- `SteamManager.cs`: 보스 러시 판(항상 보스 5 · 15분 넘김)이 `ACH_ENDLESS_BOSSES` · `Endless10` 등 무한 업적을 풀던 것 → `BossRushRun.Active` 면 무한 업적 건너뜀
- `RunCounters.cs`: `endless.best`(각성 4단계 · 기억 조각 ⑤)를 릴레이 · 역류 · 보스 러시에서 적지 않음 (릴레이 교대 주자도 판 전체 시간으로 15분이 찼음)
- `HeroAwaken.StartEvo`: 릴레이 제외 (첫 주자 시작 진화가 `RelayResetEvolution` 으로 다음 주자 몫이 됨)
- `SoulLegacy`: 불굴 사용을 `RunCounters("legacy.endure")` 에 기록 (이어하기 저장에 남음 · 예전 `endureUsed` 는 GameScene 열 때마다 풀림) · 왕의 전리품은 역류에서 끔 (`AddPending` 이 막혀 알림만 떴음)
- `RunStats.NoteChapter`: 판 시작 2초 안의 장 기록은 버림 (첫 장이 정해지기 전 값이 「2장 1초」로 찍혀 장별 시간 통계가 틀어짐)

## 버그 수정 — 저장 · UI · 스팀
- `Prefs.LoadFiles`: 복구 순서 `.tmp → .keep → .bak` (예전 `.tmp → .bak` 은 `.bak` 으로 되살리며 바로 Write → 진행 수가 같으면 최신 `.keep` 까지 덮어 마지막 저장의 포인트 · 스킨이 사라짐)
- `SteamManager.RestoreFromAchievements`: 튜토리얼 중이면 미룸 (`UnlockSecret` 이 튜토리얼에서 false 인데 `restore.steamAch = 1` 만 남음)
- `MenuExtras`: `LayoutMainV2` · `StyleTitle` 이름 목록에 `AltarButton` (새 UI 에서 옛 자리 = 영웅 패널 위에 남음 · 등장 연출에서도 빠짐) — 이어하기 + 영혼의 무게까지 켜도 종료 버튼 아래끝 약 -444 (화면 -540 안)
- `SoulBrand.IsOpen` 추가 · `ESCmenu` 가 그 창이 열려 있으면 ESC 를 넘김 (처리 순서에 따라 일시정지까지 풀림)

## 그래픽 · 접근성
- `SkinEdge.Show`: 떠 있는 액자는 0 부터 다시 나타나지 않고 지금 밝기에서 이어 올라감 (연쇄 처치마다 알파 0 ↔ 0.6 으로 초당 10~16번 깜빡임 · 광과민)
- `SkinEdge` 띠 · `SkinFx.Bolt`: `GameSettings.Flashes` 끔이면 알파 ×0.3 (Flash 연출과 같은 규칙)
- `SkinPreview`: 렌더 텍스처 `FilterMode.Point` (비정수 배 확대에서 번짐)
