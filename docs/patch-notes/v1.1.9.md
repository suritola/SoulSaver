# Soul Saver 1.1.9 패치노트 (핫픽스)

1.1.8 배포판에서 판 시작부터 프레임이 크게 떨어지던 문제(내장 그래픽 · 무한 모드에서 특히 심함)를 고친 긴급 업데이트.

## 프레임 저하 원인과 수정
- 피격 흰 번쩍임이 끝난 뒤에도 MaterialPropertyBlock 이 남아, 한 번 맞은 적은 판 끝까지 배칭이 깨짐 → 번쩍이는 동안만 번쩍임 재질로 바꿨다가 되돌림 (`Juice.SetFlash`)
- 물리 최대 시간 간격 0.333 → 0.1 (느린 PC 에서 한 프레임에 물리 단계가 최대 16번 돌던 악순환 차단)
- 게임 카메라 HDR 끔 · 게임 중 MSAA 끔 · 품질 단계 안티앨리어싱 · 그림자 · 실시간 반사 끔
- 처치 연출 상한: 0.05초마다 처치 폭발 8개 · 충격파 3개 (큰 적은 늘 나옴) — 무한 모드 초반 대량 처치 때 화면이 덮이던 것
- HUD 를 하위 캔버스 다섯으로 나눠 바뀐 조각만 다시 묶음, 게이지 · 쿨타임은 단계가 바뀔 때만 갱신
- 영혼 트리 구매 가능 검사 · 「+N」 글자 갱신 횟수 줄임 (처치마다 GC)
- 피해 숫자 페이드는 정점 알파만 바꿈(TMP 메시 재생성 없음), 벽 검사 공용 버퍼, 피격 코루틴 재사용, 체력바 머리 위치 캐시, HPpack · GrowthPrompts 매번 씬 검색 제거, 무한 모드 화면 밖 화로 연출 건너뜀, UI 크기 1배일 때 1초마다 씬 검색 건너뜀

## 새 설정
- 설정 「화면」 탭: 최대 프레임(30 · 60 · 120 · 144 · 제한 없음, 기본 60) · 수직 동기화(기본 끔) · 프레임 표시(FpsCounter)
