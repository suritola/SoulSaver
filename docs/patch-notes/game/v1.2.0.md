# 1.2.0 긴급 업데이트

- **판이 진행될수록 프레임이 떨어지던 문제를 고쳤습니다.** 게임을 오래 할수록, 일시정지 중에도 점점 느려지던 렉이 사라집니다.
- **화면을 그리는 부담을 줄였습니다.** 특히 내장 그래픽 PC와 무한 모드에서 더 부드럽게 플레이할 수 있습니다.
- **설정 「화면」 탭에 프레임 설정을 추가했습니다.** 최대 프레임(30 · 60 · 120 · 144 · 제한 없음), 수직 동기화, 프레임 표시를 고를 수 있습니다.

# 1.2.0 Hotfix

- **Fixed frame rate dropping more and more as a run went on.** The lag that kept getting worse the longer you played, even while paused, is gone.
- **Reduced rendering load.** Play is smoother, especially on integrated graphics and in Endless Mode.
- **Added frame settings to the Display tab.** You can now choose a max frame rate (30 · 60 · 120 · 144 · Unlimited), toggle V-Sync, and show an FPS counter.

- **修复了游戏进行越久帧率越低的问题。** 玩得越久、甚至暂停时也越来越卡的问题已经消失。
