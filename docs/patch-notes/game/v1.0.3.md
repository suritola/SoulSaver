# 1.0.3 업데이트

- 새 장 「영혼의 심연」 · 마지막 보스 「거울의 군주」 추가
- 일일 도전 · 스팀 순위표 추가
- 판 중간 저장 · 이어하기 · 스팀 클라우드 저장
- 직접 해 보는 튜토리얼

## 밸런스 조정

- **1장 초원**: 적 체력 · 주는 피해 **50%** 감소, 적 등장 간격 **1.7배**, 한 화면 적 수 **45%** 감소, 이동 속도 **20%** 감소, 킹 슬라임 체력 **35%** 감소
- **2장 지하 묘역**: 적 체력 · 주는 피해 **10%** 감소, 리치 왕 체력 **5%** 감소
- **연금술사**: 플라스크 피해 1.45배 → **1.2배**, 불안정 1.8배 → **1.6배**, 화상 35% → **30%**, 폭발 범위 1.8 → **1.65**, 공격 속도 0.8 → **0.75**
- **검사**: 고유 스킬 피해 배율 3배 → **2배**
- **궁수 화살비**: 필살기 강화가 화살 수 대신 한 발 피해를 올림
