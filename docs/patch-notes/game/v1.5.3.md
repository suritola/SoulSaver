# V1.3 — UI 전면 개편
메인 메뉴부터 전투 화면까지, 모든 화면을 더 읽기 쉽고 단단한 모습으로 새로 다듬었습니다.

## 새로운 화면
- 모든 버튼 · 창 · 카드를 새긴 돌판 모습으로 바꾸고, 강조색을 청록 하나로 정리했습니다.
- 반짝임 · 깜빡임 · 튀어나오는 움직임을 줄여 눈이 덜 피곤합니다.
- 고른 것은 청록 테두리와 밑줄로, 누를 수 없는 것은 흐리게 보여 구분이 쉽습니다.

## 메인 메뉴
- 메뉴를 왼쪽 한 줄로 모으고, 시작 버튼 안에서 ◀ ▶ 로 난이도를 고릅니다.
- 가운데에 지금 영웅이 서고, 오른쪽에 새 소식과 다음 목표가 보입니다.

## 레벨업 · 고르기 창
- 카드를 다시 배치해 이름 · 단계 · 설명이 한눈에 들어옵니다.
- 스킬 진화 정보가 카드 안 아래 「진화」 칸에 정리되어 보입니다.

## 결과 · 설정 · 그 밖의 창
- 결과 화면을 간결하게 정리하고, 판 요약을 제목 아래 두 줄로 보여 줍니다.
- 설정에 켜고 끄는 스위치 · ◀ 값 ▶ 고르기 · 새 슬라이더를 넣었습니다.
- 도감 · 캐릭터 · 스킨 상점 · 영혼 트리 · 로딩 화면 · 전투 HUD도 같은 모습으로 맞췄습니다.
- 버튼 이름을 짧게 다듬었습니다 (예: 「게임 시작」 → 「시작」, 「이 탭 기본값으로」 → 「초기화」).

## 시작 화면
- 게임을 켜면 엔진 로고 대신 Soul Saver 타이틀 연출이 나옵니다. 아무 키나 누르면 넘어갑니다.
- 게임 엔진을 최신 버전으로 올렸습니다.

플레이해 주셔서 감사합니다!

# V1.3 — Full UI Overhaul
From the main menu to the battle screen, every screen has been rebuilt to be clearer and more solid.

## A New Look
- All buttons, windows and cards now use a carved-stone style, with a single teal accent color.
- Less sparkling, blinking and pop-in motion, so it's easier on the eyes.
- Selected items get a teal border and underline, and unavailable ones are dimmed.

## Main Menu
- The menu is now a single column on the left, and you pick the difficulty with ◀ ▶ inside the Start button.
- Your current hero stands in the center, with news and your next goals on the right.

## Level-Up & Choice Windows
- Cards have been rearranged so the name, rank and description are easy to read at a glance.
- Skill evolution info is now shown in an "Evolution" section at the bottom of each card.

## Results, Settings and More
- The results screen is simpler, with a two-line run summary under the title.
- Settings now have on/off switches, ◀ value ▶ selectors and new sliders.
- The Codex, hero select, skin shop, soul tree, loading screen and battle HUD all match the new style.
- Button names are shorter (e.g. "Start Game" → "Start", "Reset This Tab" → "Reset").

## Start Screen
- Launching the game now shows a Soul Saver title intro instead of the engine logo. Press any key to skip.
- Updated the game engine to the latest version.

Thanks for playing!

从主菜单到战斗画面，所有界面都重新打造，更清晰、更扎实。

## 全新界面
- 所有按钮、窗口和卡牌改为雕刻石板风格，强调色统一为青绿色。
- 减少闪光、闪烁和弹出动画，看起来更不累眼。

- 技能进化信息集中显示在卡牌下方的「进化」栏中。

- 设置中新增开关、◀ 值 ▶ 选择器和新滑块。
- 图鉴、角色、皮肤商店、灵魂之树、加载画面和战斗HUD也统一为新风格。
