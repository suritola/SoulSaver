# 1.2.8 업데이트 — 긴급 버그 수정

- **무한 모드 이어하기 시간 수정**: 이어하기를 하면 시간이 00:00에서 멈추던 문제를 고쳤습니다. 15분 「최후의 시간」과 적 증가도 제대로 진행됩니다.
- **보스 무적 · 공간 침식 수정 (1.2.7)**: 보스가 영원히 공격을 받지 않거나, 게이지가 가득 차도 공간 침식이 펼쳐지지 않던 문제를 고쳤습니다.
- 보스가 기술 도중 끊겨 공중에 떠 있던 문제 등 보스전이 멈출 수 있던 문제를 더 막았습니다.
- 무한 모드 · 일일 도전 중에 게임을 끄면 지금까지의 기록이 순위표에 올라갑니다.
- 빈틈이 더 눈에 띄는 모습으로 바뀌었습니다.
