# 1.1.1 업데이트

- **신규 캐릭터 4종 추가!** (조건 달성 후 포인트로 구매)
- 무한 모드에 **최종 국면**과 **최종 보스** 추가 — 이제 무한 모드도 클리어할 수 있습니다
- 궁수 · 연금술사에 고유 규칙 추가 (숨 고르기 · 불안정도)
- 효과음 · 이펙트 강화

## 밸런스 조정

- **거너**: 공격력 1.05 → **1.15**
- **시계공**: 공격 속도 1.1 → **0.85**
- **우체부**: 공격력 1.0 → **0.9**, 공격 속도 1.15 → **1.0**
  - 속달: 표식 수 8~30개 → **6~20개**, 피해 최대 500% → **400%**
- **유령**: 공격력 1.15 → **1.0**
  - 영혼이 생길 확률 35% → **20%**, 최대 영혼 6 → **4** (영혼 수호 카드: 5 · 6 · 7)
- **궁수 숨 고르기**: 숨이 닳는 속도 초당 30 → **20**, 차는 속도 초당 28 → **45**
- **연금술사 불안정도**: 던질 때 +8 → **+5** (불안정 플라스크 +15 → **+12**), 자폭 피해 최대 체력 12% → **8%**
- **지옥의 군주**: 「지옥이 무너진다」(가장자리 용암) 패턴 삭제
