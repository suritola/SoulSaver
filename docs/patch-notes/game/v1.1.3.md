- **밸런스 전체 점검**: 영웅 · 적 · 장 난이도를 처음부터 다시 맞췄습니다
- 1장 → 2장 난이도가 갑자기 뛰던 것을 완만하게
- 거너 일제 사격이 보스도 조준
- 버그 수정

## 밸런스 조정

- **1장 잡몹** 체력 배율 0.42 → **0.55**
- **2장 잡몹** 체력 배율 1.6 → **1.2** · 주는 피해 0.8 → **0.65**, **3장 잡몹** 2.16 → **2.0** · 1.08 → **1.0**
- **리치 왕** 체력 0.88 → **0.75** · 공격 **×0.85**, **지옥의 군주** 공격 ×1.3 → **×1.1**, **거울의 군주** 체력 1.65 → **1.8**
- **적 스킬 피해** 접촉 피해의 100% → **80%** (자폭 제외), 심연 거상 균열 추가 **×0.75**
- **검사** 공격력 3.4 → **3.1** · 고유 스킬 배율 2 → **1.7** · 회전 베기 300~800% → **250~700%** · 휘두름 보호 0.3 → **0.2초** · 벤 적당 회복 0.3 → **0.2**
- **시계공** 이중 톱니 85% → **70%** · 분침 +40/60/80/100% → **+30/45/60/75%** · 되감기 400% → **500%**
- **우체부** 덧붙는 편지 40% → **55%**, **유령** 체력 0.8 → **0.9**, **연금술사** 공격 속도 0.75 → **0.8**
- **거너 일제 사격** 보스 조준 추가 (보스 피해 50%)
