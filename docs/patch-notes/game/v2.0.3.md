# 소규모 업데이트 — 재개 카운트다운 표시
창을 닫은 뒤 나오는 3초 카운트다운이 잘 보이게 바꿨습니다.

## 편의성 개선
- 재개 카운트다운 숫자와 「[Space] 즉시 시작」 안내가 영웅 머리 위 판 위에 크게 표시되고, 세는 동안 화면이 살짝 어두워집니다. (전에는 전투 화면에 묻혀 잘 보이지 않았습니다.)

플레이해 주셔서 감사합니다!

# Small Update — Resume Countdown Display
The 3-second countdown after closing a window is now easier to see.

## Quality of Life
- The resume countdown number and the "[Space] Start now" hint are now shown large on a panel above your hero, and the screen dims slightly while it counts. (They used to get lost in the battle.)

Thanks for playing!
