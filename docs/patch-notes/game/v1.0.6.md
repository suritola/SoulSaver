# 1.0.6 업데이트

- 스킬 몸동작 추가
- 보물 상자 · 고르기 창 개선

## 밸런스 조정

- **레벨업 필요 경험치**: 레벨마다 +50 → **+65**
- **일반 적 영혼 조각**: **20%** 감소
- **상점 강화 · 물약 가격**: **1.3배**
- **영웅 특수 무기 · 스킬 · 무기 필살기 피해**: **0.8배**
- **검사**: 체력 200 → **130**
  - 혈갑: 적 하나당 1.2 ~ 3% → **0.6 ~ 1.5%**, 최대 10 ~ 25% → **6 ~ 15%**
  - 영혼 흡수: 4 ~ 10% → **3 ~ 6%** · 최대 10 → **8개**
  - 역습: +30 ~ 75% → **+20 ~ 50%**
  - 거인 사냥꾼: +12 ~ 36% → **+8 ~ 23%**
  - 연속 베기: 강한 일격 2배 → **1.6배**
- **패시브 하향** (괄호 안은 진화)
  - 전투 함성 +40% → **+30%** (+60% → **+45%**) · 불굴 +50% → **+40%** (+80% → **+60%**)
  - 회피 본능 20% → **15%** (30% → **25%**) · 그림자 은신 2배 → **1.7배** (2.5배 → **2.1배**)
  - 강철 갑옷 -15% → **-12%** (-25% → **-20%**) · 약점 간파 +35% → **+25%** (+70% → **+50%**)
  - 기사의 맹세 · 전투 열기 · 연쇄 처치 · 전리품 사냥 · 거리 유지 · 연금 순환 · 도망자의 발걸음 · 비상 물약 · 금속 변환도 소폭 하향
