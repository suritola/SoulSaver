# 1.0.6 업데이트

- 영혼 트리의 **모든 칸에 능력에 맞는 새 아이콘** (같은 그림을 쓰는 칸 없음 · 단계 칸은 아래 구슬로 단계 표시)
- 무기 숙련 · 패시브 진화 칸에 작은 표식 (I · II · III · 진화 등)
- 도감 운명 카드도 트리와 같은 그림으로
- 최대 레벨에 닿으면 더 이상 레벨업 카드를 고를 수 없음
- 우편배달부 밸런스 조정

## 밸런스 조정

- **최대 레벨**: 일반 50 그대로 · 무한 모드 100 → **80**, 최대 레벨에 닿으면 레벨업 카드(성장 카드 포함)를 더 고를 수 없음 (성장 카드는 최대 레벨 전에 카드를 다 배웠을 때만)
- **무한 모드 개발자 필살기 간격**: 0.22초 → **2초** (분노 0.14초 → **약 1.3초**) · **개발자 엄마** 0.11초 → **1초** (분노 0.07초 → **약 0.64초**)
- **개발자 · 개발자 엄마 피해**: 필살기 · 탄 · 접촉 피해 **-20%** (접촉 48 → **38**, 엄마 96 → **77**)
- **우편배달부** (전체 성능 약 40% 하향)
  - 기본 공격력 (거너 대비) 90% → **80%** · 필살기 충전 95% → **87%** · 평타 사거리 14칸 → **12칸**
  - 배달 횟수 (우편 보너스 · 특급 · 머리 위 막대): 모든 편지 → **평타로 직접 보낸 편지만** (등기 · 반송 · 행운의 편지 · 우체통 · 답장 편지는 세지 않음)
  - 우편 보너스 게이지 (배달 10번마다) 5% → **4%**
  - 특급 게이지 +10 / 15 / 20 / 25% → **+8 / 11 / 14 / 17%**
  - 우표 수집: 중첩당 피해 +4 / 8 / 12% → **+3 / 6 / 9%**, 이제 **맞으면 쌓인 우표가 절반 떨어짐**
  - 우표 수집가: 최대 20중첩 → **15중첩**, 특급 게이지 두 배 → **1.5배**
  - 등기 우편 다시 배달 피해 80% → **65%** · 반송 불가 최대 3번 → **2번**
  - 다발 배송 · 총알 배송 덧붙은 편지 피해 50% → **40%**
  - 배달 경로 편지 피해 +15 / 22 / 29 / 36% → **+10 / 15 / 20 / 25%**
  - 속달 표식 6 ~ 20개 → **5 ~ 15개** (등기 표식 9 ~ 30개 → **8 ~ 22개**) · 표식 하나 피해 공격력 200 ~ 400% → **180 ~ 320%**
  - 답장: 속달 한 번에 제한 없음 → **최대 10통**
  - 영수증 회복: 배달할 때마다 → **0.3초에 한 번**

# 1.0.6 Update

- **Every Soul Tree node has a new icon** that matches its ability (no two nodes share one · tiered nodes show their tier with small orbs)
- Small marks on weapon mastery · passive evolution nodes (I · II · III · Evolve, etc.)
- Fate cards in the Codex use the same art as the tree
- Once you reach max level you can no longer pick level-up cards
- Postman balance changes

## Balance Changes

- **Max level**: Story stays 50 · Endless 100 → **80**; at max level you can no longer pick level-up cards (including Growth cards — those appear only if you learn every card before max level)
- **Endless Developer ultimate interval**: 0.22s → **2s** (enraged 0.14s → **~1.3s**) · **Developer's Mom** 0.11s → **1s** (enraged 0.07s → **~0.64s**)
- **Developer · Developer's Mom damage**: ultimate · bullet · contact damage **-20%** (contact 48 → **38**, Mom 96 → **77**)
- **Postman** (overall power about 40% lower)
  - Base attack (vs. Gunner) 90% → **80%** · Ultimate charge 95% → **87%** · basic attack range 14 → **12 tiles**
  - Delivery count (Mail Bonus · Express · overhead bar): every letter → **only letters you send with basic attacks** (registered · returned · lucky letter · mailbox · reply letters no longer count)
  - Mail Bonus gauge (every 10 deliveries) 5% → **4%**
  - Express gauge +10 / 15 / 20 / 25% → **+8 / 11 / 14 / 17%**
  - Stamp Collection: damage per stack +4 / 8 / 12% → **+3 / 6 / 9%**, and **getting hit now drops half your stamps**
  - Stamp Collector: max 20 stacks → **15**, Express gauge ×2 → **×1.5**
  - Registered Mail re-delivery damage 80% → **65%** · Return to Sender max 3 → **2** times
  - Bulk Delivery · Bullet Delivery extra letter damage 50% → **40%**
  - Delivery Route letter damage +15 / 22 / 29 / 36% → **+10 / 15 / 20 / 25%**
  - Express marks 6 ~ 20 → **5 ~ 15** (registered marks 9 ~ 30 → **8 ~ 22**) · damage per mark 200 ~ 400% → **180 ~ 320%** of attack
  - Reply: unlimited per Express → **up to 10 letters**
  - Receipt healing: on every delivery → **once every 0.3s**

- **郵便屋**（全体性能を約40%下方修正）

  - 切手コレクター：最大20スタック → **15**、速達ゲージ2倍 → **1.5倍**
  - 書留の再配達ダメージ 80% → **65%**・返送不可 最大3回 → **2回**
  - まとめて配送・弾丸配送の追加の手紙ダメージ 50% → **40%**
