# 1.0.5 Update

- **Gamepad support!** (Xbox layout · Steam Deck and PlayStation pads use the same layout through Steam Input)
- Combat: left stick move · right stick aim (tilt to auto-fire) · RT attack · LT ultimate · A interact · X reload · Y swap weapon · RB / LB / L3 skills · View Soul Tree · Menu pause
- Menus · windows: left stick · D-pad move the cursor, A presses, B goes back · on card screens pick with D-pad ← → and confirm with A
- On-screen prompts switch to pad button names like [RT] · [A] based on the last device you used
- See the pad layout in Settings → Controls
