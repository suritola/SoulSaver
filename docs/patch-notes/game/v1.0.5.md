# 1.0.5 업데이트

- 장 중반 이벤트 · 저주 제단 추가
- 보스 보상 3택 추가
- 영웅 숙련도 추가
- 빌드 시너지 추가
- 게임 오버 화면에 쓰러진 원인 표시

## 밸런스 조정

- **거너 1차 진화**
  - 쌍발 총구: 덤 총알 피해 70% → **60%**
  - 화염 총구: 피해 30% → **45%**, 사거리 4.5 → **5칸**
  - 영혼 탄두: 충전탄 250% → **300%** · 점착탄 80% → **110%** · 산탄 총구 45% → **55%**
  - 영혼 사냥: 2발 → **3발**, 50% → **60%**
  - 낙뢰탄: 8번 → **6번**마다, 120% → **150%**
  - 사신의 탄환: 확률 25% → **35%**, 150% → **180%**
- **이동 속도 상한** (모든 영웅): 기본의 1.3배까지는 그대로, 넘는 몫은 40%만, 최대 **1.7배**

- **Gunner 1st evolution**
  - Twin Muzzle: bonus bullet damage 70% → **60%**

  - Soul Warhead: charged shot 250% → **300%** · sticky shot 80% → **110%** · shotgun muzzle 45% → **55%**

  - Thunderbolt Rounds: every 8 → every **6**, 120% → **150%**
  - Reaper Rounds: chance 25% → **35%**, 150% → **180%**
- **Move speed cap** (all heroes): unchanged up to 1.3x base, only 40% of the excess counts, max **1.7x**
