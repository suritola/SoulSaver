# 1.1.7 업데이트

- **무한 모드 초반 난이도 완화**
- **무한 모드 첫 보스가 더 늦게 등장**

## 밸런스 조정

- **무한 모드 처음 5분** 잡몹 체력 ×1 → ×0.5 · 받는 피해 ×1 → ×0.6 · 보스 체력 ×1 → ×0.5 · 적 · 보스 스킬 간격 ×1 → ×1.5 (5분부터 9분까지 서서히 원래대로)
- **무한 모드 첫 보스 등장** 1분 30초 → 4분 (이후 보스 간격 · 15분 최종 국면 · 한계 돌파는 그대로)
- **무한 모드 첫 중간 보스** 약 30초 → 1분 30초 이후
- **무한 모드 강한 적 등장 조건** 처치 수만 → 처치 수 + 시각 (불 지옥 1:30 · 초원 3:30 · 심연 6:00 · 심연 거상 8:00 이후)
- **무한 모드 보스 부하** 모든 적 중에서 → 지금 나오는 적 중에서
- **무한 모드 첫 바퀴 두 번째 보스(지옥의 군주) 체력** ×1 → ×0.5
