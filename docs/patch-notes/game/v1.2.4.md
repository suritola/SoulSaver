# 1.2.4 업데이트

- **최적화:** 적과 탄이 많이 몰리는 후반 · 무한 모드 · 보스전에서 프레임이 더 안정적입니다. 오래 플레이할수록 조금씩 쌓이던 메모리도 정리했습니다.

# 1.2.4 Update

- **Optimization:** Frame rate is more stable in the late game, Endless Mode, and boss fights when many enemies and projectiles pile up. Memory that slowly built up during long sessions is now cleaned up.
- **Added "Graphics Quality" to the Display tab.** "Low" only reduces decorative effects such as trails, sparks, and glow, so the game runs smoothly on lower-end PCs.
- Fixed the middle level pip on skill icons looking broken.
