# Soul Saver 1.0.4 패치노트 — 첫 구매자 점검 81개 항목 · 무한 모드 「개발자 엄마」 · 끝없는 성장 · 이어하기 · 코인 최적화

## 🧭 첫 구매자 점검 (81개 항목, 게임패드 지원은 다음에)

처음 산 플레이어의 여정(첫 실행 → 튜토리얼 → 전투 → 레벨업 → 결과 → 메타 성장 → 설정)을 따라가며 찾은 불친절 · 불쾌 요소를 고쳤습니다. 점검 보고서: `docs/review/2026-10-14-첫구매자-점검.md`

### 첫 실행 · 메인 메뉴 · 저장
- 처음 켜면 스팀 → OS 언어로 자동 선택, 첫 실행에 4개 언어 고르기 창
- 패치노트는 새 버전일 때만 자동으로 뜸 (처음 산 사람의 첫 실행에는 안 뜸)
- 첫 게임 시작 때 「튜토리얼부터 해 볼까요?」
- 고른 난이도의 배율 설명을 늘 표시, 잠긴 일일 도전은 흐리게 · 「잠김」 · 여는 방법 툴팁
- 게임 종료 확인, 확인 창 ESC = 취소
- 이어하기가 메뉴의 난이도 · 캐릭터 선택을 덮어쓰지 않음, 이어하기 버튼에 난이도
- 저장 파일 보호: `.bak` 백업, 읽기 실패 시 `.tmp` → `.bak` 순서로 되살림, 그래도 안 되면 깨진 파일을 남기고 알림 창
- 체험판: 「상점 페이지 보기」, 체험판 기록이 정식판으로 이어지지 않는다는 안내

### 튜토리얼 · 도움말
- 첫 판 장 제목 · 조작 도움말은 시작 카드 창을 닫은 뒤에
- 도움말 줄 세우기 (하나씩, 멈춘 동안은 기다림, 다 보인 뒤에만 「봤음」), 설정에 「도움말 다시 보기」
- 튜토리얼: 그만두기 확인 · 단계 건너뛰기 · 「경고 피하기」 단계 · HUD 짚어 주기 · 완료 화면 「바로 첫 판 시작」 · 메뉴 완료 체크
- 필살기 단계는 실제로 조준해야, 재장전 단계는 직접 눌러야 통과
- 이야기 건너뛰기는 ESC 두 번, 대사는 클릭 · 확정 키로 넘김 · 「레벨업 카드」로 용어 통일

### 전투 공정성 · 연출
- 보통 · 어려움에서 잡몹 경고 원 · 띠도 예고 배율을 따름 (다 차기 전에 공격 없음), 구울 도약 원은 착지까지
- 돌진 경고 띠를 판정 지름에 맞춤 (지옥견 · 화염 돌진 · 킹 슬라임 구르기)
- 보스전 한 대 피해 최대 체력 40%까지, 쓰러진 보스 몸 접촉 피해 없음
- 결계 컷신: 클릭 · Space 건너뛰기, 두 번째부터 1초, 번쩍임 / 흔들림 설정 반영 · 스킬 / 무기 진화 섬광도
- 지옥의 군주 33% 분노 알림, 습격 남은 적 · 시간 표시 · 실패 알림, 리치 왕 영혼구 · 뼈 감옥 사망 원인

### HUD 의미
- HUD 칸 위를 겨눠도 평타가 멈추지 않음, 전투 중 설명은 잠깐 머물러야 뜸
- 체력 옆 금빛 ◆ = 남은 「최후의 보루」, 한 방 피해에도 발동
- 보스 결계 게이지 이름 · 설명, 보스 한 마리일 때도 체력 숫자, 영웅 머리 위 막대 이름표
- 저주 받은 장은 시계 옆에 효과 표시, 피해 숫자 끄기가 받은 피해에도, 큰 피해 숫자 금빛
- 능력치 창 행운 아이콘, 탄을 안 쓰는 영웅은 재장전 「-」

### 레벨업 · 카드 · 진화
- 숫자 키는 고르기 · 같은 숫자 한 번 더 = 확정 (레벨업 · 보스 보상 · 무기 진화)
- 「건너뛰기」 → 「이번 레벨업 포기」 두 번 누르기 (무료 카드 창에선 숨김)
- 다시 뽑기: 열린 직후 입력 보호, 방금 본 카드는 다시 안 나옴
- 보스 보상 · 저주 제단 · 보물 상자 창 열린 직후 클릭 보호
- 스킬 · 무기 진화 연출 건너뛰기, 최대 레벨 MAX, 새 영웅 4명 시너지 · 배지 설명

### 죽음 · 결과 · ESC
- 끝까지 깨면 엔딩 뒤 결과 화면 (「클리어!」 · 기록 · 포인트 · 다음 해금)
- 결과 화면 [R] 재시작은 1초 뒤부터, 안 연 보물 상자는 다음 장으로 가져감
- 1분마다 자동 저장, 일시정지 메뉴에 「다시 시작」 · 「게임 종료」

### 메타 성장 · 상점 · 해금
- 알림판 줄 세우기 (해금 · 클리어 알림이 덮이지 않음)
- 메뉴 포인트 툴팁, 게임 화면 「POINT」 번역, 잠긴 영웅 능력 미리 보기 (실루엣)
- 영웅 구매 · 영혼 트리 칸은 두 번 눌러 확정, 코인 부족 시 빨간 가격 · 「코인이 부족합니다」
- 보스 300P · 중간 보스 100P, 떠돌이 상점 15초 · 놓치면 다음 상점이 빨리
- 재촉 배너 · 종소리는 한 번 쌓일 때 최대 2번 (보스전엔 종소리 없음)
- 캐릭터 화면 「필살기 충전」 안내 바로잡음, 도감 상점 설명 · 가지 이름 · 적 / 보스 순서

### 설정 · 문구 · 번역
- 설정 → 조작에서 공격 · 필살기 키 변경 (마우스 옆 버튼 · 휠 클릭 지정 가능), 바꾼 키가 안내 문구 전체에 반영
- 영혼 트리 아래 Shift 빠른 배우기 · C 가운데로 안내
- 설정 항목마다 마우스 설명, 「키 아이콘」 설정 삭제, 「내 이펙트 불투명도」
- 영어 · 중국어 번역 다듬기 (「발」, 필살기 · 궁극기 · 게이지 용어, 산성 범람), 결과 화면 「쓰러졌다...」, 문 카운트다운 문구 공통화

## 🎯 적 · 보스 히트박스

- 그래픽 교체 뒤 아래로 치우쳐 있던 판정 원을 그림(불투명 부분) 가운데로, 좌우 뒤집기도 따라감
- 맞는 판정은 예전 반지름의 1.25 ~ 1.6배 (작은 적도 반드시 커지고, 장식이 큰 보스는 지나치지 않게)
- 닿기 피해는 몸 안쪽만 (예전보다 넓어지지 않음), 밀어내기 · 벽 판정은 예전 크기

## 💾 이어하기

- 화면 위 진행 시간이 00:00 으로 돌아가지 않고 이어 셈
- 같은 장이면 나갈 때 서 있던 곳에서 (보스전 중이면 장 시작점에서)
- 이미 지난 습격 · 엘리트가 한꺼번에 다시 나오지 않음, 진행 중이던 습격(남은 수) · 살아 있던 중간 보스 · 안 연 상자는 되살림
- 보스 처치 뒤 · 사망 연출 중 · 문 진입 중에 나가도 보스 보상 · 첫 문 특수 능력 · 포인트 +2 · 저주 제단을 이어할 때 받음
- 최후의 보루 다시 채워지지 않음, 받은 피해 · 진화 시각 기록 유지

## 👻 유령 「빙의」

- 지속 1초 → 3초, 빙의한 동안 그 적의 실제 이동 속도로 몸을 끌고 다님 (내 평소 속도의 30% ~ 130%)
- 무적은 들어가 있는 동안 계속 + 터진 뒤 0.65초, 무기 필살기 추가 발동은 터지는 순간 터진 자리에서

## 👩 무한 모드 — 개발자 · 개발자 엄마

- 최후의 시간 30분 → 15분
- 개발자: 체력 300,000 (난이도 배율 없이 고정), 필살기 0.22초(분노 0.14초)마다 겹쳐 씀 (동시 8개 · 적 탄 400발 상한), 등장 뒤 잡몹 · 습격 · 중간 보스 · 부하 없음
- 30분에 새 보스 「개발자 엄마」: 체력 600,000, 필살기 0.11초(분노 0.07초) · 동시 16개, 피해 · 이동 속도 · 접촉 피해 2배, 분홍빛 1.3배 몸, 대사 「우리 아들 괴롭힌 게 너니?」
- 개발자와 엄마를 모두 쓰러뜨려야 클리어 (해금 조건 문구도), 도감 보스 탭에 둘 추가
- 개발자의 영웅 필살기 9종이 플레이어와 같은 Fx · 색 · 크기 · 소리 · 시작 섬광으로, 거너 필살기는 플레이어 · 플레이어 탄이 느려짐 (겹쳐도 쌓이지 않음, 탄막 파도 4 → 2)

## 📈 끝없는 성장

- 레벨업 카드를 다 배웠거나 최대 레벨 뒤에도 경험치가 쌓이고 레벨업마다 성장 카드 (힘 +3% · 생명 +5 · 손놀림 +2% · 발걸음 +1%, 상한 없음) — 예전 「비상 보급」 대신
- 영혼 트리를 다 배우면 「영혼 정련」: 피해 +2% · 최대 체력 +4, 영혼 조각 40부터 +10씩
- 레벨 표시 「MAX +n」, 능력치 창 · 결과 화면 · 도감에 표시, 이어하기 기록

## 🎨 그 밖에

- 플레이어(몸 · 무기 · 머리 위 표시)를 맨 위 정렬 레이어 「Player」로 — 모든 이펙트 위에 보임 (UI · 화면 전체 연출은 그대로 위)
- 코인 최적화: 코인 물리 판정 제거 (관리자 하나가 줍기 · 자석 계산), 한 번에 떨어지는 코인 일반 8 · 보스 40개로 합침 (값이 큰 코인은 크고 반짝임), 바닥 상한 220개, 풀링, 줍는 반짝임 프레임당 3개 — 받는 코인 총량은 그대로
- 우체부 해금 조건 「쉬움」 15분 → 20분 안 클리어
