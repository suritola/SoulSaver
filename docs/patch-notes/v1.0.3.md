# Soul Saver 1.0.3 패치노트 — 결과 화면 「다음 해금까지」 · 스킬 진화 도감 미발견 표시

## 🎯 결과 화면에 「다음 해금까지」

판이 끝난 결과 화면에서 다음 목표가 바로 보이도록 결과 요약 위에 두 줄을 더했습니다.

- **캐릭터**: 아직 해금하지 않은 가장 가까운 캐릭터 하나
  - 조건을 아직 채우지 못했으면 해금 조건을 보여 주고, 「무한 모드 10분 버티기」 조건이면 지금 최고 기록도 함께 (예: 최고 기록 7:42 / 10:00)
  - 조건은 채웠지만 포인트가 모자라면 남은 포인트
  - 바로 해금할 수 있으면 「지금 해금할 수 있습니다! (메인 메뉴 → 캐릭터)」
- **스킨**: 지금 캐릭터가 쓸 수 있는 스킨 중 가장 싼 것 하나 — 남은 포인트, 또는 「지금 살 수 있습니다! (메인 메뉴 → 스킨 상점)」
- 데모 · 튜토리얼에서는 나오지 않습니다

## 📖 스킬 진화 도감 — 아직 발견하지 못한 진화

- 한 번도 만든 적 없는 진화는 이름이 **「???」**, 아이콘이 검은 실루엣으로 나오고 설명 대신 힌트가 나옵니다
  - 재료 카드는 그대로 보이므로 무엇을 모으면 되는지는 알 수 있습니다
- 도감 제목 옆에 탭마다 **「발견 n / 전체」**
- 이 PC 에서 만든 진화 기록(도전 과제 「서로 다른 진화 15종」과 같은 기록)을 씁니다. 「모든 캐릭터」 탭의 진화는 어느 캐릭터로 만들었든 발견으로 칩니다
- 새 문구는 한국어 · 영어 · 일본어 · 중국어
