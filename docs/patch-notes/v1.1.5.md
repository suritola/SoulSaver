# Soul Saver 1.1.5 패치노트 — 무한 모드 한계 돌파 · 스팀 순위

## ♾ 무한 모드: 클리어 뒤 「한계 돌파」
- 개발자 · 개발자 엄마를 모두 쓰러뜨려도 엔딩으로 넘어가지 않음 — 클리어 기록 · 해금 · 업적 · 「무한 모드 클리어!」 알림은 그대로, 5초 뒤 「한계 돌파! 이제 쓰러질 때까지 버텨라」
- 한계 돌파(`EndlessMode.finalStage 4` · `Beyond`): 잡몹 · 습격 · 중간 보스 다시, 보스 20초 뒤부터 주기적으로, 적은 시간에 따라 계속 강해짐(MobRamp · Surge), 최종 보스 곡을 끄고 평소 · 보스 곡, 초월 카드 다시, 화면 위 「클리어 뒤 · 한계 돌파」 — 죽을 때까지 기록이 늘어남

## 🏆 스팀 순위 창 (`LeaderboardUI.cs`, `LocTable.Leaderboard.cs`)
- 메인 메뉴 오른쪽 위 「순위표」 · 무한 모드 결과 화면 「순위 보기」(내 주변 탭) · 일일 도전 창 「전체 순위 보기」
- 순위표 고르기: 무한 모드 / 일일 도전(오늘). 탭: 전체 상위 1~100(순위 밖이면 내 줄을 맨 아래) · 내 주변 −5~+5 · 친구
- 줄: 순위(1~3위 금 · 은 · 동) · 영웅 아이콘 · 스팀 이름(늦게 오면 다시 씀, 한자 □ 방지) · 보스 처치 · 버틴 시간, 내 줄 금빛. 요약 줄 내 최고 · 내 순위 · 전체 인원, 「내 순위로」
- 상태: 불러오는 중 · 스팀 연결 없음 · 실패(15초) · 기록 없음 · 이번 판 기록 올리는 중(결과 화면에서 열면 다 올린 뒤 받음)
- 키보드 ←/→ 탭 · Tab 순위표 · ↑/↓ · PageUp/Down · Home/End · ESC, 패드 십자키 좌우 탭 · 오른쪽 스틱 목록 · B 닫기
- 제출: 점수는 버틴 초 그대로, 자세한 값 영웅 · 보스 · 레벨 · 처치 · 판 버전 5칸. 순위 창을 열면 이 PC 의 최고 기록이 스팀보다 좋을 때 한 번 올림
- 체험판에서는 숨김, 스팀이 없으면 안내만
- 같이 고침: 순위 창이 떠 있을 때 결과 화면 [R] 다시 시작이 먹던 것, 일일 도전 창 ESC 가 다른 창 ESC 까지 받던 것
