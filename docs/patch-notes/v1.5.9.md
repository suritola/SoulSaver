# v1.5.9 (2026-10-24)

스팀 공지 V1.3.2 (1.5.8 + 1.5.9 합침 · 1.5.7 잠수함 패치는 적지 않음)

전체 코드 감사: 영역 14개에서 94건을 찾고 항목마다 검증 2명이 반박 검토 → 둘 다 확인 82건 + 의견 갈림 4건 중 84건 수정 (커밋 b1fecbd), 그룹 7개마다 독립 검토.

## 보스 (boss · PlayerController · BossSkills*)
- 거울의 군주 빙의 · 돌진 · 회전 베기 · 검사 평타 흉내, 개발자 빙의: 순간이동 직후 몸통 접촉(반지름 약 5.5칸)이 경고보다 넓어 피할 수 없게 맞음 → `boss.noContactUntil` (Time.time 시각 값, 끊겨도 저절로 풀림) 동안 몸통 피해 없음

## 판 진행 (StageManager · StoryDirector · WeaponEvolutionUI · ESCmenu · Demo)
- 쓰러지는 중 보스 처치: 진화 창을 띄우지 않음, WeaponEvolutionUI.Open 씬 전환 때 초기화, 엔딩 도중 파괴되면 EndingPlaying · Playing 되돌림 (ownsEnding)
- 장 전환 중(Transitioning) ESC 무시 · 전환 끝 timeScale 은 ESC 열림이면 0 유지
- 보스 사망 자리의 신전 문에 바로 들어가도 BossReward 는 새 장에서 뜸
- 체험판 끝 창이 떠 있으면 ESC 메뉴 안 열림

## 영웅 (CharacterKit* · Bullet · PlayerController)
- 필살기 조준 · 충전 중 멈춤(ESC · 레벨업 · 영혼 트리)이면 조준 취소 · 게이지 유지 (CancelUltForPause)
- 거너 일제 사격 조준 중 영혼 트리 · 진화 창: 먼저 CancelSkill
- 우체부 속달 표식 0개면 게이지 안 씀
- Bullet.onHitBoss 추가 → 궁수 천공 게이지가 보스 명중에도 참
- 시계공 보스 눈금(검증 의견 갈림)은 밸런스 변경이라 안 고침

## 적 (EnemySkill · EnemySpawn · EnermyController · TargetMark · MapProps)
- 습격 스폰이 맵 가장자리에서 플레이어 바로 옆에 몰리던 것 → 반대편 · 일반 스폰 자리로
- 빙결 · 속박 · 시간 정지 중 적 스킬 안 씀, 보스 처치 연출 중 적 스킬 멈춤 · 장판 정리
- 공허의 시선 광선 판정 = 예고 부채꼴
- 필살기 조준 표식이 보스 처치 가능 여부 표시
- 시간 정지 두 개 연달아 주우면 뒤의 것이 먼저 풀리던 것

## 카드 (SpecialAbilities* · SignatureSkills · SoulWeight)
- 희생의 계약이 공격 속도 · 피해 배율을 덮어쓰던 것 → 곱했다 되돌리기
- 운명 바꾸기 사라짐, 이어하기 부활 재충전, 공격력 패시브 중 트리 칸 구매, 연금 순환 · 거너 유물 스킬, 시간 왜곡 · 분신 전역 값, 각성 HUD, 유물 조준형 스킬 미리보기
- 영혼의 무게 5+ (다시 뽑기 없음) 에서 다시 뽑기 트리 칸 안 나옴
- HUD · 설명 수치를 실제 효과와 맞춤 (새 영웅 궁극기 % · 마름쇠 12 → 20 등), 공명 효과가 카드 없이 알림만 뜨던 것

## 레벨업 · 상점 (LevelShop* · ShopStall)
- ESC 로 나갈 때 열린 카드 저장, 다시 뽑기 0.45초 잠금, 제단 둘 이상 근처 판정(프레임 기준), 최대 레벨 근처 레벨업 집계

## 저장 · 텔레메트리 (RunSave · Prefs · RunStats · Telemetry · analyze.py)
- 이어하기 뒤 보스 보상 창에서 끄면 장 클리어 보너스 중복 → 막음
- .bak 복구 직후 바로 저장
- 판 결과에 saved(저장하고 나감) · closed(게임 끔) 추가, 이어한 판 resumed_secs · resumed_kills, 줄마다 run_id → analyze.py 가 짝지어 중복 제거 (1.5.8 이전 quit 와 뜻이 다름)
- 보낸 줄은 바로 큐에서 지움 (전송 중 종료 시 중복 방지)

## 메뉴 · 성능
- 어려움 선택 시 영혼의 무게 줄이 도감 버튼과 겹침, 시작 연출 넘김 입력이 뒤 창 닫음, 도감 수집 보상 창 ESC · 받음 글 위치, 더 보기 NEW 표시, 출석 토스트 시점
