# Soul Saver v1.2.8

무한 모드 이어하기 시계가 00:00 에 멈추던 치명적인 문제와, 1.2.7 보스 무적 수정 뒤 독립 검토에서 찾은 멈춤 위험을 고친 긴급 패치입니다.

## 고친 버그

- **무한 모드 이어하기 시계가 00:00 에 멈추던 문제 (치명)**: 시계 시작 시각을 「지금 − 저장한 경과 시간」으로 잡는데, 켜짐을 「시작 시각 ≥ 0」으로 봐서 게임을 켜자마자 이어하면(`Time.time` < 저장한 시간) 시작 시각이 음수가 되어 시계가 멈췄습니다. 실제 시간이 저장한 시간을 따라잡을 때까지 15:00 최후의 시간 · 적 증가 · 이정표도 0초로 계산됐습니다. 켜짐을 따로 플래그로 봅니다 (`GameMode.StartEndlessClock`).
- 끊긴 리치 「망자의 의식」은 8초 뒤에 다시 합니다 (결계 · 침식이 끝나는 프레임에 바로 다시 무적이 되지 않게).
- 지옥의 군주 내려찍기 · 공중 탄막 · 리치 의식이 끊기면 땅 자리로 내려놓습니다 (12칸 위에 떠 있지 않게).
- 스킬 감시: 보스 스킬이 40초 넘게 끝나지 않으면(코루틴 예외) 끊고 무적 · 시전 상태를 정리합니다.
- 보스 시작 처리 순서를 바꾸고(체력바 · 스킬 · 결계 먼저), 체력바가 없어도 매 프레임 처리 · 처치 처리가 멈추지 않게 했습니다.
- 처치 처리 중 예외가 나도 보스를 지웁니다 (다음 보스 · 최종 국면이 막히지 않게).
- 장면을 시작할 때 결계 · 침식 · 연출 · 개발자 대기 상태도 비웁니다.
