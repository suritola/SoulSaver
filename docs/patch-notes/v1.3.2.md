# Soul Saver v1.3.2

게임 버전을 스팀 공지 번호에 맞췄습니다 (스팀 공지 V1.3.1 = 게임 1.2.6 다음). 스팀에 공지하지 않은 긴급 패치 1.2.7 · 1.2.8 의 내용과 이번 수정을 이 버전에 모두 담았습니다 (자세한 노트: `docs/patch-notes/merged/`).

## 고친 버그

- **결과 화면 UI 가 메인 메뉴 · 다음 판까지 화면 맨 위에 남아 쌓이던 문제 (치명)**: UI 를 붙일 캔버스(`UIKit.HudCanvas`)가 장면이 바뀌어도 남는 캔버스(FPS 표시 · 장면 전환 막, 정렬 32000)를 고를 수 있었습니다. 탄약 패널이 없는 결과 화면에서 FPS 표시를 켰으면 결과 UI 전체가 거기 붙어 사라지지 않았습니다. 지금 장면의 캔버스만 고르고, 두 캔버스는 장면마다 자기 것이 아닌 자식을 지웁니다.
- **무한 모드 이어하기 시계가 00:00 에 멈추던 문제 (치명, 1.2.8)**: 게임을 켜자마자 이어하면 시계 시작 시각이 음수가 되어 「시작 시각 ≥ 0」 조건에 걸렸습니다. 켜짐을 따로 플래그로 봅니다.
- **보스가 영원히 무적이 되던 문제 (치명, 1.2.7)**: 공간 침식 · 결계 시전 대기가 리치 「망자의 의식」을 끊으면 무적이 남았습니다. 끊을 때 무적 · 공중 · 받는 피해 배율을 늘 되돌리고 의식은 8초 뒤 다시 합니다. 스킬이 돌지 않는데 상태가 남으면 매 프레임 되돌리고, 40초 넘게 끝나지 않는 스킬은 끊습니다.
- **공간 침식 게이지가 가득 차도 발동하지 않던 문제 (치명, 1.2.7)**: 무적 · 공중 보스를 시간 제한 없이 기다려 침식 · 새 보스 · 15:00 최후의 시간 · 보스 스킬이 모두 멈췄습니다. 3초가 지나면 끊고 시작합니다.
- 슬라임 대점프 · 지옥의 군주 내려찍기 · 공중 탄막이 끊기면 땅 자리로 내려놓습니다.
- 보스 시작 처리 · 처치 처리 중 예외가 나도 진행이 막히지 않게 했습니다 (ready 보장, 체력바 없음 대비, 처치 뒤 반드시 지움). 장면 시작 때 결계 · 침식 · 연출 · 개발자 대기 상태도 비웁니다.
- 무한 모드 · 일일 도전 중 게임을 끄면 판을 끝내 순위표에 올린 뒤 끕니다 (`EndlessQuit`, 최대 4초 대기).
