# Soul Saver v1.2.6

1.2.0 이후 추가 · 변경분 전체를 그래픽 · 밸런스 · 사운드 · 시스템 네 갈래로 다시 검증한 패치입니다. 정적 분석 14건과 실제 게임 화면 배치 캡처(QA 도구 `tools/qa`, 9회)로 찾고 반박 검증으로 확정한 25건을 고쳤습니다.

## 고친 버그

- **왕들의 영토 지형이 칠해지지 않던 문제 (치명)**: 씬 타일맵의 타일이 모두 z 100 에 있는데 `EndlessTerrain` 이 z 0 칸을 읽어, 칠할 수 있는 칸이 0개였습니다. 층마다 실제로 타일이 있는 z(`TileZ`)를 찾아 쓰게 했습니다. 영토 번짐 · 용암 / 늪 웅덩이가 생기는 것을 화면으로 확인했습니다.
- 결계 · 공간 침식 중 용암 피해 · 늪 느려짐을 주지 않고, 「고요의 눈」이 웅덩이 근처에 생기지 않게 했습니다. 웅덩이를 지형 타일 바로 위 정렬 층으로 옮겼습니다.
- 15:00 「최후의 시간」이 결계 · 침식 중에 시작되지 않게 했습니다. 침식에 들지 않은 보스도 침식 밖으로 밀어냅니다.
- 다중 보스 체력바: 「기억」 줄과 결계 게이지 겹침을 정리하고, 보스가 셋 이상이면 추가 바를 0.6 크기로 줄였습니다. 최종 국면 보스 등장 간격 4.5 → 7.
- 엄마 「잔소리」 글자를 화면 아래쪽으로 옮기고, 일시정지 · 설정 창에서는 숨깁니다.
- 메인 메뉴 · 결과 화면에서 공용 효과음이 없어 소리가 나지 않던 문제(메뉴 전용 오디오), 정의되지 않은 `coin` 소리를 `sparkle` 로.
- 공간 침식 중에는 결계 공격이 아닌 피해도 한 대 상한 25% 를 적용합니다.
- 이어하기: 보스 보상 가운데 칸을 저장해 같은 칸이 나오고, 풍화 배율을 바로 복원해 알림이 다시 뜨지 않으며, 되살린 보스의 자리를 최종 국면과 같게 했습니다.
- 게이지가 찬 뒤 3초가 지나도 시전 중인 보스는 시전을 끊고 결계를 펼칩니다.
- 보스 인트로가 선택 창이 닫힐 때까지 기다립니다.
- 적의 찌그러짐이 되돌아가지 않고 쌓여 크기가 무한대 · 위치가 NaN 이 될 수 있던 문제를 막았습니다.
- 일시정지 메뉴의 적 설명이 버튼을 가리지 않게, 언어 변경 때 「포인트」 글자가 바로 바뀌게, 거울의 군주 알림의 「을(를)」을 받침에 맞게.
- 도감 비밀 탭의 개발자 · 엄마 카드에서 잘리던 결계 문장을 빼고 보스 탭에만 둠.

## 밸런스 조정

- 보스 보상 가운데 칸 후보: 「생명」 · 「회복」 포함 → 제외
- 보스 보상 가운데 칸 (이어하기): 이어할 때마다 새로 뽑음 → 처음 뽑은 칸 그대로
- 공간 침식 중 결계 공격이 아닌 피해의 한 대 상한: 최대 체력 40% → 25%
- 결계 · 침식 중 용암 웅덩이: 0.6초마다 6 피해 → 피해 없음 (늪 느려짐도 없음)
- 시전 중인 보스의 결계: 시전이 끝날 때까지 대기 → 게이지가 찬 뒤 최대 3초 뒤 시전을 끊고 펼침

## 그 밖에

- 상점 트레일러: 자막 없이, 합성 배경음 · 인게임 효과음 · 리미터, 원거리 영웅 카이팅, 새 끝 카드.
- QA 배치 캡처 도구 `tools/qa` (QaCapture.cs · qa.ps1).
