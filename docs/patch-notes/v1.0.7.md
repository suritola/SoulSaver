# Soul Saver 1.0.7 패치노트 — 궁수 정조준 · 매복 조건 변경 · 개발자 체력 10만 · 필살기 간격 체력 비례 · 잡몹 복귀

## 🏹 궁수 정조준 · 매복

- 정조준이 아예 안 되던 원인: 멈춰 있던 시간(`CharacterKit.stillTime`)을 몸 그림이 6장 이상일 때만 셌음 → 그림 장수와 상관없이 늘 셈 (지도 제작자 현지 안내 · 기사 기세 판정도 같이 고쳐짐)
- 정조준: 「가만히 서서 당기면」 조건을 없애고 상시 효과로 — 당기는 속도 +30 / 60 / 90% → +25 / 50 / 75%
- 매복: 「2초 동안 움직이지 않으면」 → **가득 당겨 쏠 때마다 발밑에 덫 (2초에 한 번)**
  - 반경 2.2 → 3.2, 묶는 시간 1 ~ 2.5초 → 1.5 ~ 3초
  - 걸릴 때 공격력 80% 피해, 묶인 동안 받는 피해 +30% (명궁의 호흡이면 2배)
  - 같은 적이 3초마다 다시 걸림 (예전: 덫 하나에 한 번), 덫 동시에 최대 3개 · 8초 유지
- 카드 설명 4개 언어

## 👨‍💻 무한 모드 개발자 · 개발자 엄마

- 체력: 개발자 30만 → 10만, 엄마 60만 → 30만
- 싸우는 동안 일반 잡몹이 다시 나옴 (습격 · 중간 보스 · 보스 부하는 지금처럼 나오지 않음)
- 유령(빙의) 필살기는 쓰지 않음 (8명 필살기만 돌림)
- 필살기 간격을 체력에 따라: 가득 찼을 때 10초 → 바닥에서 1초 (엄마 5초 → 1초), 분노 구분 없앰
- 한 번에 끝나던 필살기를 여러 번: 궁수 화살비 4 · 5번 → 8 · 10번, 연금술사 대폭발 2 · 3번 → 5 · 6번 (불꽃놀이 2배), 우체부 속달 1번 → 3 · 4번
- 도감 설명 4개 언어
