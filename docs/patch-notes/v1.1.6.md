# Soul Saver 1.1.6 패치노트 — 전체 피해 하향 · 버그 점검

## ⚖️ 전체 피해 하향
- 플레이어가 적 · 보스에게 주는 모든 피해 ×0.8 (`GameMode.PlayerDamageMul`, `EnermyController` · `bosss.TakeDamage` 입구에서 한 번 — 평타 · 고유 스킬 · 필살기 · 진화 · 초월 · 유물 모두, 피해 숫자 표시도)

## 🐞 1.1.2~1.1.5 버그 점검 (영역 5개 찾기 → 반박 검증 → 수정, 9건 확인 · 같은 버그 2건이라 8건 수정)
- 이어하기 뒤 「전설의 힘」 · 상자 「힘」(ap 기록) 기준 공격력이 달라져 공격력이 저장 때보다 커지던 것 → `RunSave.Data.baseAttack` · `baseMag` 를 저장하고 기록 재생 전에 되돌림 (예전 저장은 재생 전 시작 공격력 기준)
- 개발자 · 엄마가 쓰러지는 순간 최종 보스 곡이 보스 곡으로 튀고, 클리어 때 엄마 곡이 무음 1초 뒤 처음부터 다시 나오던 것 → `FinalBossMusic` 이 처치 처리(devDown · momDown)만 봄
- 1.1.5 한계 돌파 뒤 무한 모드 클리어 보너스 1,500P 가 지급되지 않던 것 → 클리어 순간 한 번 (일일 도전 제외)
- 도감 「개발자 엄마」 설명이 옛 규칙(30분 · 체력 3배), 「개발자」 설명이 「잡몹이 계속 몰려온다」 그대로였던 것 (4개 언어)
- 영혼 정련 툴팁 「비용이 10씩 오릅니다」 → 「5배로 오릅니다」 (4개 언어)
- 도감 초월 카드 설명이 영어 · 일본어 · 중국어에서 한국어로 나오던 것
- 스킬 · 유물 키를 「-」로 바꾸면 얻을 때 「키가 비어 있습니다」로 잘못 안내하던 것
