# Soul Saver 1.1.3 패치노트 — 지도 제작자 평타 개편 · 새 캐릭터 넷 편의성과 버그 수정 · 패치노트 4개 언어

새 캐릭터 넷(지도 제작자 · 시계공 · 우체부 · 유령)을 하나하나 점검해 어렵거나 안 보이던 것, 잘 안 맞던 것을 고쳤습니다.

## 🗺 지도 제작자 평타 개편 — 더 쉽게

- **예전**: 앞 획의 끝에서 이어 그려 직접 도형을 닫아야 안쪽 적이 크게 다쳤습니다 (계획해서 그려야 해서 어려웠음)
- **이제**: 나에게서 마우스 쪽으로 획을 긋기만 하면 됩니다. **세 번째 획마다 획 끝을 감싸는 삼각형이 저절로 닫혀** 안쪽의 적이 크게 다칩니다
- 다음 획에 닫힐 삼각형이 마우스 자리에 금색으로 미리 보입니다 (실제 범위 그대로)
- 관련 효과도 새 방식에 맞춤
  - 지구본(무기 진화): 도형이 **1.5배** 커짐
  - 끊기지 않는 선(카드): 도형 **+15% / 단계**
  - 지름길 · 직행로: 획을 그은 뒤 **1.4초** 동안
- 지도 접기를 멈춤 중에 떼면 게이지만 사라지던 것 수정, 보스 같은 큰 적이 몸에 닿아도 안 맞던 것 수정, 「보물 지도」만 있을 때 보물 표시가 안 보이던 것 수정

## 📊 새 캐릭터 고유 수치가 머리 위에

궁수 · 연금술사처럼 넷 모두 머리 위 막대로 지금 상태를 보여 줍니다.

| 캐릭터 | 막대 |
|---|---|
| 시계공 | 시계 눈금 (다 차면 금빛 깜빡 — 다음 톱니가 정각) · 발밑 시계도 굵고 밝게 |
| 지도 제작자 | 도형까지 남은 획 (다음 획에 닫히면 금빛) |
| 우체부 | 우편 보너스까지 배달 수 · 속달을 누르는 동안은 붙은 표식 수 |
| 유령 | 영혼 수 / 최대 · 적 몸 둘레에 냉기 고리 |

머리 위 막대는 스킬 이펙트에 가리지 않게 위에 그리고, 더 굵고 진하게 했습니다.

## ⏱ 시계공

- 되감기를 누른 채 멈춤 · 레벨업 · 연출 · 쓰러짐이 오면 되감기를 취소 (예전엔 잔상이 남고 나중에 저절로 되감겼음)
- 되감기 경로를 실제로 베는 폭(3.2) 그대로 그리고 도착 범위 고리 표시, 무기 진화 뒤 경로가 사라지던 것 수정
- 도착하면 체력을 되찾을 수 있을 때 도착 고리가 초록빛
- 순간이동(스테이지 넘어감 · 끌려감) 뒤나 지금 벽인 자리로 되감기지 않게, 쓰러지는 중 회복 막음
- 정각의 종이 적을 멈추는 범위를 고리로 표시

## ✉ 우체부

- 가까운 옆 · 뒤의 받는 이 둘레를 편지가 맴돌기만 하다 사라지던 것 수정
- 큰 적 · 보스 몸에 닿으면 배달, 쓰러진 적에게는 배달하지 않고 바로 다른 적으로
- **우체통(무기 진화)과 궁극기 「우체통 행렬」 피해에 숙련 배율이 두 번 곱해지던 것 수정** (설명 수치대로)
- 받는 이에게 붉은 조준 표식, 속달 표식 아이콘이 터질 때까지 머리 위에 남고 쓰러진 적의 표식은 떨어짐

## 👻 유령

- 서리 자국 · 빙의 폭발 · 빙의 여운 · 폴터가이스트의 그림을 실제 판정 크기에 맞춤 (그림이 판정보다 두 배 크게 보이던 것)
- 몸이 여러 조각인 적이 한 번에 여러 번 맞던 것 수정, 얼음 파편이 엉뚱한 적으로 터지던 것 수정
- 빙의한 적이 먼저 쓰러지면 그 자리에서 바로 터짐, 멈춤 중 빙의 조준 취소
- 큰 적 · 보스 몸 위에 마우스를 올려도 빙의 대상으로 잡힘, 터질 범위 미리 보기, 영혼 구슬 크기 0.6 → 0.8
