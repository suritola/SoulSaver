# Soul Saver 플레이 데이터 수집 · 개인정보 처리방침

문서 버전 v1 · 시행일 2026-10-20

Soul Saver 는 게임을 더 좋게 만들기 위해, 플레이어가 **동의한 경우에만** 판이 끝날 때마다 익명의 플레이 기록을 보냅니다. 동의하지 않아도 게임의 모든 기능을 똑같이 이용할 수 있으며, 설정 > 일반에서 언제든 바꿀 수 있습니다.

## 1. 수집하는 항목

- 게임 버전, 정식판 / 체험판 구분, 플랫폼(운영체제 종류), 게임 언어
- 영웅, 난이도, 모드, 판 결과, 플레이 시간, 레벨, 처치 수
- 고른 카드 · 무기 · 스킬 · 갈래 · 진화, 장별 소요 시간, 주고 받은 피해 통계, 쓰러진 원인, 영혼 조각
- 필살기, 도달한 장, 영혼 무게 · 각인 · 유물, 스킬 진화, 갈래 단계 · 교차, 계약 · 업적 진행, 재도전 방식, 판 사이 메뉴에 머문 시간, 약점 적중 통계, 그 밖의 게임 진행 수치(점수, 전령 · 기억 이벤트 발생 여부 등), 동의문 버전
- 날짜(일 단위)
- 무작위로 만든 익명 ID (게임이 처음 동의할 때 만든 무작위 번호로, 계정 · 기기와 연결되지 않음)

이름, SteamID, 이메일, IP 주소는 저장하지 않습니다. 인터넷 통신의 특성상 전송 과정에서 IP 주소가 일시적으로 처리되지만, 저장하거나 기록하지 않습니다.

## 2. 이용 목적

게임 밸런스 조정, 버그 수정, 성능 개선에만 씁니다. 광고, 판매, 프로파일링(개인 성향 분석)에 쓰지 않으며, 제3자에게 판매하거나 제공하지 않습니다.

## 3. 처리의 법적 근거

이용자의 동의 (개인정보 보호법 제15조 제1항 제1호, GDPR 제6조 제1항 a호).

## 4. 보유 기간

수집일로부터 2년이 지나면 자동으로 삭제합니다. 삭제를 요청하거나 서비스를 종료하면 지체 없이 삭제합니다.

## 5. 처리 위탁 및 국외 이전

| 항목 | 내용 |
|---|---|
| 이전받는 자 | Cloudflare, Inc. (미국) · 연락처 privacyquestions@cloudflare.com |
| 이전 국가 | 미국 등 Cloudflare 데이터센터 소재국 |
| 이전 일시 · 방법 | 판이 끝날 때마다 인터넷(HTTPS 암호화)으로 전송 |
| 이전 항목 | 1번의 수집 항목 |
| 이용 목적 | 데이터 저장 · 호스팅 |
| 보유 기간 | 4번과 같음 |
| 거부 방법 · 결과 | 「동의하지 않음」을 고르거나 설정에서 끄면 전송하지 않음. 거부해도 게임 이용에 불이익 없음 |

EU · 영국 거주자의 데이터 국외 이전은 Cloudflare 의 표준계약조항(SCC) 및 EU-US Data Privacy Framework 에 따릅니다.

## 6. 이용자의 권리

- 동의를 거부할 수 있고, 언제든 설정 > 일반에서 철회할 수 있습니다. 철회하면 그때부터 전송하지 않습니다.
- 설정 > 일반의 「내 데이터 삭제 요청」 버튼으로 지금까지 보낸 기록의 삭제를 요청할 수 있습니다.
- 열람 · 정정 · 처리 정지는 아래 문의처로 요청할 수 있습니다.
- 한국 개인정보보호위원회(개인정보침해 신고센터 privacy.kisa.or.kr · 국번없이 118)에, EU 거주자는 거주국 감독기관에 민원을 낼 수 있습니다.

기록은 익명 ID 로만 구분되므로, 요청할 때는 설정 화면에 표시된 ID 를 함께 알려 주세요.

## 7. 아동

만 14세 미만(미국은 만 13세 미만)이라면 보호자의 동의 없이 동의하지 말고 「동의하지 않음」을 골라 주세요.

## 8. 안전성 확보 조치

모든 전송은 HTTPS 로 암호화하며, 저장된 데이터에 대한 접근 권한은 개발자로 제한합니다.
