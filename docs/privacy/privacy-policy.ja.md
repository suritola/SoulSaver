# Soul Saver プレイデータ収集・プライバシーポリシー

文書バージョン v1 · 施行日 2026-10-20

<!-- ゲーム内同意文(Assets/Scripts/LocTable.Telemetry.cs)と同じ内容。変更時は両方を直し ConsentVersion を上げること -->

Soul Saver はゲームをより良くするため、プレイヤーが**同意した場合に限り**、ラン終了ごとに匿名のプレイ記録を送信します。同意しなくてもゲームのすべての機能を同じように利用でき、設定 > 一般からいつでも変更できます。

## 1. 収集する項目

- ゲームバージョン、製品版／体験版の区別、プラットフォーム(OS の種類)、ゲーム言語
- 英雄、難易度、モード、ランの結果、プレイ時間、レベル、撃破数
- 選んだカード・武器・スキル・系統・進化、章ごとの所要時間、与ダメージ・被ダメージの統計、倒れた原因、魂のかけら
- 必殺技、到達した章、魂の重み・刻印・遺物、スキル進化、系統の段階・交差、契約・実績の進行、リトライの方法、プレイの合間にメニューにいた時間、弱点ヒットの統計、その他のゲーム進行の数値(スコア、使者・記憶イベントの発生有無など)、同意文書のバージョン
- 日付(日単位)
- ランダムな匿名 ID(初めて同意したときにゲームが作る乱数で、アカウントや端末とは結び付きません)

氏名、SteamID、メールアドレス、IP アドレスは保存しません。インターネット通信の性質上、送信の過程で IP アドレスが一時的に処理されますが、保存・記録はしません。

## 2. 利用目的

ゲームバランスの調整、バグ修正、パフォーマンス改善にのみ使用します。広告、販売、プロファイリングには使用せず、第三者に販売・提供することはありません。

## 3. 処理の法的根拠

利用者の同意(韓国個人情報保護法第15条第1項第1号、GDPR 第6条第1項(a))。

## 4. 保存期間

収集日から2年が経過すると自動的に削除します。削除の要請またはサービス終了時には遅滞なく削除します。

## 5. 処理の委託および国外移転

| 項目 | 内容 |
|---|---|
| 移転先 | Cloudflare, Inc.(米国)· 連絡先 privacyquestions@cloudflare.com |
| 移転先の国 | 米国など Cloudflare のデータセンター所在国 |
| 移転の時期・方法 | ラン終了ごとにインターネット(HTTPS 暗号化)で送信 |
| 移転する項目 | 1 の収集項目 |
| 利用目的 | データの保存・ホスティング |
| 保存期間 | 4 と同じ |
| 拒否の方法・結果 | 「同意しない」を選ぶか設定でオフにすると送信しません。拒否してもゲームの利用に不利益はありません |

EU・英国居住者のデータの国外移転は、Cloudflare の標準契約条項(SCC)および EU-US Data Privacy Framework に基づきます。

## 6. 利用者の権利

- 同意を拒否でき、設定 > 一般からいつでも撤回できます。撤回するとそれ以降は送信しません。
- 設定 > 一般の「データの削除をリクエスト」ボタンで、これまで送信した記録の削除を要請できます。
- 閲覧・訂正・処理の停止は、下記のお問い合わせ先に要請できます。
- 韓国の個人情報保護委員会に、EU 居住者は居住国の監督機関に苦情を申し立てることができます。

記録は匿名 ID でのみ区別されるため、要請の際は設定画面に表示される ID もお知らせください。

## 7. 子ども

14歳未満(米国では13歳未満)の方は、保護者の同意なしに同意せず、「同意しない」を選んでください。

## 8. 安全管理措置

すべての送信は HTTPS で暗号化し、保存データへのアクセス権限は開発者に限定します。
