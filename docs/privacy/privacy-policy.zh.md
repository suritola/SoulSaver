# Soul Saver 游戏数据收集与隐私政策

文档版本 v1 · 生效日期 2026-10-20

<!-- 与游戏内同意文本(Assets/Scripts/LocTable.Telemetry.cs)内容相同。修改时两处都要改,并提高 ConsentVersion -->

为了让游戏变得更好,Soul Saver **仅在你同意的情况下**,在每局结束时发送匿名的游戏记录。即使不同意,也能同样使用游戏的全部功能,并可随时在 设置 > 通用 中更改。

## 1. 收集的项目

- 游戏版本、正式版/试玩版、平台(操作系统类型)、游戏语言
- 英雄、难度、模式、对局结果、游戏时长、等级、击杀数
- 选择的卡牌·武器·技能·流派·进化、各章用时、造成/受到伤害的统计、倒下原因、灵魂碎片
- 必杀技、到达的章节、灵魂重量・刻印・遗物、技能进化、流派阶段与交叉、契约与成就进度、重试方式、两局之间停留在菜单的时间、弱点命中统计、其他游戏进度数值(分数、是否触发传令或记忆事件等)、同意书版本
- 日期(精确到日)
- 随机匿名 ID(首次同意时由游戏生成的随机编号,与账号或设备无关联)

我们不保存姓名、SteamID、电子邮箱或 IP 地址。由于互联网通信的特性,传输过程中会临时处理 IP 地址,但不会保存或记录。

## 2. 使用目的

仅用于游戏平衡调整、漏洞修复和性能改进。不用于广告、销售或用户画像,也不会出售或提供给第三方。

## 3. 处理的法律依据

用户的同意(韩国《个人信息保护法》第15条第1款第1项、GDPR 第6条第1款(a)项)。

## 4. 保存期限

自收集之日起满2年后自动删除。提出删除请求或服务终止时,将立即删除。

## 5. 委托处理与跨境传输

| 项目 | 内容 |
|---|---|
| 接收方 | Cloudflare, Inc.(美国)· 联系方式 privacyquestions@cloudflare.com |
| 传输国家 | 美国等 Cloudflare 数据中心所在国家 |
| 传输时间与方式 | 每局结束时通过互联网(HTTPS 加密)发送 |
| 传输项目 | 第1条中的收集项目 |
| 使用目的 | 数据存储与托管 |
| 保存期限 | 与第4条相同 |
| 拒绝方法与后果 | 选择「不同意」或在设置中关闭即不会发送。拒绝不会对游戏使用造成任何不利影响 |

欧盟及英国居民的数据跨境传输依据 Cloudflare 的标准合同条款(SCC)及 EU-US Data Privacy Framework。

## 6. 用户的权利

- 你可以拒绝同意,并可随时在 设置 > 通用 中撤回。撤回后将不再发送。
- 可通过 设置 > 通用 中的「请求删除我的数据」按钮,请求删除迄今为止发送的记录。
- 查阅、更正、停止处理可通过下方的联系方式提出请求。
- 可向韩国个人信息保护委员会投诉;欧盟居民可向所在国的监管机构投诉。

记录仅通过匿名 ID 区分,提出请求时请一并告知设置界面中显示的 ID。

## 7. 儿童

未满14周岁(美国为未满13周岁)者,请勿在未经监护人同意的情况下同意,请选择「不同意」。

## 8. 安全保障措施

所有传输均采用 HTTPS 加密,存储数据的访问权限仅限开发者。
