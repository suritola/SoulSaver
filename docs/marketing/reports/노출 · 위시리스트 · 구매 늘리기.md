1. **컨트롤러 표기 바꾸기**: Steamworks 「컨트롤러 지원」을 **Full** 로 바꾸고, Steam Input 기본 구성을 「게임패드(Xbox)」로 켠다(PS 패드는 이 설정으로 동작). 스팀덱은 1280×800 에서 메뉴 · 카드 · 영혼 트리 글자를 한 번 확인한다. Valve 가 2026년 여름 출하를 공지한 Steam Machine 의 검증 기준도 「컨트롤러만으로 전체 플레이」다. → 구매 **중간~높음**
2. **출시일 다시 판단 (10월 말까지)**: Steamworks 에서 총 위시리스트와 최근 30일 증가분을 적는다(둘의 판매 예측력은 비슷하다).
   - Next Fest 2026-02 벤치마크(182개): 행사 전 위시리스트 0~999개면 행사 중 중앙값 **+322**, 1,000~9,999개면 **+1,006**.
   - 체험판 플레이 → 위시리스트 전환 중앙값은 16.3%, 상위권은 20%.
   - 2027년 6월까지 스팀 테마 축제 가운데 서바이버류에 맞는 것은 **Next Fest(2/22~3/1, 등록 마감 1/10) 하나뿐**이다.
   - 그래서 **2/22 전에 2,000개 이상 모을 수 있으면 B안(2월 Next Fest → 3월 출시)이 낫다.** 출시일은 한 번 정하면 옮기지 않는다(개인 캘린더 매칭이 날짜 기준).

   - 켜야 체험판 리뷰가 보이고, New & Trending 에 오를 수 있다.

4. **태그 20개 채우기**: 공식 문서에 따르면 상위 20개가 유사 게임 판단에 쓰이고, **흔한 태그보다 드문 태그가 가중치가 크다.**

5. **짧은 설명을 「장르 → 훅 → 분량」 순서로 다시 쓰기** (한 판 길이는 실제 값으로 바꿀 것)

7. 소형 캡슐(462×174)은 따로 구성한다: 로고 85% + 거너 · 광선 · 리치 왕 얼굴만.
8. 라이브러리 캡슐(세로)은 지금이 가장 낫다. 거너만 1.5배로 키운다.
