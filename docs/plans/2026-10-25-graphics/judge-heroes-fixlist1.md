## 공통
- 흑백 계층: 얼굴 · 눈이 가장 밝아야 함. 금속 강조 · 머리카락 · 소품이 얼굴보다 밝은 곳은 한 단계 낮춤.
- 검사 · 지도 제작자 · 거너 · 시계공이 모두 같은 「넓은 금 허리띠 가로 막대 + 가운데 버클」 → 묶음 전체 반복 무늬. 허리띠 폭 · 버클 위치 · 재질을 영웅마다 다르게(없애도 됨).
- 검사기: gunner_nogun.png(256×416, 세로가 김)는 첫 칸 자동 자르기가 빗나가 k 0.50 → 거짓 실패. tools/art/lint.py 의 자동 자르기를 「시트의 칸 크기 = 설계도 칸(32) 기준」으로 고치거나 README 를 바로잡을 것 (--design-cell 32x32 면 통과).
