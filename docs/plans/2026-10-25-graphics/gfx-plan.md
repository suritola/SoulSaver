## 검토 반영 (2026-10-24 · 반박 검토 → 이 문서가 최종본)

코드로 다시 확인한 결과: 줄 위치 · 수치 주장 약 60곳은 맞음 (FloorTone · 초원 감광 · Fx 기본 층 · 「내 이펙트 불투명도」 · 체력바 숨김 조건 · 숫자 수명 · 알림 띠 상수 · 카드 배치 · 룬 · 충격파 지름 · QA 캡처 정렬 결함 · 압축 텍스처 33장 · 보스 배율 등). 아래만 바꿈 — 고친 자리는 본문에 「(검토)」로 표시.

**A. 틀린 전제 고침**
1. 「정예 = IsMidBoss」 아님 — 「정예 무리」(`ChapterEvents.cs:484-490`)는 `Buff`(체력 ×3 · 「정예」 꼬리표, `:499-510`)만 받은 일반 적이라 `IsMidBoss` 가 거짓. 그대로면 「정예만」 설정에서 정작 「정예」 꼬리표 적의 막대가 숨음 → `Buff` 가 표식 `EliteMark` 를 붙이고 체력바가 읽음 (1-F 에 ChapterEvents.cs).
2. 4장 AbyssWarn 은 1.5.8 사용자 요청이 「스킬마다 다른 **모양 · 색**」. `HostileColor` 를 그대로 걸면 영혼(194°) · 강철(228°, 채도 0.15) · 균열(157°)이 보라 285° 로 모여 넷 중 셋이 같은 색 → 종류별 적대 대역 색 표(넷 다 다른 색)로.
3. 「그림에 외곽이 이미 있음」은 일부만 — 가장자리 칸 중 어두운(Y<40) 칸 실측: 초원 슬라임 53% · 버섯 55% · 벌 65% · 묘역 해골 41% · Enemy2 54% · Enemy3 57% · 리치 왕 61% · 지옥 잡몹 63~80% (심연 그림만 74~98%). 셰이더 외곽을 끄면 체험판 잡몹 실루엣의 절반이 바닥에 녹음 → 「붙은 그림 칸이 이미 어두우면 그 자리만 셰이더 외곽 생략」(`_SkipDark`)으로 어디서나 정확히 1칸.
4. 보스 몸의 흰 깜빡임은 이미 게임 신호 — 기억이 깨진 「휘청(지금 더 아프다)」 = 1.5초 동안 0.25초 주기 흰 깜빡임(`BossMemory.cs:364`), 기억 시작 = 0.6초 흰빛(`:280`). 피격마다 0.3초 간격 흰 번쩍임을 넣으면 이 신호와 구분이 안 되고, 화면 높이의 1/3 이 넘는 몸이 초당 3.3번 번쩍임(광과민 기준 초당 3번 초과) → 보스 피격은 순빨강 대신 0.1초 밝기 ×0.85 (색 · 흰빛 없음).
5. 「내 것」 분류(`Fx.Mine` = `DamageSource.Current`)가 적 반응에 샘 — 보스 「분노!」 붉은 충격파(`boss.cs:295`)는 플레이어 피해 호출 안에서 불려 지금도 「내 이펙트 불투명도」가 걸리고, 기획대로면 적 아래 층 · 아군 처리까지 받음 → 그 줄을 `DamageSource.As(DamageSource.Other)` 로 감쌈 (1-E · 처치 연출 `Juice.cs:25` 와 같은 방식).
6. 색각 모드에서 적 테는 `Hostile.Accessible` 이 주황 (1, 0.72, 0.1) = 색상 41° 로 바꿈 → 새 거너 금 #FFC94D(41°) · 시계공 황동(37°) · 우체부 금(40°)과 같은 색상. 체험판 기본 영웅이 거너 → 색각 모드에서만 아군 영웅 전투색 20°~65° 를 하늘 195° 로 (`VisualRules.AllyCb`).
7. 체력바 `OnDamaged` 의 visible 은 피해 등급에도 쓰임 (`HealthBarFeel.cs:131`: 안 보이면 체력 2% 미만 피해는 Small) → 숨긴 막대에 visible=false 를 넘기면 피해 숫자 크기가 바뀜 → visible 은 그대로, 렌더러만 끔.
8. 알림 띠 위끝 −150 의 빈틈 3가지 — ① 주 보스 막대만 있을 땐 `bossbar.LowestShown` 이 null(`bossbar.cs:302`)이라 「보스 막대 없음」을 알 수 없음 ② 정예 무리 · 습격 시작 알림(`Notice.Big`)과 진행 줄(위끝 −150 · 높이 50, `Notice.cs:47`)이 같은 순간 뜸 ③ 오른쪽 위 열(코인 · 포인트 · 키 안내 −193 까지)과 넓은 띠가 겹침 → `bossbar.MainShown` 추가 · 띠가 −150 일 땐 진행 줄을 잠깐 숨김 · 띠 반폭이 오른쪽 열에 닿으면 −212 (1-H 에 bossbar.cs).
9. 6-3 기준의 자기모순 — 적대 테 #FF4033 은 흑백 Y 120 인데 「테 · 탄 심 Y ≥ 200」 → 「닫히는 흰 고리 · 탄 흰 심 Y ≥ 200, 테는 색상만」.

**B. 효과 대비 위험으로 빼거나 줄인 것**
10. 내 **바닥** 이펙트 알파 상한 0.55 뺌 — 적 아래 층(GroundFx)으로 내리는 것만으로 적을 덮지 않음. 상한은 외부 평가의 다른 절반 「내 스킬이 안 보임」만 악화. 적 **위** 층에 남는 몸 0.8 · 장식 0.7 상한은 유지.
11. 「터짐 0.4초」 수명 상한 뺌 — 표 C 의 6프레임 시트는 16fps 에서 이미 0.375초, 실제로 줄어드는 건 폭발 0.5초 정도인데 폭발은 적 아래로 내려감. 남는 건 `Play` 로 받은 FxAnim 을 붙잡는 호출부가 먼저 지워지는 위험뿐 → 장식(불꽃 튐 · 반짝임 · 핏방울 · 연기) 0.25초만, 풀(`Spawn`) 경로에서만. fx_soulstep(사용자가 승인한 영혼불 발자국) · fx_trail_dot(잔상)은 장식 표에서 뺌.
12. 내 이펙트 색 **전역** 자동 보정(`AllyColor` 를 `Fx.MyAlpha` · `BulletGlow` · `SkinFx` · `AttackLook.Vivid` 에) 뺌 — 플레이어 쪽 코드의 채도 있는 색 500개 중 157개가 적대 대역(불꽃 · 피 · 표식 · HUD 포함)이라 결과를 예측할 수 없고, 효과 스킨 「벚꽃」(1, 0.6, 0.75 = 337°)이 주황이나 청보라로 바뀌어 구매한 꾸미기가 망가짐 → 영웅색 표 3벌을 1벌로 맞추는 것만 (9색 · `HeroColor` · `HeroAim.ColorOf`), 나머지 키트 색은 2단계 2-5 에서.
13. `BulletGlow` 투사체 알파 하한 0.7 뺌 — 사용자가 고른 「내 이펙트 불투명도 50%」를 투사체에서 무시함. 색 보정도 12 로 빠져 1-B 에서 BulletGlow.cs 가 빠짐.
14. 잡몹 흰 번쩍임 0.05 → 0.08초 뺌 — 0.25초 간격이라 계속 맞는 무리의 흰 시간 비율이 20% → 32%, 「흰 테 = 플레이어」 규칙과 경쟁. 지금 0.05초 그대로.
15. 밝은 잡몹 ×0.88 어둡게 뺌 — 문제는 「적 위치가 안 보임」인데 가장 잘 보이는 적(위습 153 · 공허의 눈 145 · 묘역 해골 146)을 어둡게 할 까닭이 없음. 어두운 2종(Enemy3 63 · 사신 66) ×1.15 만. 6-3 의 「적 몸 ≤ 128」도 뺌.
16. 바닥 국소 평균 밉 3(8×8 상자) → 밉 5(32칸 타일 1장) — 8칸 상자마다 평균이 달라 상자 경계에 3~4 Y 계단(화면 6화소 격자)이 생김. 타일셋 5장이 모두 160×64(5×2 타일)라 밉 5 = 타일 1장 평균으로 정확히 맞고 이웃 타일로 번지지 않음.
17. 코인 금 외곽 뺌 — 코인 그림 1칸 = 1080p 0.11화소라 외곽선은 지금도 보이지 않음(재질 값만 바뀜). 대신 코인은 윤곽 재질 자체를 안 씀(아래 20).
18. 우체부 새 색 초록 → 지금 평타색 금(PostGold) 그대로 — 적대 대역 밖이고 가장 작은 변화 (UI · 범위표시의 빨강만 금으로).
19. QA 4번(전 · 후 · ui_menu · soak) → 1번 — AGENT 규칙 5 (캡처 · 배치 테스트는 토큰 · 시간이 큼). 6-3 기준이 절댓값이라 「전」 촬영이 필요 없고(전 값은 1-2 실측), 매 프레임 새 일이 거의 없어 soak 는 의심될 때만.

**C. 빠졌던 큰 효과 더함**
20. 코인이 적 **위**에 그려짐 — `PickupGlow` 가 코인 · 회복 물약을 Effect 층 순서 70 · 빛 무리 알파 0.6 으로 올림(`PickupGlow.cs:34-46`). 무한 모드에서 쌓인 코인이 적 무리를 덮음 → 코인은 GroundFx(적 아래 · 내 바닥 이펙트 위), 회복 물약만 지금 그대로 (1-E).
21. 피격 「어둡게」(×0.55 · 0.4 · 0.42 = 밝기 약 45%, 1단계-10)가 어두운 바닥과 겹침 — 초원 잡몹 Y 125 → 56 으로 지금 초원 바닥(58)과도, 눌린 바닥(48)과도 같아짐. 계속 맞는 무리 = 나에게 붙는 무리가 바닥에 녹음(받는 피해 60~80% 가 몸 충돌) → 밝기만 ×0.78 (Y 125 → 98, 바닥 + 50) (1-E).
22. 피해 숫자 그림자(Underlay)는 TMP 의 shader_feature 라 빌드에 없는 키워드 조합은 **빌드에서만 조용히 빠짐** → `CreateFontAsset` 이 만드는 Mobile SDF 재질 + OUTLINE_ON · UNDERLAY_ON 만 씀 (TMP Resources 의 「LiberationSans SDF - Drop Shadow.mat」 이 같은 셰이더 · 같은 조합이라 빌드에 남음).
23. 바닥 셰이더는 `Resources.Load<Shader>` + `isSupported` 확인, 못 읽으면 바닥 재질을 바꾸지 않음 (`Shader.Find` 금지 · shader_feature 금지 · 주 색은 명시 LOD 0 이라 밉맵을 켜도 조준 줌에서 흐려지지 않음).

**D. 규칙 · 묶음**

26. 보류 그대로 (사용자 결정): 산세리프 단일 글꼴 · UI 강조 #FFBB00 · 2단계 그림 주체. 피해 숫자의 숫자 글꼴(숫자 14자 · UI 글은 그대로)은 글꼴 통일 결정과 떼어 1-G 에 둠 — 통일을 안 하기로 해도 남길 수 있고, 하기로 하면 그 글꼴로 바꾸기만 하면 됨.

### 1-A 바닥 재질 — `Resources/Shaders/FloorFlat.shader`(새 셰이더) · `StageManager.cs`

### 1-B 내 이펙트 층 · 알파 · 장식 수명 — `Fx.cs`
- `Play` · `Spawn` · `SpawnGet` 의 `layer` 기본값 "Effect" → `null`. `null` 이면 `!Legacy && Mine && VisualRules.IsGround(name)` → `VisualRules.GroundFx`, 아니면 "Effect". 명시해서 넘긴 층은 그대로 (SpawnPop 의 경고 층 · 처치 퍼프 · 등장 고리 · 지형 웅덩이 등). `Reuse`(매 프레임 다시 그리는 조준 표시) · `SpawnFacing` 은 "Effect" 그대로. 구현 때 `"Effect")` 를 직접 넘기는 내 바닥 이펙트 호출부를 grep 해 그 인자를 지움.
- `MyAlpha(c, name)` (`Fx.cs:110`): `Mine && !Markers` 일 때 `cap = MyAlphaCap(name)` 이 1 이면 지금처럼 `c.a *= MyFxAlpha`, 아니면 `c.a *= max(cap × MyFxAlpha, MyAlphaFloor(name))`. **색은 바꾸지 않음** (검토 — 전역 색 보정 없음).
- 장식 수명: `SpawnGet`(풀 경로)에서만 `!Legacy && Mine && !loop && life <= 0 && DecorLifeMax(name) > 0` 이면 `fps = max(fps, frames.Length / DecorLifeMax(name))`. Setup 이 매번 fps 를 새로 넣으므로 풀에서 다시 쓸 때 남는 값 없음. `Play` 는 손대지 않음 (돌려받은 FxAnim 을 붙잡는 호출부가 있음).

### 공통
- 격자: **그림 1칸 = 월드 1/6칸 (PPU 6 · 배율 1)** → 1080p 4.09 · 1440p 5.45 · 4K 8.18 화소 (카메라 22 에선 정수가 아니라 ±1화소 흔들림은 남음 — 「한 가지 크기」가 목표).

### 6-3 판단 기준 (흑백 Rec.601 Y)
1. **바닥**: 평균 28 ≤ Y ≤ 55, 8×8 국소 표준편차 ≤ 8. (지금 사막 92 · 초원 58 · 묘역 36±11)
2. **적 몸**: 평균 Y ≥ 바닥 + 35 — 맞는 중인 무리(화염 지대 위)도. (지금 03 은 바닥 > 적 탄 역전 · 초원에서 맞는 잡몹 56 ≈ 바닥 58) (검토: 위 한도 ≤ 128 은 뺌)
3. **플레이어**: 외곽 띠 Y ≥ 235, 발 고리 보임. 플레이어 둘레 띠가 화면에서 가장 밝은 무리에 듦.
4. **적 위험**: 경고 테 색상이 적대 대역(빨강 · 보라 / 색각 모드 주황 · 자홍), 닫히는 흰 고리 · 탄 흰 심 Y ≥ 200 (검토: 테는 #FF4033 = Y 120 이라 색상만 봄), 흰 · 하늘 룬 원 0개, 적 탄 고리 색상 35°~250° 0개, 4장 잡몹 예고 4종이 서로 다른 색상.
5. **내 이펙트**: 있을 때/없을 때 적 몸 평균 Y 차이 ≤ 10% (적이 덮이지 않음), 적 위(Effect 층)에 그린 내 이펙트 실효 알파 ≤ 0.8, 내 바닥 이펙트는 적보다 아래 층.
6. **순서**: 바닥 < 적 몸 < 플레이어 띠 ≤ 적 위험의 흰 요소 (내 바닥 이펙트는 밝아도 적 아래 층이라 비교에서 뺌).
7. **화소 밀도**: 화면 12화소/칸 넘는 렌더러 = 보스 6종 · 중간 보스뿐 (2단계 끝나면 0). 결계 · 침식 룬 · 거대 충격파 0.
8. **UI**: 보스 막대 · 진행 줄이 없고 짧은 알림이면 큰 알림 띠가 화면 위 14~24% 안 (위끝 ≤ 15%), 그 밖엔 20~29%, 띠와 진행 줄이 겹치지 않음, 4개 언어 글 넘침 0, 카드 설명 위 정렬, 띠 · 카드 위를 다른 그림이 덮지 않음(캡처 수정 확인).
9. **성능**: 렌더러 수 감소(룬 · 잡몹 체력바 · 결계 충격파) — soak 는 의심될 때만.
10. **사후 지표**(배포 뒤): 텔레메트리 「적과 부딪힘」 받은 피해 비율(지금 60~80%) · 분당 피격 · 생존 시간 · 초반 사망률을 버전 비교 (`tools/telemetry` pull.py). 패치노트 표기 「그래픽 가독성 · 밸런스 변화 없음」 + 잡몹 체력바 기본 끔 · 설정 위치 한 줄.
