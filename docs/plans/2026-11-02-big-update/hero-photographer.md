## 0. 한 줄 정체 · 재미 핵심

> **「커서가 뷰파인더다.」** 틀에 몇 마리를 넣느냐(구도), 가운데에 누구를 두느냐(초점)가 곧 평타 실력이다. 찍힌 적은 **흰 테두리를 두른 납작한 종이**가 되어 힘없이 펄럭이고, 필름 한 통을 다 찍으면 감으면서 **그 통에서 가장 잘 나온 사진을 커서 자리에 인화**한다. 인화된 종이 사본이 미끼가 되어 적을 끌어모으고, 찢어지면 터진다.

| 동사 | 기존 9명과 다른 점 |
|---|---|
| **사각 틀로 찍기** (공간 선택) | 연금술사(점 + 원 폭발) · 궁수 화살비(원)와 달리 **축이 고정된 직사각형**. 「몇 마리 넣었나」가 화면에 숫자로 보이고 보상이 계단으로 커짐 (스냅 → 단체 사진 → 걸작) |
| **종이로 만들기** (무력화) | 유령의 냉기는 **쌓아서** 멈춤(5중첩 → 1초 얼음, 파란색). 종이는 **찍는 즉시**, 멈추지 않고 **약해지고 · 가벼워지고 · 아프지 않게** 됨 (받는 피해 ×1.4 · 넉백 ×2.5 · 접촉 피해 0 · 스킬 못 씀 · 30% 속도로 펄럭임, 흑백에 흰 테). 지도 제작자의 종이는 **땅에 긋는 획**일 뿐 적을 바꾸지 않음 |
| **인화 · 미끼** (위치 유도) | 거너의 거울 분신(`EnermyController.Decoy`: 모든 적이 하나를 쫓음)과 달리 **찍힌 적의 모습 그대로, 사진 속 배치 그대로** 서는 종이 사본 여러 장. 7칸 안의 적만 끌림. 찢기면 터짐 |
| **살려 두기** (해금 · 정체성) | 다른 영웅은 「빨리 죽이기」가 미덕이지만 사진사는 「찍을 거리가 많을수록」 세짐. 해금 자체가 「죽이지 않고 많이 살려 두기 → 찰칵 → 찾아가기」 |

## 3. 평타 · 우클릭(필살기) · 필름 감기(인화)

### 3-1. 평타 「셔터」 (좌클릭)

| 단계 | 일어나는 일 | 수치 |
|---|---|---|
| 늘 | 커서 자리에 **뷰파인더**(꺾쇠 네 모서리 + 가운데 초점 원)가 옅게 따라다님. 중심은 사거리 안으로 당겨짐(`ClampRange` 와 같음). 회전 없음(화면 축) | 틀 3.6 × 2.7칸(4:3) · 초점 원 반지름 0.7칸 · 알파 0.45 |
| 틀 안 수 | 틀 오른쪽 위에 지금 틀에 든 일반 적 수 「×7」 (6 이상이면 금색 ★) | 0.1초마다 다시 셈 (`PhysHits.Box` 하나) |
| 누름 (`FireDown` · 꾹 누르면 공격 간격마다) | 「찰칵」 — 틀 안 적 · 보스 모두에게 셔터 피해, 틀 **안쪽만** 흰 번쩍(0.08초 · 화면 전체 백색 금지 원칙), 필름 −1 | 피해 공격력 100% · 넉백 0 |
| 초점 | 초점 원에 몸이 닿은 적 중 **중심에 가장 가까운 하나**는 초점 피해 (금색 숫자 `DamagePopup.NextCrit`) | ×1.6 |
| 종이 | 틀 안 **일반 적**(중간 보스는 짧게, 보스는 제외)은 종이가 됨 (3-4절 `PaperRoll`) | 2.5초 · 중간 보스 1.2초 · 종이가 풀린 뒤 1.5초는 다시 안 됨(「현상 중」 — 흐린 흰 테가 한 번 깜빡) |
| 사진 등급 | 틀 안 일반 적 수: 1~2 스냅 · 3~5 단체 사진 · **6 이상 걸작** | 걸작: 필름 1장 돌려받음(**통마다 최대 2장**) · 필살기 게이지 3% · 손맛 Attack 연출 · `RunCounters.Both("photo.masterpiece")` |
| 보스 | 종이가 되지 않고 **초점 표식** +1 (가운데 초점이면 +2) — 표식마다 사진사가 주는 모든 피해 +6% · 최대 5 · 마지막으로 찍힌 뒤 4초 유지 | 최대 +30% |
| 사진 기록 | 이번 장을 「사진」으로 기억: 찍힌 일반 적 최대 6마리의 (지금 스프라이트 · 좌우 뒤집힘 · 틀 중심에서의 상대 위치) + 수 + 시각 | 판 안에서만 (저장하지 않음 · 7절 난점 4) |

- **틀 안 판정**: `PhysHits.Box(중심, 크기, 0°)` (새 도우미, `PhysHits.Circle` 과 같은 방식 — 「필요한 공용 변경」). 몸 콜라이더가 틀에 조금이라도 걸리면 안. 벽 너머도 찍힘(사진이니까) — 단 경기장 밖은 `ArenaRules` 경계로 틀을 자름.
- **빈틈(WeakSpot)**: 초점 원 가운데가 보스 빈틈 위면 초점 피해에 빈틈 배율 (연금술사 첫 병 직격점과 같은 규칙: `WeakHit.Hit(…WeakShape.Point(중심, 0.5f, 1.75f)…)`).
- **멀티샷(`player.multiShot`)**: 셔터 한 번에 장수가 늘지 않고 **틀이 커짐** (멀티샷 1마다 가로세로 +12%, 피해는 `MultiShotDamageRate` 그대로). 표창 · 편지처럼 개수가 늘면 같은 틀을 겹쳐 찍어 의미가 없음.
- **범위 표시**(범위표시 기획): 뷰파인더는 `PixelStrokeMin` 에 **새 모양 Rect**(꺾쇠 네 개 · 1/7 칸 도트 · 맨 위 층 · Overlay 큐). 가운데 초점 원은 사진사 문양 고리(아래). 필름이 2장 남으면 틀 아래에 남은 필름 점 2개가 깜빡.
  - 사진사 고리 문양(`PixelRingArt` style): **조리개 날** — 테 사이에 휘어진 날 빗금 6개, 네 방향 마름모 자리는 작은 네모(필름 구멍).
  - `HeroAimDecor`: 파노라마 띠 위아래 가장자리를 따라 **필름 구멍(스프로킷)이 흘러가고**, 띠 한쪽 끝에 접힌 셔터 커튼이 대기 · 다 차면 커튼 끝이 흰빛으로 깜빡.
- **조준 표시(HeroAim)**: 뷰파인더 자체가 조준이라 따로 조준선 없음. 화면 밖으로 커서가 나가면 틀은 사거리 끝에 멈춤.
- **패드**: 오른 스틱 = 커서 (기존 패드 조준 규칙 `GamePad.Aiming` · 스틱 방향 × 기울기 × 사거리). RT 셔터 · LT 파노라마 (필름 감기 = 인화는 자동 · 기존 재장전 버튼 X 로 일찍도 가능). 스틱을 놓으면 틀은 마지막 자리(나를 따라 움직임)에 남음.

### 3-2. 필름 감기 = 「인화」 (평타 쪽으로 접음 — 필름을 다 쓰면 자동)

- 입력은 늘지 않음 (heroes-common 2-1): 여섯 번째 셔터가 끝나는 순간 감기가 저절로 시작 = 인화. 일찍 감기는 이미 있는 재장전 키(R · 패드 X)로 **할 수도 있을 뿐** — 기본 플레이는 좌클릭 하나로 끝까지 굴러감. 공격 고정(`GameSettings.AttackLock`) · 패드 · 자동 조작 모두 같은 자동 감기라 따로 처리 없음.

### 3-4. 종이(Paper) 상태 — `PaperRoll` (heroes-common 2절 EnemyHold 사용)

| 항목 | 내용 |
|---|---|
| 붙잡기 | `EnemyHold.TryTake(e, roll)` — 보스 · 이미 잡힌 적 · 죽은 적은 거절. **중간 보스는 사진사 문서에서 허용**(1.2초). 거절되면 종이 없이 피해만 |
| 움직임 | owner 가 `transform.position` 을 직접: 플레이어 쪽으로 원래 속도의 **30%** + 옆으로 흔들림(사인 ±0.6칸 · 1.6Hz). 넉백은 owner 가 속도로 받아 ×2.5 (0.25초에 걸쳐 감쇠). 경계는 `ArenaRules` 로 자르고, 벽(`Hostile.IsWall`)이면 멈춤 |

| 상한 | 동시 종이 **40** (넘으면 가장 먼저 종이가 된 적부터 풀림) · 면역 기록은 `Dictionary<EnermyController, float>` 2초마다 정리 (`PostmanPaths.Prune` 과 같은 방식) |
| 쓰러짐 | 그 자리에 종이 찢김 조각 3장(`fx_papertear`) + 「바스락」 · `RunCounters.Add("paper.kill")` |
| 판 끝 · 영혼 릴레이 | `End()` · 영웅이 바뀔 때 · 씬 전환 때 `EnemyHold.ReleaseAll(roll)` + 그림 복원 |

**그림 처리 (난점 1의 해결)**
1. 적 본체 `SpriteRenderer` 는 `enabled = false` 로 끄고(애니메이터는 그대로 돎), 대신 「종이 그림」 자식 렌더러를 붙임. 자식은 `PaperRoll` 의 풀(최대 40)에서 꺼냄 — `new GameObject` + `SpriteRenderer` (자기 복제 `Instantiate` 금지 규칙).
2. 자식은 매 `LateUpdate` 에 본체의 `sprite` · `flipX` 를 그대로 베낌 (애니메이터는 본체에서 계속 돎 → 풀릴 때 자연스러움).
3. 재질: `SpriteOutline` 셰이더로 **종이 재질 하나** (`_OutlineColor` 흰색 불투명 · `_Saturation` 0.3 · `_Brightness` 1.15) = 흑백 사진 + 1도트 흰 테. 재질 하나를 모두 같이 써서 그리기 묶음이 늘지 않음 (`SpriteOutline.Enemy` 와 같은 관례로 `SpriteOutline.Paper` 를 더함 — 「필요한 공용 변경」).
4. 납작함: 자식 크기를 **계단 배율**로 — 세로 0.6, 펄럭임은 가로를 {1, 0.75, 0.5, 0.75} 계단으로 0.15초마다 바꿔 「돌아가는 종이」처럼 + 기울임 ±8°. 소수 배율의 도트 뭉개짐을 계단으로 줄임 (결정 D-P2).
5. 콜라이더는 본체 그대로 (크기를 줄이지 않음 → 맞는 판정 · 밀어내기 그대로).
6. 피격 흰 번쩍: `Juice.SetFlash` 가 본체 렌더러에 걸리므로, 종이 자식에도 같은 `_Flash` 값을 베낌 (MaterialPropertyBlock 하나 재사용).
7. 풀릴 때: 본체 렌더러 켜고, 자식은 풀로. 적이 죽은 프레임에도 같은 프레임 `LateUpdate` 에서 복원 → 죽는 연출은 본래 그림 + 찢김 조각.

### 11-1. 흔적 · 위치
- **고정 흔적**: 시작점에서 **1시 방향(북북동) 45칸** 모래 언덕 위에 **빈 삼각대** 하나 (카메라 없음 · 다리 셋 · 꼭대기에서 렌즈 반사광이 3초마다 반짝 — 멀리서도 보이는 유일한 반짝임). 시작하자마자 화면 오른쪽 위 끝에 반짝임이 걸리도록 거리 조정 (화면 반너비 약 26칸 · 반높이 15칸 → 45칸이면 첫 30초 안에 시야). 둘레 6칸 장식 소품은 비움.
- 삼각대는 **판정 장소가 아님** (사진사는 조건형). 삼각대 곁에 가면 삼각대가 플레이어 쪽으로 「끼익」 고개를 돌림 — 「누군가 찍을 장면을 기다린다」는 인상만.
- 조건이 차는 동안 화면 네 모서리에 **초점 꺾쇠**(UI 오버레이 · 1도트 흰 L자)가 나타남: 노출 시간 비율에 맞춰 알파 0 → 0.6, 기준 이상인 동안만 0.5초 주기로 깜빡.

### 11-2. 판정 (난점 5 · 6)
- 조건: **무한 모드 사막 · 3:00 이후**, 카메라 화면 안(뷰포트에서 1칸 안쪽) **살아 있는 일반 적 수 ≥ N** 인 동안 「노출 시간」이 쌓여 **12초**가 되면 달성.
  - 셀 적: `tag == enermy` · 죽지 않음 · `swarm == null`(부스러기 제외) · 보스 제외 · **중간 보스 포함** · 종이 상태 포함.
  - 노출 시간: 기준 이상이면 `+dt`, 아래면 `−0.5 × dt` (0 아래로 안 감) — 잠깐 하나 잡아도 다 날아가지 않게.
  - **기준 N = clamp(지금 한 화면 상한 − 4, 12, 18)**. 고정 수가 아니라 상한을 따라가는 이유: 무한 모드의 상한은 **처치 수로 열리는 국면**(`EndlessMode.WithEndlessStage` 처치 0 · 25 · 55 · 90 · 130 … / 상한 8 · 10 · 12 · 14 · 16 · 18 …)에 묶여 있어, 「죽이지 않기」를 일찍 시작하면 상한이 낮은 채로 멈춘다. 고정 18 이면 그런 플레이어는 영영 못 깬다. −4 는 생성 직후 화면 밖에서 걸어 들어오는 몫.
  - 시각별 예 (보통 처치 속도 · `GameMode.ExtraAliveCount` = 2 + ⌊(MobRamp − 1) × 4⌋ 포함):

| 시각 | 국면 상한 | 한 화면 상한 (`min(20, 국면) + 덧수`) | N |
|---|---|---|---|
| 3:00 (처치 90) | 14 | 16 | **12** |
| 5:00 (처치 180) | 18 | 20 | **16** |
| 8:00 (처치 390) | 22 → 20 | 22 | **18** |
| 10:00 | 20 | 24 | 18 |
| 15:00 이후 (최종 국면 Surge) | — | 29 ~ 110 | 18 (쉬워짐 — 대신 버티기가 어려움) |
| 개발자 · 엄마전 | 잡몹 없음 | — | 판정 멈춤 (노출 시간 유지) |
| 영혼을 모으는 국면 | — | 55 | 18 |

  - 「필요한 공용 변경」: `EnemySpawner.MaxAliveNow` (지금 private `MaxAlive` 를 읽기 전용으로) · `PhysHits.Box`.
  - 성능: 0.25초마다 `PhysHits.Box(카메라 중심, 뷰포트 크기 − 2칸)` 한 번 + 태그 · `EnermyController.FromCollider` 검사 (매 프레임 검색 없음).
- 어느 영웅으로도 됨 (해금 비밀이니까). 사진사 자신이 달성하면 전설 스킨 업적(D11 업적형).

### 11-3. 발견 연출 (판은 멈추지 않음)
1. 화면 **가장자리 테두리만** 흰빛 0.1초 + `imp_shutter` 큰 소리 「찰칵!」 — 빛이 오는 쪽 = 삼각대 쪽 화면 끝 (삼각대 방향 벡터와 가장 가까운 변).
2. 그 변 밖에서 사진사가 삼각대를 메고 걸어 들어와 화면 끝 2칸 안쪽에 섬 (공격 받지 않음 · 적과 충돌 없음 · 4초).
3. 말풍선 1.5초: 「좋아, 이걸로 상점 페이지 바꾸자!」
4. `Notice` 작게 「새 영웅: 사진사」 · `char.unlocked.13 = 1` 즉시 저장 · 스팀 업적 `UNLOCK_PHOTOGRAPHER` (스팀 쪽 등록은 사용자 몫 — 보고서에 남김) · `RunCounters.Add("secret.photographer")`.
5. 사진사는 「현상하러 갈게요」 하며 원래 변으로 걸어 나감. 정식 축하는 결과 화면 — **이 순간 화면 안 적들을 사진 한 장으로**(아래 결과 사진과 같은 방식) 보여 줌.

### 11-4. 다시 했을 때 · 일일 도전 · 도감 · 힌트
