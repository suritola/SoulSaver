# 대규모 업데이트 기획 (2026-11-20)

사용자 결정
- 메타 성장: 모든 모드에 적용 — 기존 「판마다 같은 출발」(docs/review/2026-10-16-한판더-몰입-설계.md 3-9 · 506줄)을 이번에 뒤집음
- 2차 지시: **포인트로 능력치를 사는 것이 아니라, 특정 조건으로 특수한 능력을 해금 · 새 스킬 키는 만들지 않음** (모두 저절로 발동)
- 새 모드: **보스 러시** — 슬라임이 제일 먼저
- 영웅 확장: **기존 영웅의 영구 진화** (판 밖)

## A. 영혼 제단 — 유산 (SoulLegacy, 모든 영웅)
조건을 이루면 깨어나고, 깨어난 것 중 **셋까지 지님** (메인 메뉴 「영혼 제단」에서 지니기 · 내려놓기)
| 유산 | 효과 | 조건 |
|---|---|---|
| 피의 맹세 | 처치 시 3% 확률로 최대 체력 2% 회복 | 적 20,000 처치 (누적) |
| 불굴 | 판마다 한 번 쓰러질 피해를 체력 30%로 버팀 · 2초 무적 | 어려움 클리어 |
| 왕 사냥꾼 | 보스에게 주는 피해 +15% | 영웅 5명으로 이야기 클리어 |
| 왕의 전리품 | 보스 처치 시 레벨업 카드 2장 (상자처럼 대기 카드만 · 경험치 요구량 그대로) | 무한 모드 클리어 |
| 숨 고르기 | 레벨업마다 최대 체력 3% 회복 | 쉬움 클리어 |
| 선구자 | 판 시작 레벨업 카드 +1 (이야기) | 숙련 최대 영웅 1명 |
| 역류의 잔향 | 체력 30% 이하일 때 받는 피해 -25% | 역류 클리어 |
| 연전의 기억 | 보스 처치 시 최대 체력 20% 회복 | 보스 러시 클리어 |

- 저장: `legacy.eq` (지닌 유산 비트) · 조건은 이미 쌓이는 기록(누적 처치 · 클리어 · 숙련 · 모드 클리어)을 그때 읽음
- 꺼지는 판: 체험판 · 페스티벌 · 튜토리얼 · 자동 봇 · 배치

## B. 영웅 각성 (HeroAwaken, 영웅마다 · 판 밖)
그 영웅으로 조건을 이루면 단계가 따로 열리고 늘 켜짐 (영웅 상세 「각성」 버튼에서 확인)
| 단계 | 효과 | 조건 (그 영웅으로) |
|---|---|---|
| 1 | 판 시작 레벨업 카드 +1 (이야기) | 이야기 모드 클리어 |
| 2 | 필살기를 쓰면 최대 체력 8% 회복 | 이야기 보스 네 종 처치 |
| 3 | 판 시작 때 필살기 게이지 절반 | 필살기 300번 |
| 4 | 체력 40% 이하일 때 받는 피해 -20% | 무한 모드 15분 |
| 5 | 판 시작부터 1차 무기 진화 | 숙련 최대 |

- 효과는 지금 영웅으로 그때그때 읽어서 영혼 릴레이 교대도 그대로 맞음

## C. 보스 러시 (BossRushRun)
- 킹 슬라임 → 리치 왕 → 지옥의 군주(체력 ×0.5) → 거울의 군주 → 개발자, 앞 보스 처치 · 연출 · 진화 창이 끝나고 12초 뒤 다음
- 보스마다 무한 모드처럼 무기 진화 · 전리품 + 체력 30% 회복 · 잡몹은 무한 모드 그대로
- 기록: 모두 쓰러뜨린 시간 (순위표 BOSSRUSH_BEST 오름차순) · 첫 클리어 5,000P · 그 뒤 1,000P
- 해금: 보통 클리어 · 이어하기 없음 · 메인 메뉴에서 고른 영웅으로

## 확인 안 한 것 / 위험
- 게임에서 직접 돌려 보지 않음 · 화면 배치(메인 메뉴 한 줄 · 도전 모드 카드 넷 · 순위 탭 다섯 · 제단 여덟 줄) 캡처 없음
- 보스 러시 업적 · 전용 그림 없음 (그림은 역류 그림)
