=== ko
제목: V2.0.7 — 버그 전면 수정 · 밸런스 조정
부제: 영혼 제단 · 영웅 각성 · 보스 러시와 저장 보호의 버그를 모아 고치고, 첫 판이 너무 빨리 끝나지 않게 다듬었습니다.
본문:
[p]지난 대규모 업데이트에서 나온 버그를 한꺼번에 고쳤습니다. 플레이 기록을 보고 처음 시작하는 판이 너무 빨리 끝나지 않도록 밸런스도 조정했습니다.[/p]
[h2]🛠 버그 수정[/h2]
[list]
[*]보스가 쓰러지지 않고 사라지면 보스 러시를 끝낼 수 없던 문제
[*]보스 러시를 깨면 무한 모드 업적이 함께 풀리던 문제
[*]영웅 각성 4단계(무한 모드 15분)가 영혼 릴레이 · 역류 · 보스 러시에서도 열리던 문제
[*]영웅 각성 5단계의 시작 진화가 영혼 릴레이에서 다음 주자에게 넘어가던 문제
[*]유산 「불굴」이 메인 메뉴로 나갔다 이어하면 다시 채워지던 문제
[*]역류에서 「왕의 전리품」 알림만 뜨고 카드는 들어오지 않던 문제
[*]저장 파일이 사라졌을 때 가장 최근 백업이 아니라 그 전 백업으로 되살리던 문제
[*]튜토리얼 중에 스팀 업적으로 저장을 되살리면 비밀 영웅이 돌아오지 않던 문제
[*]메인 메뉴의 「영혼 제단」 버튼이 메뉴 줄에서 벗어나 화면 가운데에 있던 문제
[*]게임 중 「영혼 각인」 창을 ESC 로 닫으면 일시정지까지 풀리던 문제
[/list]
[h2]✨ 그래픽 · 접근성[/h2]
[list]
[*]연속 처치 때 화면 가장자리 빛이 빠르게 깜빡이던 문제 — 이제 부드럽게 이어서 빛납니다
[*]「번쩍임 효과」를 끄면 번개와 가장자리 빛도 옅어집니다
[*]스킨 미리보기의 도트가 1080p 가 아닌 화면에서 흐리게 번지던 문제
[/list]
[h2]⚖ 밸런스 조정[/h2]
[list]
[*]거너 체력: ×1.0 → ×1.15
[*]쉬움 난이도 보스 결계 피해: ×1.0 → ×0.8
[/list]
[p]플레이해 주셔서 감사합니다! 버그를 만나면 디스코드나 토론 게시판에 알려 주세요.[/p]

=== en
Title: V2.0.7 — Bug Fix Sweep · Balance Changes
Subtitle: Fixes for the Soul Altar, Hero Awakening, Boss Rush and save protection, plus tuning so first runs last longer.
Body:
[p]This update fixes the bugs that came with the last major update. Based on play data, we also tuned the balance so your first runs don't end too soon.[/p]
[h2]🛠 Bug Fixes[/h2]
[list]
[*]Boss Rush could never finish if a boss disappeared instead of being defeated
[*]Clearing Boss Rush also unlocked Endless achievements
[*]Hero Awakening tier 4 (15 minutes in Endless) could unlock in Soul Relay, Reflux and Boss Rush
[*]In Soul Relay, the tier-5 starting evolution passed on to the next runner
[*]The Indomitable legacy refilled after returning to the main menu and continuing
[*]In Reflux, Spoils of Kings showed its notice but gave no cards
[*]A missing save file was restored from the older backup instead of the newest one
[*]Restoring from Steam achievements during the tutorial left secret heroes locked
[*]The Soul Altar button sat in the middle of the main menu instead of in the menu column
[*]Closing Soul Brand with ESC during a run also unpaused the game
[/list]
[h2]✨ Graphics · Accessibility[/h2]
[list]
[*]The screen-edge glow flickered rapidly during kill streaks — it now glows smoothly
[*]Turning off Flash Effects now also dims lightning and the edge glow
[*]Skin previews looked blurry on screens other than 1080p
[/list]
[h2]⚖ Balance Changes[/h2]
[list]
[*]Gunner HP: ×1.0 → ×1.15
[*]Boss barrier damage on Easy: ×1.0 → ×0.8
[/list]
[p]Thanks for playing! If you run into a bug, let us know on Discord or in the discussions.[/p]
