# 1.0.7 업데이트

- 궁수 **정조준 · 매복** 개편
- 무한 모드 **개발자 · 개발자 엄마** 조정 — 싸우는 동안 잡몹이 다시 몰려옴
- 정조준이 작동하지 않던 문제 수정

## 밸런스 조정

- **정조준**: 가만히 서서 당길 때 당기는 속도 +30 / 60 / 90% → **항상 +25 / 50 / 75%**
- **매복**: 2초 동안 움직이지 않으면 덫 → **가득 당겨 쏠 때마다 발밑에 덫 (2초에 한 번)**
  - 반경 2.2 → **3.2** · 묶는 시간 1 / 1.5 / 2 / 2.5초 → **1.5 / 2 / 2.5 / 3초**
  - 걸린 적에게 **공격력 80% 피해** · 묶인 동안 **받는 피해 +30%** (새로 추가)
  - 같은 적이 **3초마다 다시 걸림** · 덫 최대 1개 → **3개**
- **개발자 체력**: 300,000 → **100,000** · **개발자 엄마** 600,000 → **300,000**
- **개발자 필살기 간격**: 2초 (분노 약 1.3초) → **체력이 가득일 때 10초, 닳을수록 빨라져 1초까지** · **개발자 엄마** 1초 (분노 약 0.64초) → **5초 → 1초**
- **개발자 필살기**: 화살비 4번 (분노 5) → **8번 (10)** · 대폭발 2번 (3) → **5번 (6)** · 속달 1번 → **3번 (4)** · 유령 필살기는 **쓰지 않음**

# 1.0.7 Update

- Archer **Steady Aim · Ambush Trap** reworked
- Endless **Developer · Developer's Mom** adjusted — regular enemies keep coming during the fight again
- Fixed Steady Aim not working

## Balance Changes

- **Steady Aim**: draw speed +30 / 60 / 90% while standing still → **always +25 / 50 / 75%**
- **Ambush Trap**: snare after standing still for 2s → **a snare at your feet on every fully drawn shot (once per 2s)**
  - Radius 2.2 → **3.2** · root 1 / 1.5 / 2 / 2.5s → **1.5 / 2 / 2.5 / 3s**
  - Caught enemies take **80% ATK damage** and **+30% damage taken** while rooted (new)
  - The same enemy can be **caught again every 3s** · max traps 1 → **3**
- **Developer health**: 300,000 → **100,000** · **Developer's Mom** 600,000 → **300,000**
- **Developer ultimate interval**: 2s (enraged ~1.3s) → **10s at full health, speeding up to 1s as health drops** · **Developer's Mom** 1s (enraged ~0.64s) → **5s → 1s**
- **Developer ultimates**: Arrow Rain 4 waves (enraged 5) → **8 (10)** · Grand Blast 2 (3) → **5 (6)** · Express Delivery 1 → **3 (4)** · **no longer uses** the Ghost ultimate
